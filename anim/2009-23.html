本题讲解：单处理机系统中谁能并行

第一步：抓住"单处理机"这个前提

答案：D。单处理机系统只有一个 CPU，判断能否并行只需问一句：双方是否要同时占用这个唯一的 CPU 执行？凡是互不抢占 CPU 的组合，都可以并行。

第二步：逐项判断

组合分析可否并行
I. 进程与进程进程运行必须占用 CPU，同一时刻 CPU 只能执行一个进程不能
II. 处理机与设备CPU 计算时，设备可由控制器/通道驱动同时做 I/O能
III. 处理机与通道通道是独立于 CPU 的专用 I/O 处理机，能执行自己的通道程序能
IV. 设备与设备各设备相互独立（打印的同时可以读盘）能

进程与进程在单处理机上只能并发（宏观同时推进、微观交替执行），做不到同一时刻并行。

易错点

  • 把并发当并行：A、B、C 三个干扰项都含 I，只要认定"单处理机上进程之间不能并行"，即可全部排除。
  • 漏掉通道：误以为通道与处理机是"一家人"。通道恰是独立于 CPU 的 I/O 处理部件，与处理机并行工作，III 必须选入。
单处理机上唯一不能并行的是"进程与进程"，可并行的是 II、III、IV，选 D。
