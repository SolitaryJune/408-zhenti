本题讲解：x 翻倍循环的时间复杂度

答案：A（O(log₂n)）。

第一步：抓住循环变量的变化规律

代码只有一处改变状态：x = 2 * x，即 x 每执行一轮循环就翻一倍。初始 x = 2，逐轮跟踪：

第二步：用退出条件解出执行次数

循环条件是 x < n / 2，所以执行完 t 轮后停止，意味着 2 的 t+1 次方 ≥ n/2。两边同乘 2 得 2 的 t+2 次方 ≥ n，解得 t ≥ log₂n − 2。执行次数与 log₂n 只差常数，故时间复杂度为 O(log₂n)，选 A。

第三步：排除干扰项

  • B（O(n)）：需要循环变量每轮增加常数（如 x = x + 1），本题是翻倍，增长速度远快于线性。
  • C、D：程序片段中没有嵌套循环，O(nlog₂n) 与 O(n²) 无从谈起。

易错点

  • 把初值 2 当成无关信息：初值只影响常数项（t = log₂n − 2 中的 −2），不影响量级，但不能因此漏掉「从 2 到 n/2 需要翻多少次倍」这个主体推导。
  • 忽略退出条件是 n/2 而不是 n：这同样只差常数，但推导过程要写对；考场上先写 2 的 t+1 次方 ≥ n/2 再解，就不会错。
记忆锚点：循环变量每轮翻倍的循环，执行次数都是 O(log₂n)；每轮加常数才是 O(n)。
