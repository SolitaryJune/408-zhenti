本题讲解：TCP/IP 网络层提供什么服务

答案：A（无连接不可靠的数据报服务）

第一步：审清问的是哪一层

题目问的是 TCP/IP 参考模型的网络层，核心协议就是 IP。判断服务类型抓三个维度：

维度要问的问题
连接发分组前要不要先建立连接
可靠性有没有确认、重传、按序保证
交付方式数据报（独立分组）还是虚电路（先建虚连接）

第二步：IP 的工作方式

IP 把每个分组当作独立单位转发：发送前不建立连接，每个分组自带完整目的地址、独立选路——这就是无连接的数据报方式。同时 IP 不确认、不重传、不保证按序，只做"尽力而为"交付，因此是不可靠的。

第三步：逐项排除

  • B（无连接可靠的数据报服务）：无连接说得对，但"可靠"需要确认与重传机制，IP 没有——可靠性是传输层 TCP 的职责。
  • C、D（有连接……虚电路服务）：虚电路必须先建立虚连接、分组沿同一路径按序转发，这是 X.25 等网络的思路，TCP/IP 网络层从不建立连接。

易错点

  • 把 TCP 的可靠安到网络层头上：可靠传输由传输层 TCP 提供，网络层 IP 只管尽力而为。
  • 以为"数据报"就是可靠：数据报与虚电路只是交付方式，与可靠与否是两个独立维度。
一句话结论：TCP/IP 网络层（IP）= 无连接 + 不可靠 + 数据报，选 A。
