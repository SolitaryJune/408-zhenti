本题讲解：IEEE 754 单精度格式的解码与比较

答案：A（x < y 且符号相同）。

第一步：按 1 + 8 + 23 拆位段

单精度浮点数 = 1 位符号 + 8 位阶码（移码，偏置 127）+ 23 位尾数（隐含最高位 1）。

f1 = CC900000H = 1100 1100 1001 0000 …（低 16 位全 0）：

  • 符号位 = 1 → x 为负；
  • 阶码 = 1001 1001B = 153，真实指数 = 153 − 127 = 26；
  • 尾数 = 1.001B = 1.125 → x = −1.125 × 226，绝对值很大。

f2 = B0C00000H = 1011 0000 1100 0000 …：

  • 符号位 = 1 → y 也为负；
  • 阶码 = 0110 0001B = 97，真实指数 = 97 − 127 = −30；
  • 尾数 = 1.1B = 1.5 → y = −1.5 × 2−30，绝对值极小。

第二步：比较符号与大小

两者符号位都是 1 → 符号相同；同为负数时绝对值越大数值越小，|x| = 1.125 × 226 远大于 |y| = 1.5 × 2−30 → x < y。

易错点

  • 忘减偏置 127：阶码字段存的是移码（指数 + 127），153 要减 127 得 26，直接拿 153 当指数会差出天文数字。
  • 丢掉隐含的 1：尾数要补回隐含的最高位，1.001B 是 1.125 而不是 0.125。
  • 只看符号不比大小：两个都是负数，还须比较绝对值；226 与 2−30 悬殊，方向不会错。
记忆锚点：先拆 1+8+23，符号定正负、阶码减 127 定指数、尾数补 1 定有效数字，再按"负数绝对值大者小"比较。
