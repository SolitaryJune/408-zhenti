本题讲解：CDMA 叠加序列的解码（内积 + 规格化）

结论：答案 B（101）

CDMA 的解码规则：把收到的一段时间序列按码片长度分组，每组与某站点的码片序列逐位相乘再求和（内积），再除以码片数规格化：结果为 1 表示该站发了 1，为 0 表示发了 0，为 0 且无起伏则表示该站未发送。

第一步：切分序列

收到 12 个码片，码片长度 4 → 每个比特周期占 4 个码片，共 3 段：

段收到的 4 个码片
第 1 段(2, 0, 2, 0)
第 2 段(0, −2, 0, −2)
第 3 段(0, 2, 0, 2)

第二步：逐段与 A 的码片序列 (1,1,1,1) 做内积

段内积计算和规格化（÷4）A 发送的比特
12×1 + 0×1 + 2×1 + 0×1411
20×1 + (−2)×1 + 0×1 + (−2)×1−4−10
30×1 + 2×1 + 0×1 + 2×1411

A 发送的数据就是 1、0、1，即 101，选 B。

第三步：顺手验证（考试不必写）

用 C 的码片 (1,1,−1,−1) 检查第 1 段：2 + 0 − 2 − 0 = 0，规格化为 0 → C 在该周期未发送；B 的码片 (1,−1,1,−1) 对第 1 段：2 − 0 + 2 − 0 = 4 → B 发了 1。多站叠加的序列正是这样被各个码片序列"正交"分离的。

易错点

  • 忘记除以码片数规格化：内积和 4 / −4 要除以 4 才是 ±1；不过本题判断 1/0 只看正负号，答案不受影响，但书写过程要规范。
  • 切段出错：12 个码片必须切成 3 组、每组 4 个，从左往右顺序对应 3 个比特，不能打乱。
  • 把别站的比特当成 A 的：题目问的是 A，务必用 A 的码片序列 (1,1,1,1) 做内积，用错序列就会算出别的选项。
记忆锚点：CDMA 解码三步——切段、与目标站码片内积、除以码片数看正负：正→1，负→0，零→没发。
