本题讲解：TLB + 直写 Cache 下的访存次数推演

第一步：先给答案

答案：B（至少 1 次）。

第二步：拆解指令功能

add xaddr, 3 把地址 xaddr 所指单元的内容加 3 后写回。执行阶段对 x 有两次访问：

  1. 读操作数 x；
  2. 写回结果 x。

题问"完成该指令功能"的访存，不把取指令本身的访存计入；"至少"按最有利情形（TLB 命中、Cache 命中）。

第三步：两次访问逐一看

访问机制是否访主存
读 x：地址变换TLB 命中 → 直接得到物理地址，不查页表（页表在主存中）0 次
读 x：取数据Cache 命中 → 数据从 Cache 读出0 次
写 x：写回直写（Write Through）：写 Cache 时必须同时写主存，维持一致1 次

合计：0 + 1 = 1 次。

易错点

  • 误选 2 或 3：忘了 TLB 命中时查页表的那次主存访问被省掉（页表项在主存里，无 TLB 时每次地址变换都要访存一次）。
  • 误选 0：忘了"直写"的含义——写命中也要把数据同步写进主存，这一笔省不掉；只有回写方式才可能暂不访主存（仅置脏位）。
  • 混淆两种写策略：直写 = 每写必穿透主存；回写 = 换行淘汰时才写回。
直写 = 每次写都穿透到主存；TLB 命中 = 省掉查页表的访存；Cache 命中 = 省掉读数据的访存。
