本题讲解：哪条指令不可能触发"用户态 → 内核态"

答案：C（NOT R0）。

第一步：切态的唯一入口

CPU 从用户态切换到内核态，只有一条路：发生中断或异常（陷入内核，如系统调用、缺页、除零）。所以问题转化为——哪条指令绝不会产生异常或中断。

第二步：逐条指令排查

指令可能"出事"吗结果
DIV R0, R1除数为 0 → 除零异常可能陷入内核态
INT n软中断指令，执行即主动陷入必然进入内核态
NOT R0只对寄存器取反：不访存、不除零，不产生任何异常/中断不可能切态
MOV R0, addr访问内存：可能缺页、地址越界可能陷入内核态

第三步：锁定答案

NOT R0 是纯寄存器操作，无论 R0 是什么值都能顺利执行完，不会触发任何事件 → 不可能引起用户态到内核态的切换，选 C。

易错点

  • 误选 A：以为除法一定能正常执行——除数恰为 0 时硬件抛出异常，照样切态。
  • 漏掉 D：访存指令在请求分页系统中可能缺页，缺页异常正是进入内核的典型入口；地址越界同样如此。
  • 核心判据：会不会切态，看这条指令会不会"出事"（异常/中断），与指令常用与否无关。
记忆锚点：纯寄存器运算（不访存、无除法的算逻指令）不会产生中断/异常，不引起态转换。
