本题讲解：SCAN（电梯）调度的磁头移动道数

答案：C（325）。

第一步：SCAN 规则与本题方向

SCAN 像电梯：磁头沿当前方向一路服务请求，直到该方向的尽头（盘边）再折返。题目：最外侧为 0 号磁道，磁头在 58 号并从外向内移动 → 先沿磁道号增大方向服务，到最内侧 199 再折返。

第二步：按方向排请求

  • 内侧方向（≥ 58）：130, 180, 199；
  • 折返后外侧方向（< 58）：42, 15。

第三步：逐段累加移动道数

移动段距离累计
58 → 130（服务 130）7272
130 → 180（服务 180）50122
180 → 199（服务 199，到达最内侧端）19141
199 → 42（折返向外，服务 42）157298
42 → 15（服务 15）27325

总移动 = (199 − 58) + (199 − 15) = 141 + 184 = 325 个磁道 → 选 C。

易错点

  • 漏算最后一段：服务完 42 后还有请求 15，必须继续移到 15；只累加到 42 会得 298。
  • 折返点搞错：SCAN 要到盘边（本题最内侧 199）才折返——199 恰好既是请求又是端点；若误在 180 折返或按"就近跳"处理，路线全错。
  • 方向搞反：最外侧是 0 号磁道，"从外向内" = 磁道号增大方向；若当成先去 42、15，整条路线都会错。
记忆锚点：SCAN = 当前方向服务到盘边再折返；总移动按段累加 |终点 − 起点|。
