本题讲解：POP3 建立在哪种传输层服务之上

答案：D（有连接、可靠的数据传输服务）。

第一步：给应用层协议「配」传输层

传输层只有两个候选：TCP（面向连接、可靠、字节流）与 UDP（无连接、不可靠、报文）。应用层协议选谁，取决于它对「不丢、不乱、不重」的要求。

第二步：看收邮件场景

POP3 用于用户从邮件服务器读取邮件：账号口令、邮件内容都不允许丢失或出错，必须可靠送达，因此 POP3 运行在 TCP 之上。TCP 先经三次握手建立连接（有连接），再靠确认与重传保证可靠性。

第三步：排除干扰项

  • A（无连接不可靠）：这是 UDP 的特征，邮件协议不采用。
  • B（无连接可靠）：自相矛盾，无连接的 UDP 谈不上可靠交付。
  • C（有连接不可靠）：传输层的标准组合里没有这一对——面向连接的 TCP 恰恰以可靠交付为核心。

易错点

  • 以为邮件收发用 UDP：邮件三兄弟 SMTP / POP3 / IMAP 全部基于 TCP；UDP 的典型用户是 DNS、DHCP、实时音视频。
  • 把「有连接/无连接」与「可靠/不可靠」随意配对：记住 TCP = 有连接 + 可靠，UDP = 无连接 + 不可靠，另外两种组合是干扰项惯用套路。
记忆锚点：收邮件（POP3）= TCP = 有连接 + 可靠，选 D。
