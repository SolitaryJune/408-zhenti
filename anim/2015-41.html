本题讲解：单链表按绝对值去重（以空间换时间）

第 0 步：先立机制——去重的本质是"在线的成员查询"

整道题反复回答的其实只有一个问题：当前结点的绝对值，前面出现过没有？ 判断"出现过没有"有两条路：

  • 两两比较：每个结点都要和它前面的所有结点比一遍，时间 O(m²)——题目要求"时间尽可能高效"，这条路被排除；
  • 桶登记：题给 |data| ≤ n，绝对值只可能取 0~n 这 n+1 种值——值域有限，就可以开一个 n+1 的数组当"签到表"，绝对值当下标，登记与查询都是 O(1)。

为什么保留的一定是第一次出现的结点：扫描从链头到链尾单向进行，一个绝对值第一次被遇到时签到表还是 0，结点被保留并登记；此后再遇到，签到表已是 1，一律摘链删除——"先到先登记"天然保证了保留的是首次出现。

为什么一趟扫描就够：每个结点只需查一次表，而签到表随扫描即时更新，既不用回头看已处理部分，也不用预先知道全表内容。

问题（1）：算法的基本设计思想

按第 0 步的机制落笔：申请大小为 n+1 的辅助数组 q（下标对应绝对值 0~n），全部初始化为 0；从头到尾只扫描链表一趟，对每个结点取 m = |data|——q[m] = 0 说明首次出现，保留结点并置 q[m] = 1；q[m] = 1 说明重复，修改前驱的 link 摘链并 free。用 O(n) 空间把"判断是否重复"变成 O(1) 查表，总时间从 O(m²) 降到 O(m)，这就是以空间换时间。

示例（即题图）：21 → 15 → 15 → −7 → 15 去重后为 21 → 15 → −7——第二个 15 与末尾的 15 都是重复，−7 的绝对值 7 是首次出现故保留。

问题（2）：结点数据类型定义

  • 结点结构：typedef struct node { int data; struct node *link; } NODE;——data 存整数（|data| ≤ n），link 指向后继；
  • 指针别名：typedef NODE *PNODE;

问题（3）：算法描述（与参考答案一致的 C 语言实现）

  1. 函数入口：void func(PNODE h, int n)，h 指向链表的头结点；
  2. 申请辅助空间：q = (int *)malloc(sizeof(int) * (n + 1));——n+1 个单元，下标 0~n 正好覆盖全部可能的绝对值；
  3. 初始化：用 for 循环把 q[0..n] 全部置 0（*(q + i) = 0;）；
  4. 一趟扫描：while (p->link != NULL)，取绝对值 m = p->link->data > 0 ? p->link->data : -p->link->data;；
  5. 若 *(q + m) == 0：首次出现——登记 *(q + m) = 1; 并保留结点 p = p->link;；
  6. 否则重复出现：r = p->link; p->link = r->link; free(r);——此时 p 不动，继续检查新的 p->link；
  7. 扫描结束后 free(q); 释放辅助数组。

为什么删除结点时 p 必须原地不动：p 始终指向"已处理部分的最后一个结点"，待检查的是 p->link。摘链后 p->link 指向的是还没检查过的新结点；若再执行 p = p->link，这个新结点就被跳过了。只有保留结点（p = p->link）时，p 才前进一格。

问题（4）：时间与空间复杂度

链表从头到尾扫一遍，每个结点只做常数次操作（查一次表、至多摘一次链）：时间复杂度 O(m)（m 为链表结点数）；辅助数组占 n+1 个单元：空间复杂度 O(n)（n 为给定的绝对值上限）。

易错点

  • 删除结点时让 p 后移：p->link 已换成未检查的新结点，再后移会漏检一个结点——删除分支里 p 必须原地不动（机理见第（3）问）。
  • 用两重循环两两比较：空间 O(1) 但时间 O(m²)，违背"时间尽可能高效"的题眼；本题的空间换时间正是为了避免它。
  • 辅助数组开成 n 而不是 n+1：|data| ≤ n 意味着绝对值可以取到 n，下标要覆盖 0~n 共 n+1 个值，少开一个会越界。
  • 忘记释放 q：算法结束前应 free(q)，避免内存泄漏。
记忆锚点：值域有限 → 桶数组签到；从前往后扫、先登记后查询 → 自然保留首次出现；删除时 p 不动、保留时 p 才走；时间 O(m)、空间 O(n)。
