本题讲解：判断哪一个不是深度优先搜索序列

答案：D。

第一步：把图读成邻接表

从配图（有向图）读出各顶点的出边：

顶点能直接到达
V1V2, V3, V5
V2V5
V3V2
V4V3
V5V4

第二步：明确 DFS 的行进规则

从 V1 出发的深度优先搜索：每访问一个顶点，下一步只能沿它的出边走向一个尚未访问的邻接点；四周无未访问邻接点时才回溯。序列中相邻两顶点之间必须有边相连。

第三步：逐项检验

  • A：V1, V5, V4, V3, V2 —— V1→V5、V5→V4、V4→V3、V3→V2，步步有边，合法。
  • B：V1, V3, V2, V5, V4 —— V1→V3、V3→V2、V2→V5、V5→V4，步步有边，合法。
  • C：V1, V2, V5, V4, V3 —— V1→V2、V2→V5、V5→V4、V4→V3，步步有边，合法。
  • D：V1, V2, V3, V4, V5 —— V1→V2 可行，但 V2 的出边只有 V2→V5，V2 与 V3 之间没有边，DFS 不可能从 V2 直接访问 V3，非法。

（V3 只能由 V1 或 V4 进入，而 V4 又必须等 V5→V4 之后，所以 V1、V2 之后只能是 V5，那正是选项 C 的走法。）

易错点

  • 把 DFS 当成按编号顺序访问：DFS 严格沿边走，不按顶点编号推进，D 恰是这个误区。
  • 忽略边的方向：图里是 V3→V2、V5→V4，方向看反就会误判 D 合法。
  • 只查“有没有边”不查方向：无向图的序列检查与有向图不同，本题是有向图。
记忆锚点：判 DFS 序列，就逐对检查“相邻两顶点之间有没有方向正确的边”。
