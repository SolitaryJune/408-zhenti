本题讲解：异常与中断的归属判断

答案：A（"访存时缺页属于中断"错误）。

第一步：抓住题干给的判据

题干已给出定义：异常 = 指令执行过程中在处理器内部发生的特殊事件（内中断）；中断 = 来自处理器外部的请求事件（外中断）。对每个事件只需回答一个问题：它由谁、在哪儿引发？

第二步：逐项归位

事件发生位置归属判定
访存时缺页执行访存指令查页表时，由处理器内部（MMU/页机制）发现异常（故障类）A 说成中断，错误 → 选它
整数除以 0执行除法指令时处理器内部检测异常B 正确
DMA 传送结束DMA 控制器（外设一侧）向 CPU 发请求中断C 正确
存储保护错指令执行中处理器内部检测出越权访问异常D 正确

第三步：为什么缺页不是中断

缺页不是某个外部设备"请求"CPU，而是 CPU 执行访存指令、查页表时发现页不在内存，由指令执行本身引发——完全符合"处理器内部发生"的异常定义（且属于可修复、可返回重执行的故障类异常）。

易错点

  • 把缺页当外部事件：看到"访存"联想到内存在 CPU 外面，就误判为中断——判断标准是事件由谁引发，不是部件的物理位置。
  • 混淆 DMA 结束与传送过程：DMA 传送由控制器独立完成，结束时才向 CPU 发一次请求，这是典型的外中断。
  • 记成"除 0 是中断"：除 0 由正在执行的除法指令触发，是异常的教科书例子。
一句话判据：指令执行在 CPU 内部引发的 → 异常；外部设备发来的请求 → 中断。
