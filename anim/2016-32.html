本题讲解：管程的四个说法逐个辨

第一步：管程是什么

管程把共享数据结构 + 对它的操作过程 + 初始化代码封装成一个模块；互斥由编译器自动保证（同一时刻至多一个进程在管程内执行），并提供条件变量的 wait/signal 实现同步等待与唤醒。

第二步：逐项判断

  • A 错误（本题答案）：管程既能实现互斥（天然互斥进入），也能实现同步（条件变量阻塞/唤醒），"只能用于实现互斥"以偏概全。
  • B 正确：管程是编程语言级的同步机制，由编译器生成进入/退出代码（如 Java 的 synchronized），不靠程序员手工 PV。
  • C 正确：任何时候只允许一个进程在管程中执行，这是管程互斥性的体现。
  • D 正确：管程内的数据被封装，只能被管程内定义的过程访问，外界不能直接操作。

易错点

  • 把互斥当成管程的全部功能：漏掉同步能力，A 项的陷阱所在。
  • 把管程与信号量混为一谈：信号量机制靠程序员手工 P/V 操作；管程的互斥同步是语言级自动保证的。
答案：A。管程 = 语言级封装的共享数据 + 过程，天然互斥、又可通过条件变量同步。
