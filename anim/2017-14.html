本题讲解：二重循环访问数组的局部性判断

第一步：分清两种局部性

时间局部性：刚被访问的数据很快又被再次访问；空间局部性：与其相邻地址的数据被顺序访问。代码中外层 i 控制轮数，内层 j 从 0 扫到 i，依次访问 a[j]。

第二步：分别找证据

外层轮次内层访问序列体现的局部性
i=0a[0]首次访问
i=1a[0]、a[1]a[0] 重访 = 时间；a[1] 紧跟 a[0] = 空间
i=2a[0]、a[1]、a[2]前两个重访 = 时间；a[2] 顺序后延 = 空间
  • 内层循环对 a[0..i] 按下标递增连续扫描 → 空间局部性。
  • 外层每加 1，上一轮刚访问过的 a[0..i] 又被完整重扫一遍 → 时间局部性。

第三步：结论

两种局部性皆有，答案：A。

易错点

  • 只看内层顺序访问：漏掉跨外层循环的重复访问，会误选 B（无时间局部性）。
  • 只看重复访问：漏看内层的连续扫描，会误选 C。
  • 混淆定义：时间局部性看"同一数据重复用"，空间局部性看"相邻地址顺序用"。
记忆锚点：顺序扫描给空间局部性，重复扫描给时间局部性，本程序两样都占。
