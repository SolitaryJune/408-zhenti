本题讲解：滑动窗口的窗口大小约束

答案：B（3）

第一步：算出序号空间

分组序号采用 3 bit 编号，可提供 2^3 = 8 个不同序号（0～7）。序号是循环使用的，所有窗口约束都来自一句话：新旧帧不能共用同一序号而不被察觉。

第二步：写出总约束式

滑动窗口协议（后退 N 帧、选择重传都满足）的一般约束是：

发送窗口 W_S + 接收窗口 W_R ≤ 2^n

若两窗口之和超过序号空间，接收窗口就会与发送窗口在序号空间上"重叠"：发送方超时重传的旧帧落入接收窗口内，会被当成新帧收下，造成重复接收。

第三步：代入求最大接收窗口

已知 W_S = 5，n = 3，则 W_R ≤ 8 − 5 = 3，即接收窗口最大是 3，选 B。

参数值
序号空间 2^38
发送窗口 W_S5
接收窗口最大 W_R8 − 5 = 3

易错点

  • 套用选择重传的对称公式 W_R ≤ 2^(n-1) = 4：误选 C 的来源。2^(n-1) 只在发送窗口也取到最大时才成立；本题发送窗口已固定为 5，必须用总量约束 8 − 5 = 3。
  • 以为接收窗口只能为 1：那是后退 N 帧协议（GBN）的特例，题目问的是滑动窗口协议的一般情形。
  • 忘记扣掉发送窗口：直接把序号空间 8 当成答案（同类题的常见干扰项）。
序号 3 bit → 空间 8；W_S + W_R ≤ 2^n → 8 − 5 = 3，选 B。
