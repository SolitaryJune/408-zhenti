本题讲解：哲学家就餐变体（碗 + 筷子）的信号量设计

第 0 步：先立模型——死锁是怎么形成的，才能对症下药

经典 n 位哲学家、n 根筷子的死锁机制：每人先抓起左手一根筷子 → n 根筷子全被占 → 每人都阻塞在等右手的筷子，而那根筷子在邻居手里、邻居也在等他——"持有并等待"连成一个环（循环等待条件成立），谁也不放手，全体永远等下去。

对症思路：不让 n 个人同时进入"各持一根筷子"的状态。本题的新道具是 m 个碗——规定"先拿到碗，才有资格去拿筷子"，并把碗的名额限制在 n−1 以内。于是任何时刻至多 n−1 人在竞争筷子，而筷子有 n 根，由鸽笼原理：这 n−1 人中总有人能同时抓到左右两根 → 至少一人能就餐、吃完归还 → 循环等待无法成环。这就是 bowl 信号量的全部使命。

第一步：信号量及初值（与参考答案同口径）

  • chopstick[i]（i = 0,1,…,n−1）：互斥信号量，表示第 i 根筷子，初值均为 1（一根筷子一次只许一人用）。
  • bowl：资源信号量，表示允许同时"取碗进餐"的名额数，初值为 min(m, n−1)。

为什么初值取 min(m, n−1)：m 是碗的物理上限，n−1 是防死锁的上限，名额取两者较小者。碗多（m ≥ n−1）时起作用的是 n−1，把竞争筷子的人数压到 n−1 以内；碗少（m < n−1）时起作用的是 m，能就餐的人数更少，死锁更无从谈起。两种情况都安全，且名额不打折扣地用满。

第二步：写出 Pi 的流程（与参考答案同口径）

semaphore chopstick[n];   // 初值全 1
bowl = min(m, n-1);

Pi:
while (true) {
    think;
    P(bowl);                    // 先拿"入场券"
    P(chopstick[i]);            // 取一侧筷子
    P(chopstick[(i+1) % n]);    // 取另一侧筷子
    eat;
    V(chopstick[i]);            // 先还筷子
    V(chopstick[(i+1) % n]);
    V(bowl);                    // 最后还名额
}

为什么 P(bowl) 必须在最前：先拿"入场券"再碰筷子。若反过来先 P 筷子再 P 碗，可能出现 n 人各持一根筷子后一起在 bowl 上排队，拿到 bowl 的人互相等对方的筷子——死锁照旧。先拿碗，才把竞争筷子的人数从根本上压到 n−1 以内。

为什么两根筷子不需要"先左后右"的全局顺序：经典问题的奇偶/统一方向解法是为了破循环等待；这里破环的任务已交给 bowl，先拿哪根都安全，参考口径即先 chopstick[i] 后 chopstick[(i+1)%n]。

为什么 V 的顺序是先筷后碗：V 操作不阻塞、不会死锁，先还筷子能让邻座尽快凑齐两根开饭；最后 V(bowl) 归还名额并唤醒一位等待者。P、V 一一对应，名额不会泄漏。

第三步：验证题目两个目标

  • 防死锁：就餐者 ≤ min(m, n−1) ≤ n−1 < n，鸽笼原理保证总有人能同时拿到两根筷子，循环等待成不了环。
  • 尽可能多就餐：名额 = min(m, n−1)，碗不少占、名额不闲置，能同时就餐的人数达到安全前提下的最大值。

易错点

  • 只设筷子信号量、不设 bowl：n 人各抓一根筷子照样全体阻塞，经典死锁原样重现。
  • bowl 初值直接写 m：m ≥ n 时限流失效，n 人可同时持筷，防死锁没有保障。
  • 先 P 筷子后 P 碗：持筷等碗，循环等待未被破坏。
  • 漏掉某个 V 或 P/V 不对应：名额/筷子泄漏，最终无人能再就餐。
一句话锚点：chopstick[n] 初值 1 管互斥，bowl 初值 min(m, n−1) 管限流；先拿碗后拿筷是破环的关键——把"n 人抢 n 根筷"压成"≤n−1 人抢 n 根筷"，鸽笼原理兜底。
