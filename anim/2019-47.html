本题讲解：小型局域网的设备选型、地址规划与广播

答题框架：四问分别对应「互连设备工作在哪个层次 → 路由器接口配什么 IP → 私有地址上网靠什么服务 → 直接广播地址能传多远」。逐问拆解如下。

第 (1) 问：三个设备各选什么类型

  • 设备 1 选路由器：它左侧连路由器 R 的接口（网段 192.168.1.252/30），右侧分出 LAN1（192.168.1.0/26）与 LAN2（192.168.1.64/26）两个不同子网。连接不同网络、需要按 IP 目的网络转发分组，必须用网络层设备——路由器。
  • 设备 2、设备 3 选以太网交换机：它们只在各自 LAN 内连接主机与上级接口，同一子网内按 MAC 地址透明转发帧即可。

第 (2) 问：哪几个接口要配 IP，怎么配

交换机工作在数据链路层，按 MAC 转发帧，不需要配置 IP；路由器每个接口都属于一个网络，必须配置与所连网段同网的 IP：

接口所连网段应配 IP
设备1 IF1与 R 相连的 /30 链路（R 端为 192.168.1.253/30）192.168.1.254
设备1 IF2LAN1：H1 .2/26、H2 .3/26，默认网关 .1192.168.1.1
设备1 IF3LAN2：H3 .66/26、H4 .67/26，默认网关 .65192.168.1.65

IF1 的算路：/30 网段为 192.168.1.252～255，可分配的只有 .253 与 .254，R 已占用 .253，故 IF1 = 192.168.1.254。所以只有设备 1 的接口需要配置 IP 地址。

第 (3) 问：R 需要提供什么服务

内网全部使用 192.168.1.0/24 的私有地址，这类地址在 Internet 上不可路由。要让 H1～H4 访问 Internet，R 必须提供 NAT（网络地址转换） 服务：出流量把私有地址转换为公网地址（101.1.2.10 对应接口），回程流量再反向转换回来。

第 (4) 问：目的地址 192.168.1.127 谁接收

H3 的地址 192.168.1.66/26 属于子网 192.168.1.64/26，该子网主机位全 1 的直接广播地址正是 192.168.1.127。发往它的数据报只在 LAN2 内以广播帧扩散：

  1. 路由器（设备 1）隔离广播域，不向 LAN1 转发 → H1、H2 收不到；
  2. H3 是发送方，不接收自己发出的数据报；
  3. 同一子网内的另一台主机 H4 会接收该数据报。

易错点

  • IF1 配成 .253：那是 R 的地址；/30 里只剩 .254 可用。
  • 给交换机接口配 IP：无 VLAN 的以太网交换机是链路层设备，接口无 IP。
  • 第 (4) 问答成 H3、H4 都收：发送方不接收自己的广播帧；若再答上 H1/H2，则是忽略了路由器隔离广播域。
设备 1 = 路由器，设备 2/3 = 以太网交换机；IF1 192.168.1.254、IF2 192.168.1.1、IF3 192.168.1.65；R 提供 NAT；只有 H4 接收。
