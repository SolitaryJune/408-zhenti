本题讲解：中断 I/O 方式的特点与适用条件

第一步：中断 I/O 的工作方式

CPU 启动外设后不再空等，转去执行其他程序；外设把数据准备好后向 CPU 发中断请求，CPU 响应后在中断服务程序里用 I/O 指令把数据取走——数据传送由软件（程序）完成。适合键盘、针式打印机等中低速字符型设备。

第二步：逐项核对

选项判断理由
A 适用于键盘、针式打印机等字符型设备正确中低速、数据量小、随机性强，正合适
B 数据传送通过软件完成正确传送靠执行中断服务程序（软件），没有 DMA 硬件通路
C 外设准备数据的时间应小于中断处理时间不正确方向反了：应大于中断处理时间
D 外设准备数据时 CPU 可运行其他进程正确CPU 与外设并行，这正是中断方式的优点

第三步：为什么 C 错

中断 I/O 要高效，须保证 CPU 执行完一次中断服务后，外设的下一个数据刚好备好——即外设准备数据的时间应大于 CPU 的中断处理时间。若外设准备更快，CPU 服务不过来，只能等待或造成数据覆盖/丢失，中断方式就不适用了。

答案：C。

易错点

  • 把"大于"记成"小于"：外设慢、CPU 快，"准备时间小于处理时间"意味着 CPU 来不及取。
  • 以为传送靠硬件：中断 I/O 的传送仍由软件逐字/逐字节完成，靠硬件通路的是 DMA。
一句话结论：中断 I/O 适合中低速设备、软件传送、CPU 可并行；约束是外设准备时间大于中断处理时间，选 C。
