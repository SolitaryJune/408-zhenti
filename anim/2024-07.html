本题讲解：二叉搜索树中子树的取值范围

第一步：认清树形

题 7 图：k1 是根，k2 是 k1 的右孩子，k3 是 k2 的左孩子，子树 T 是 k3 的右子树。T 中任一关键字 x 同时受路径 k1 → k2 → k3 → T 上所有祖先的约束。

第二步：逐站收集约束

BST 性质在子树中的传递规则：T 在某结点的右子树里 ⇒ x > 该结点关键字；在左子树里 ⇒ x < 该结点关键字。

站点方向得到的约束
k1T 在其右子树x > k1
k2T 在其左子树x < k2
k3T 在其右子树x > k3

第三步：合并取最紧

下界取较大者：k3 与 k1 中，k3 在 k1 的右子树里必满足 k3 > k1，故更紧的下界是 k3；上界只有 k2。所以 k3 < x < k2（自动涵盖 x > k1），答案选 D。

代入数字自检：k1=20、k2=50、k3=30，T 中关键字须 >30 且 <50，如 40；若选 C（20<x<30）则 40 被排除，明显矛盾。

易错点

  • 选 A（x<k1）：只看到 k1 是根，忘了 T 挂在 k1 的右子树里。
  • 选 B（x>k2）：忽略了 k3 → T 这一站 T 在 k2 的左子树内。
  • 选 C：把 x 与 k3 的不等号方向写反，且「最紧下界取较大者」没做。
一句话结论：右转抬下界、左转压上界，最紧约束是 k3 < x < k2，选 D。
