本题讲解：四类"指令"中 CPU 能直接执行的是哪些

答案：B（仅 II、III）

第一步：先立判据——CPU 硬件只认二进制编码

CPU 的取指-译码-执行电路只能处理二进制编码：ISA 层的机器指令、更底层的微指令都是这种编码；而汇编层面的伪指令、汇编指令是写给汇编程序看的符号文本，CPU 硬件"看不懂"文本，必须先翻译成二进制。这就是"能/不能直接执行"的分界线。

第二步：四类对号入座

  • III 机器指令：ISA 层的二进制编码，CPU 直接译码、执行 → 可以。
  • II 微指令：存放在 CPU 内部控制存储器里的二进制控制码，控制器逐条取出、直接产生控制信号序列 → CPU（控制部件）能直接执行。
  • IV 汇编指令：机器指令的助记符文本。它与机器指令一一对应，但"直接执行"发生在翻译之后，CPU 不理解助记符 → 不算。
  • I 伪指令：连机器码都不生成，只是指示汇编程序做展开、分配存储等处理 → 更不能直接执行。
名称所在层面谁来"理解"它
伪指令汇编源程序汇编程序（翻译/展开，不生成对应机器码）
汇编指令汇编源程序汇编程序（翻译成机器指令）
机器指令机器（ISA）级CPU 直接译码、执行
微指令控制器（微程序级）控制器从控存逐条取出执行

易错点

  • 选 C 或 D（把汇编指令算进去）：汇编指令与机器指令一一对应，但 CPU 直接执行的对象是翻译后的二进制，不是符号文本。
  • 漏掉微指令：微指令虽在微体系结构层，但由控制器硬件直接执行，符合题意。
  • 把伪指令当指令：题干已说明"将指令序列定义成一条伪指令"——它是给汇编器的宏式缩写，CPU 没有对应的硬件动作。
一句话结论：汇编层面的"指令"（伪指令、汇编指令）都要先过汇编程序这道关；机器指令由 CPU 直接执行，微指令由控制器直接执行——选 B。
