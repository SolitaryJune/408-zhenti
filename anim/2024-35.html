本题讲解：VLAN 隔离广播域，ARP 表只会有同 VLAN 主机

答案：D（192.168.3.129 那条不可能出现）。

第一步：先立机制——ARP 表项从哪来，VLAN 挡住了什么

ARP 表靠广播建立：主机对某 IP 发 ARP 请求帧，请求在本广播域内泛洪，对应主机回 ARP 应答，双方把「IP，MAC，TTL」记入各自 ARP 表。VLAN 按端口把交换机切成多个广播域：广播帧（含 ARP 请求）只在同一 VLAN 内扩散，不同 VLAN 之间二层不通。所以 H4 的 ARP 表里只可能出现与它同 VLAN 主机的表项——判断每台主机的 VLAN 归属即可。

第二步：读图确定各主机的 VLAN

交换机按端口划分 3 个 VLAN：VLAN1 含端口 1～5 与 13～17；VLAN2 含端口 6～8 与 18～20；VLAN3 含端口 9～12 与 21～24。

第三步：逐项核对

  • A = H2（VLAN1）：可能出现
  • B = H1（VLAN1）：可能出现
  • C = H3（VLAN1）：可能出现
  • D = H6（VLAN3）：ARP 广播到不了 VLAN3，不可能出现，选 D。

易错点

  • 按 IP 同网段误判：192.168.3.129 与 H4 的地址在同一 IP 网段，但被 VLAN 隔离，二层仍不可达，ARP 广播到不了 H6。
  • 只看 MAC 不查端口：D 的 MAC 属于接入端口 9 的 H6，端口 9 属 VLAN3。
  • 被 TTL 干扰：TTL 只是 ARP 表项的老化时间，与"会不会出现"无关。
一句话结论：VLAN 隔离广播域，H4 的 ARP 表只含 VLAN1 主机（H1、H2、H3），H6 属 VLAN3 不可能出现，选 D。
