本题讲解：非持久 HTTP/1.0 串行取 8 个对象的 RTT 数

答案：D（16 个 RTT）。

第一步：数对象、明规则

1 个 Web 页 + 页中引用的 7 个图像 = 8 个对象。非持久 HTTP/1.0：每请求一个对象都要新建一条 TCP 连接，用完即断；浏览器不支持并行 TCP 连接，8 个对象只能串行获取。

第二步：算单个对象需要的 RTT 数

每个对象：TCP 三次握手 1 RTT + HTTP 请求与响应 1 RTT = 2 RTT。题干从"为传输 Web 页请求建立 TCP 连接"起算，第一次握手的前半个 RTT 正好落在第一个"建连 1 RTT"内。

第三步：逐对象累计

对象本对象耗时累计 RTT
Web 页本身2 RTT2
图 12 RTT4
图 22 RTT6
………
图 72 RTT16

共 8 × 2 = 16 个 RTT，选 D。

易错点

  • 误选 B（9）：把每个对象只算 1 个 RTT，漏掉了每个对象都要付一次 TCP 建连的 1 RTT。
  • 误选 C（14）：只算 7 个图像、漏掉 Web 页本身（7 × 2 = 14）。
  • 误选 A（4）：按持久连接或并行连接的思路算——题目明确是"非持久"且"不支持并行 TCP 连接"。
一句话结论：8 个对象 × 每对象 2 RTT（建连 1 + 请求响应 1）= 16 RTT，选 D。
