📝 文字讲解与动画配套的完整讲解

本题讲解：相似关系经得起哪些运算（转置是个例外）

答案：C

第 0 步：先立机制——相似就是"同一变换换基看"

$A\sim B$ 的全部内容：存在可逆 $P$ 使 $A=P-1BP$。$P$ 是换基矩阵，$A,B$ 是同一个线性变换在不同基下的坐标。于是判断"对 $A,B$ 同做某运算后还相似吗"，只看一件事：该运算还能否用同一个 $P$ 贯穿成 $P-1(\cdot)P$ 的形状。取逆、乘方、多项式组合是"整块"运算，$P$ 直接穿过；转置会把矩阵"翻面"，$P$ 被翻成 $PT$，与原来的 $P$ 一般不配对——这就是 C 要出事的机制根源。（题干强调 $A,B$ 可逆，是为了让选项 B、D 里的 $A-1,B-1$ 有意义。）

第一步：逐项过"同一个 P"的关

  • B 成立：$A-1=(P-1BP)-1=P-1B-1P$，同一 $P$。
  • D 成立：$A+A-1=P-1BP+P-1B-1P=P-1(B+B-1)P$，同一 $P$ 直接提出；同理 $Ak$ 与 $Bk$、任何多项式 $h(A)$ 与 $h(B)$ 都相似。
  • A 成立：$AT=(P-1BP)T=PTBT(PT)-1$。转置确实换走了 $P$，但这是整体翻面，可取 $Q=(PT)-1$，则 $AT=Q-1BTQ$，仍相似。
  • C 不成立：$A+AT=P-1BP+PTBT(PT)-1$——一半用 $P$、一半用 $PT$，两套基拼不回一起，提不出 $P-1(B+BT)P$，一般不相似。

第二步：给 C 造反例钉死

取 $B=\begin{pmatrix}1&0\\0&2\end{pmatrix}$，$P=\begin{pmatrix}1&1\\0&1\end{pmatrix}$，则 $A=P-1BP=\begin{pmatrix}1&-1\\0&2\end{pmatrix}$。

$$A+AT=\begin{pmatrix}2&-1\\-1&4\end{pmatrix},\ \det=7;\qquad B+BT=\begin{pmatrix}2&0\\0&4\end{pmatrix},\ \det=8.$$

相似矩阵必同行列式，$7\ne8$，C 确实不成立，选 C。

易错点

  • 以为转置也共享 $P$：把 $(P-1BP)T$ 粗心写成 $P-1BTP$——转置的"逆序 + 翻面"正是 C 陷阱的全部机关。
  • 没看清问法：本题找"错误的结论"，A/B/D 都是真命题，选了它们就反向了。
  • 对 A 选项犹豫："换 $P$"与"不相似"不是一回事——$AT,BT$ 之间可以用新矩阵 $Q=(PT)-1$ 配对；出事的是"一半 $P$、一半 $PT$"的混搭。
结论：逆与多项式共享同一个 $P$；转置翻面换走 $P$，混搭（$A+AT$）即散架，选 C。
