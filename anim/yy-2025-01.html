📝 文字讲解与动画配套的完整讲解

本题讲解：2025 完形第 1 空 · 指代衔接 · this + 名词回指上句

答案：D（question 问题；困惑）。

第 0 步：先立机制——this + 名词是一道「回指路标」

指代衔接题不能盯着空格所在的半句猜。this + 名词是英语里的回指路标：它指向上一句刚说完的内容，并用空格处的名词给那个内容「归类命名」。所以解题顺序固定两步：先回上一句弄清 this 指什么，再问「这件事是一个 ____？」——词义辨析只是最后的筛选器。

第 1 步：定位原文，抽证据

There are many understandable reasons why you might find it difficult to ask for help when you need it. Psychologists have been interested in this __1__ for decades, not least because people's widespread __2__ to ask for help has led to some high-profile failures.

空格句说：心理学家几十年来一直对这个 ____ 感兴趣。对「什么」感兴趣？本句自己答不了，必须看上一句：①句提出一个完整的问题——为什么你需要帮助时，却难以开口求助（why 引出的疑问内容）。this + 单数可数名词，正好把这件事归类为「一个问题」。

第 2 步：对号入座：四个选项逐个上桌

选项词义判定理由
A illusion幻想；错觉✗ 排除①句说求助难有「合情合理的原因」（understandable reasons），是真实存在的心理现象；上文没有任何「幻觉」信息。
B discussion讨论；商讨✗ 排除interested in this discussion =「对这场讨论感兴趣」，但上文没有任何「讨论」发生；心理学家感兴趣的是①句提出的问题本身。
C tradition传统；风俗✗ 排除全文谈求助的心理障碍，与「传统」毫无信息复现；this 的回指对象是①句的疑问内容。
D question问题；困惑✓ 当选this question 回指①句提出的「为什么求助难」这一问题；be interested in this question 语义与搭配都咬合。

易错点：每个干扰项对应哪种误解

  • 把「开口求助难」当成一种错觉 → 误选 A（illusion）：①句说求助难有「合情合理的原因」（understandable reasons），是真实存在的心理现象；上文没有任何「幻觉」信息。
  • 把「对……感兴趣」脑补成「讨论过这个话题」 → 误选 B（discussion）：interested in this discussion =「对这场讨论感兴趣」，但上文没有任何「讨论」发生；心理学家感兴趣的是①句提出的问题本身。
  • 只看搭配顺口，不核对 this 的回指内容 → 误选 C（tradition）：全文谈求助的心理障碍，与「传统」毫无信息复现；this 的回指对象是①句的疑问内容。
记忆锚点：this + 名词 = 给上句内容「贴标签」：先回上一句找到「这」指什么，再选名词归类——question 正是「为什么求助难」的归类。
