本题讲解：难民危机的"根本原因"怎么定位

答案：B（中东地区战乱、冲突和动荡加剧）。

第 0 步：先立机制——"根本原因"问的是难民从哪里来

2015 年欧洲难民危机要拆成两问：①难民为什么产生（产生侧）；②危机为什么在欧洲凸显、为什么难处理（接收侧）。设问"难民数量增长的根本原因"，指向产生侧的深层动因——什么力量让民众大规模流离失所、被迫外逃。

由此确立判别尺度：根本原因须是长期、整体、结构性的层面；一个具体组织的一次具体行为够不上"根本"，接收方的能力与意愿更不在产生一侧。尺度立好，四个选项变成查表。

第 1 步：把四个选项挂到模型上

选项侧别 / 层次判断
A 极端组织"伊斯兰国"驱逐民众产生侧的下位具体表现是诱因之一，够不上"根本"
B 中东地区战乱、冲突和动荡加剧产生侧的整体动因✅ 根本原因
C 美国等发达国家无力接收大量难民接收侧（且"无力"表述失实）答非所问
D 欧盟未形成共同应对策略接收侧的处置分歧答非所问

→ 选 B。

第 2 步：为什么 A 不是"根本"

A 描述的是战乱中的一个具体主体、一种具体行为，属于"中东战乱动荡"的下位表现。问"根本"要向上收拢一层：正是地区层面的战乱、冲突和动荡持续加剧，才使难民源源不断地产生并外涌；A 之外还有其他战乱来源，单凭一个组织的行为解释不了"数量持续增长"的整体格局。C、D 则把视角从"难民从哪来"换成了"难民到欧洲后怎么样"，答非所问。

易错点

  • 误选 A：把"最抢眼的新闻画面"当"根本原因"——具体事件冲击力强，但它是战乱的组成部分，层次不够。
  • 误选 C / D：被题干"欧洲遭受危机"带偏，视角滑到接收侧。C、D 解释的是"欧洲为什么被动、为什么难处理"，不解释"难民为什么增长"；且 C 的"无力接收"表述失实——问题在意愿与政策分歧，不在能力上限。
记忆锚点：根本原因 → 产生侧整体动因（中东战乱动荡）；具体组织行为 = 诱因；接收能力 / 欧盟分歧 = 处置侧，答非所问。
