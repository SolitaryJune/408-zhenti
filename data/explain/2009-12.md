## 本题讲解：short 与 int 的机器数及相加

### 第一步：写出 x 与 y 的机器数

x 为 int（32 位）：127 = 7FH，即 x = `0000007FH`（四个选项此项相同）。

y 为 short（16 位）：-9 = -0009H，求补码：0009H 取反得 FFF6H，再加 1 得 `FFF7H`。注意 FFF9H 对应的是 -7，属于求补时出错的结果。

### 第二步：按 C 语言规则符号扩展后相加

z = x + y 中 short 自动转 int：FFF7H 符号扩展为 `FFFFFFF7H`（最高位为 1，高 16 位补全 1）。

补码相加：0000007FH + FFFFFFF7H = 1 00000076H，最高位进位超出 32 位被丢弃，z = `00000076H`。

| 变量 | 类型 | 机器数 |
|---|---|---|
| x | int | 0000007FH |
| y | short | FFF7H |
| y 符号扩展 | int | FFFFFFF7H |
| z | int | 00000076H |

### 第三步：十进制验证并选答案

127 + (-9) = 118 = 76H，与 z = 00000076H 一致。逐项核对：A 中 y 错；B 中 y、z 都错；C 中 z 错；只有 **D** 全对，选 **D**。

### 易错点

- **求补漏加 1**：得到 FFF9H（选项 A、B）。
- **忽略符号扩展 / 保留进位**：把 16 位结果直接拼进高位会得到形如 FFFF0076H 的错误值（选项 B）。
- **只核对一个变量**：必须 x、y、z 三个都验算，干扰项常是"两对一错"。

> 结论：x = 0000007FH，y = FFF7H，z = 00000076H，选 D。
