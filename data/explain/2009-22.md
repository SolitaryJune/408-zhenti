## 本题讲解：外部中断与内部异常的区分

### 第一步：先分两类

- **外部中断**：由 CPU 以外的部件（外设等）发出中断请求引起，与当前执行的指令无关，随机产生。
- **内部异常**：由 CPU **内部**在执行指令过程中发生的事件引起，如运算溢出、除 0、缺页、非法操作码等。

### 第二步：逐项归类

A 键盘输入——键盘是外设，敲键后向 CPU 发中断请求，属**外部中断** ✓

B 除数为 0——执行除法指令时 CPU 内部检测出错误，属内部异常

C 浮点运算下溢——运算结果超出表示范围，发生在 CPU 运算器内部，属内部异常

D 访存缺页——访存时发现所需页不在主存，由指令执行引发，属内部异常

### 易错点

- **把缺页当成外设事件**：缺页由 CPU 访存引发（页表由 CPU 侧的存储管理处理），不是外设的请求。
- **把「下溢」不当异常**：浮点下溢虽常按机器零处理，但事件发生在 CPU 内部，仍属内部事件。
- **判断口诀**：看事件的「源头」在 CPU 之外还是之内——外设请求 = 外部中断；指令执行中 CPU 内部产生 = 内部异常。

> 答案：**A**（键盘输入）。
