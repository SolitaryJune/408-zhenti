## 本题讲解：单链表倒数第 k 个结点 —— 双指针一次遍历

### 第一步：审题，确定效率目标

带头结点的单链表只给头指针 list，且**不改变链表**。要「尽可能高效」，就不能先遍历一遍求表长、再第二遍定位，目标是**一次遍历、常数个辅助变量**——这指向**双指针（快慢指针）法**。

### 第二步：问 1 —— 基本设计思想

设 p、q 两个指针，初始都指向第一个结点（list 的后继）。让 p 先沿链走 k 步，之后 p、q **同步后移**，两者始终保持 k 个结点的间距。当 p 到达链尾（为 NULL）时，q 恰好停在倒数第 k 个结点上。若 p 在走满 k 步之前就到达链尾，说明 k 超过表长，查找失败。

### 第三步：问 2 —— 详细实现步骤

1. 初始化：p = q = list 的后继（第一个结点），计数器 count = 0。
2. 当 p 不为空时循环：若 count < k，则 p 后移一步、count 加 1（p 先行）；否则 p、q 各后移一步（同步走）。
3. 循环结束后：若 count = k，q 即倒数第 k 个结点，输出其 data 并返回 1；若 count < k，说明 k 超出表长，返回 0。

### 第四步：问 3 —— C 语言实现

| 行 | 代码 |
|---|---|
| 1 | `typedef struct LNode { int data; struct LNode *link; } *LinkList;` |
| 2 | `int Search_k(LinkList list, int k) {` |
| 3 | `LinkList p = list->link, q = list->link;  // 初始指向第一个结点` |
| 4 | `int count = 0;` |
| 5 | `while (p != NULL) {` |
| 6 | `if (count < k) { p = p->link; count++; }  // p 先前进 k 步` |
| 7 | `else { p = p->link; q = q->link; }  // 之后 p 和 q 同步前进` |
| 8 | `}` |
| 9 | `if (count == k) { printf("%d", q->data); return 1; }  // 链表长度大于等于 k` |
| 10 | `return 0;  // k 超出链表长度` |
| 11 | `}` |

### 易错点

- **两趟遍历**：先求表长再定位虽正确，但不满足「尽可能高效」的要求，按次优解扣分。
- **丢边界**：忘记判 k 大于表长的情况（count < k 时必须返回 0）。
- **起点弄错**：带头结点的链表第一个结点是 list 的后继，不是 list 本身。

> 一句话结论：双指针保持 k 的间距一次遍历定位倒数第 k 个结点，时间 O(n)、空间 O(1)。
