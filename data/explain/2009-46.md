## 本题讲解：请求分页的访问耗时与缺页置换

### 第 0 步：机制先行——一次虚地址访问的完整流水线

请求分页系统里，每访问一个虚地址都要走完这条流水线，计时就是把走过的每一段加起来：

1. **切地址**：页面大小 4KB = 2¹² B，虚地址**低 12 位（低 3 位十六进制）是页内位移**，其余高位是页号。为什么可以只换页号、照抄位移？因为分页把地址切成定长块，页与页框等大，块内偏移在页框里同样成立。
2. **查 TLB（10ns）**：命中，直接得页框号；未命中也要付这 10ns（题设②规定先查 TLB）。
3. **TLB 未命中 → 查页表（100ns）**：有效位 1 → 得到页框号（按题设，其后的 TLB 更新不计时）；有效位 0 → **缺页中断**，处理耗时 10⁸ ns（题设已含更新 TLB 和页表），处理完**返回重新执行该指令**——重执时页已进 TLB，按命中路径重新计时。
4. **访问主存（100ns）**：拿到页框号后拼出物理地址，取数据还要真正访存一次——TLB 只负责「地址翻译」，数据本身在内存。

TLB 的状态随访问序列演变：TLB 初始为空；第一次访问后页 2 进 TLB；1565H 的缺页处理把页 1 写入 TLB。这些状态是后面三次计时的依据。

### 问 1：三个虚地址逐个计时

**2362H**：页号 2、位移 362H。TLB 空 → 未命中 10ns；查页表，页 2 有效 → 100ns；拼 254H ∥ 362H 后访存 → 100ns。合计 **210ns**。此后页 2 进入 TLB（更新时间按题设忽略）。

**1565H**：页号 1、位移 565H。TLB 未命中 10ns；查页表，页 1 有效位 0 → 100ns；缺页中断处理 10⁸ ns（含把页 1 写入 TLB 与页表）；返回重新执行：TLB 命中 10ns + 访存 100ns。合计 10 + 100 + 10⁸ + 10 + 100 = **100000220ns**。

**25A5H**：页号 2、位移 5A5H。页 2 在第一次访问时已进 TLB，且此后没有被移出——缺页处理换出的是**主存驻留集**里的页 0，TLB 中页 2 → 254H 的表项不受影响 → TLB 命中 10ns + 访存 100ns = **110ns**。

| 虚地址 | 路径 | 计时 |
|---|---|---|
| 2362H | TLB 未命中 → 页表有效 → 访存 | 10+100+100 = **210ns** |
| 1565H | TLB 未命中 → 页表无效 → 缺页处理 → 重执：TLB 命中 → 访存 | 10+100+10⁸+10+100 = **100000220ns** |
| 25A5H | TLB 命中 → 访存 | 10+100 = **110ns** |

### 问 2：1565H 的物理地址为什么是 101565H

**先淘汰谁？** 缺页发生时驻留集已满（固定 2 页：页 0 在 101H、页 2 在 254H），必须先淘汰一页再装入页 1。LRU 选「最久未被访问」的驻留页：页 2 刚被 2362H 访问过，页 0 自始至终没被碰过——牺牲的是**页 0**（注意不是「淘汰页 1」，页 1 本来就不在内存，谈不上淘汰）。页 1 装入页 0 腾出的页框 **101H**。

**地址怎么拼？** 页框大小 = 页面大小 = 4KB，页内位移直接照抄：物理地址 = 页框号 ∥ 页内位移 = 101H ∥ 565H = **101565H**。

### 易错点

- **漏算缺页后的「重新执行」**：题设③明确返回重执，重执的 TLB 命中 10ns + 访存 100ns 不能漏。
- **LRU 选错牺牲页**：在驻留的页 0、页 2 之间选最久未用的页 0；页 1 不在驻留集，不是候选。
- **误判第三次访问**：页 2 的 TLB 表项仍有效，25A5H 走命中路径 110ns，不能再算一次页表 100ns。
- **页号切错**：页内位移位数由页面大小决定，4KB → 低 3 位十六进制；2362H 的页号是 2，不是把 236 当页号。

> 一句话结论：三次访问依次 210ns、100000220ns、110ns；LRU 淘汰页 0，页 1 入驻 101H，物理地址 101565H。
