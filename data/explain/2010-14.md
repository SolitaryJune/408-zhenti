## 本题讲解：int/float/double 类型转换的精度取舍

答案：**B**（仅 I 和 III 为真）。

### 第一步：抓住各转换的"精度规则"

- float 有 24 位二进制有效位，能**精确表示**绝对值不超过 2^24（16 777 216）的整数。
- float → int：**截断小数**，必然丢掉小数部分。
- float → double：double 有效位更多，转换**无损**；再转回 float 得到原值。
- double 大数加小数：double 只有 53 位有效位，两数相差悬殊时，小数落不到大数的末位有效格子里，被完全"吸收"。

### 第二步：逐式判定

| 表达式 | 分析 | 结果 |
|---|---|---|
| I. i==(int)(float)i | i = 785 < 2^24，int→float 精确，转回仍是 785 | 真 |
| II. f==(float)(int)f | f = 1567.8，(int)f 截断为 1567，再变回 1567.0，比原值少了 0.8 | 假 |
| III. f==(float)(double)f | float→double 无损、double→float 舍入回原值 | 真 |
| IV. (d+f)−d==f | d = 1.5×10^100 的相邻可表示数间隔远大于 1567.8，d+f 舍入后仍等于 d，(d+f)−d = 0 | 假 |

### 易错点

- **以为 int→float 总会丢精度**：只有绝对值超过 2^24 的整数才丢，785 远没到。
- **以为 float→double→float 有"往返损耗"**：float 的可表示数是 double 的子集，往返无损。
- **漏看 IV 的数量级**：1.5×10^100 与 1567.8 相加，小数根本进不了双精度数的有效位，减回来只剩 0。

> 记忆锚点：整数往返看 2^24；小数取整必截尾；升精度无损、降精度舍入；大数吃小数——为真的只有 I 和 III，选 B。
