## 本题讲解：完全二叉树的叶结点个数

**答案：C（384）。**

### 第一步：n0 = n2 + 1 不是口诀，数两遍边就能推出来

二叉树里除了根，**每个结点头顶都有一条来自父结点的边**，所以边数 = 结点数 − 1；而边只会从分支结点发出——度 1 结点发 1 条、度 2 结点发 2 条，边数 = n1 + 2n2。两式相等：

n0 + n1 + n2 − 1 = n1 + 2n2，两边消去 n1，得 **n0 = n2 + 1**——叶子永远比"双孩子结点"恰好多一个。

### 第二步：完全二叉树为什么 n1 只能取 0 或 1

完全二叉树按层编号 1..n，编号 i 的孩子是 2i 和 2i+1。度为 1 的结点若存在，只能是**编号 ⌊n/2⌋ 的最后一个分支结点**，且只可能"有左孩子、缺右孩子"——它若缺的是左孩子，左孩子编号 2i 比右孩子 2i+1 更小却不存在，违背按层连续填放的规则。于是：**n 为奇数时 n1 = 0；n 为偶数时编号 n 恰是某个结点的左孩子，n1 = 1**。

### 第三步：本题求解

768 是偶数 ⇒ n1 = 1。代入 n0 + n1 + n2 = 768 与 n0 = n2 + 1：2·n2 + 2 = 768，n2 = 383，**n0 = 384**。

### 第四步：编号法复核（第二层对号入座）

叶结点恰为编号 ⌊768/2⌋ + 1 = 385 到 768 的结点，共 768 − 384 = **384** 个；编号 384 的结点左孩子（768 号）存在、右孩子（769 号）越界不存在——这正是 n1 = 1 在这棵树上的具体模样。

### 易错点

- **漏用奇偶性**：令 n1 = 0 会得到 2·n2 + 1 = 768，无整数解——方程无解本身就是"n1 必为 1"的信号。
- **编号法差一**：叶子从 385 号开始数；把 384 号（它是分支结点）也算进去会误选 D（385）。

> 记忆锚点：n0 = n2 + 1 靠数边两步推得；完全二叉树 n 为偶 ⇒ n1 = 1（最后一个分支结点只缺右孩子）。
