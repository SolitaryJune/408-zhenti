## 本题讲解：完全二叉树叶结点个数

**答案：C（384）。**

### 第一步：备好两条结论

- 二叉树度数性质：**n0 = n2 + 1**（叶子数 = 度为 2 的结点数 + 1）；
- 完全二叉树中度为 1 的结点 **n1 只能取 0 或 1**。

### 第二步：列方程，用奇偶性定 n1

由 n = n0 + n1 + n2 = 768 与 n0 = n2 + 1，得 2·n2 + n1 + 1 = 768。左边 2·n2 + 1 是奇数，要等于偶数 768，**n1 必为 1**。于是 2·n2 = 766，n2 = 383，**n0 = n2 + 1 = 384**。

### 第三步：用编号法验证

完全二叉树按层编号，叶子恰为编号 **⌊n/2⌋+1 到 n** 的结点：⌊768/2⌋+1 = 385，即编号 385~768 全是叶子，共 768 − 384 = **384** 个，两法一致。最后一个分支结点是编号 384：它的左孩子（编号 768）存在而右孩子（编号 769）不存在，恰好只有一个孩子——这正是 n1 = 1 的体现。

### 易错点

- **漏用奇偶性**：若令 n1 = 0，则 2·n2 + 1 = 768 无整数解——这一步是判断的关键，跳过它就可能凑出错误答案。
- **编号法差一**：叶子从 ⌊768/2⌋+1 = 385 号开始，共 384 个；把 384 号也数进去会误选 D（385）。

> 记忆锚点：完全二叉树求叶子——先由 n 的奇偶定 n1（偶数 ⇒ n1 = 1），再由 n0 = n2 + 1 解出；或直接用「叶子是编号 ⌊n/2⌋+1 … n 的结点」。
