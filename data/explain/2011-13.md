## 本题讲解：把 −8.25 编成 IEEE 754 单精度浮点数

**答案：A（C104 0000H）**。单精度 = 1 位数符 + 8 位阶码 + 23 位尾数；动手前先弄清两个设计的"为什么"，步骤才不是死记。

### 第一步：为什么阶码要加偏置 127、尾数要隐含 1

- **阶码加偏置 127**：真指数可正可负（2³ 与 2⁻³ 都会出现），若用补码存 8 位阶码，比较两个浮点数大小前还得先判符号。规定**阶码 = 真指数 + 127**，把指数平移成 1~254 的无符号数，浮点数之间就能像整数一样按位快速比较——偏置的全部目的就是"免符号判定"。
- **尾数隐含 1**：规格化后二进制数必写成 1.xxx × 2ᵉ 的形状，整数位恒为 1，存它是浪费。把它藏起来，23 位全部用来存小数部分，**凭空多赚一位精度**；还原数值时硬件自动补回这个 1。

### 第二步：可复现编码

1. 写成二进制：8.25 = 1000 + 0.01 = 1000.01B，故 x = −1000.01B；
2. 规格化：小数点左移 3 位，得 −1.00001 × 2³，真指数 = 3；
3. 数符 S：负数 → **1**；
4. 阶码 E：3 + 127 = 130 = `1000 0010B`；
5. 尾数 M：去掉隐含的 1，存小数部分 `00001` 并补 0 满 23 位。

| 字段 | 内容 |
|---|---|
| 数符（1 位） | 1 |
| 阶码（8 位） | 1000 0010 |
| 尾数（23 位） | 0000 1000 0000 0000 0000 000 |

拼接 32 位：`1100 0010 0000 1000 0000 0000 0000 0000` → **C104 0000H**。

### 第三步：反向验算

数符 1（负）×（1 + 1/32）× 2^(130−127) = −33/32 × 8 = **−8.25** ✓。

### 易错点

- **选 B（C242 0000H）**：其阶码字段是 132，即把指数当成 5——8.25 的小数点只左移 3 位，指数是 3 而非 4、5。
- **选 C/D**：尾数错位——`00001` 表示"小数点后第 5 位为 1"，应落在 23 位尾数的**高 5 位**（高位起 `00001`），不是右移后的 `000000001…`，也不是把隐含的 1 写进尾数。
- **忘加偏置 127**：把 3 直接填进阶码字段。
- **用补码思路存阶码**：阶码是无符号的"真指数 + 偏置"，不走补码。

> 记忆锚点：单精度编码 = 规格化定指数 → 加 127 得阶码 → 去 1 补零填尾数；偏置为快速比较、隐含 1 为多赚精度。
