## 本题讲解：偏移寻址的判定——谁不是"寄存器 + 形式地址"

### 第一步：先给答案

**答案：A（间接寻址）**。题干已给出判定标准：**有效地址 EA = 某个寄存器内容 + 形式地址 A**。三个偏移寻址都满足这一形式，间接寻址不满足。

### 第二步：逐项对照定义

| 选项 | 寻址方式 | 有效地址 | 是否偏移寻址 |
|---|---|---|---|
| A | 间接寻址 | EA = (A)，即 A 单元里**存的是地址**，再去取内容 | 否 |
| B | 基址寻址 | EA = (BR) + A，基址寄存器 + 形式地址 | 是 |
| C | 相对寻址 | EA = (PC) + A，程序计数器 + 形式地址 | 是 |
| D | 变址寻址 | EA = (IX) + A，变址寄存器 + 形式地址 | 是 |

### 第三步：本质区别

基址、变址、相对这三种寻址的共性是"**先取一个寄存器的值，再与形式地址相加**"——寄存器提供基准，形式地址提供偏移量，所以统称偏移寻址。而间接寻址的关键动作是"**再访存一次**"：A 或 (A) 指向的单元内容才是有效地址，全程没有"寄存器内容与形式地址相加"这个操作。

### 易错点

- **选 C（相对寻址）**：以为"相对"特殊——其实相对寻址就是以 PC 为基准寄存器的偏移寻址，用于支持程序浮动。
- **混淆基址与变址的方向**：谁做基准、谁做偏移是用途问题（基址面向操作系统重定位、变址面向用户数组遍历），不影响"二者都是偏移寻址"的归类。

> 记忆锚点：偏移寻址 = 基址 + 变址 + 相对，公式统一为 EA = (寄存器) + A；间接寻址 = 串接访存，不是相加。
