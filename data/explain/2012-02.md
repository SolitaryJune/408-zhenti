## 本题讲解：中缀转后缀时操作符栈的最大深度

**答案：A（5 个）**

### 第一步：明确转换规则

操作数直接输出；操作符入栈前，先把栈顶所有"优先级 ≥ 自己"的操作符弹出；`(` 直接入栈；`)` 负责连续弹出直到遇见 `(`（括号本身不输出）。

### 第二步：逐符号模拟，盯住栈深

| 读入 | 动作 | 栈内（左底右顶） | 栈深 |
|---|---|---|---|
| a | 输出 | 空 | 0 |
| + | 入栈 | `+` | 1 |
| b | 输出 | `+` | 1 |
| - | 弹`+`、入栈 | `-` | 1 |
| a | 输出 | `-` | 1 |
| * | 入栈 | `-*` | 2 |
| ( | 入栈 | `-*(` | 3 |
| ( | 入栈 | `-*((` | 4 |
| c | 输出 | `-*((` | 4 |
| + | 入栈 | `-*((+` | **5** ← 峰值 |
| d | 输出 | `-*((+` | 5 |
| ) | 弹`+`、弃`(` | `-*(` | 3 |
| / | 入栈 | `-*(/` | 4 |
| e | 输出 | `-*(/` | 4 |
| - | 弹`/`、入栈 | `-*(-` | 4 |
| f | 输出 | `-*(-` | 4 |
| ) | 弹`-`、弃`(` | `-*` | 2 |
| + | 弹`*`、`-`、入栈 | `+` | 1 |
| g | 输出 | `+` | 1 |
| 结束 | 弹出`+` | 空 | 0 |

### 第三步：结论

同时留在栈中的操作符最多 **5 个**（读里层 `(c+d)` 中的 `+` 时，栈内是 `- * ( ( +`），选 **A**。

### 易错点

- **漏算两个 `(`**：括号也是"暂时不能确定运算次序的操作符"，同样占栈深；只数运算符会误得 3。
- **在外层 `+` 处误判**：外层 `+` 会先把 `*` 和 `-` 弹光，栈反而变浅，不是峰值。

> 最深时刻发生在"双层括号内部再遇到运算符"。
