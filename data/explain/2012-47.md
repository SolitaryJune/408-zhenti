## 本题讲解：TCP 抓包分析（握手、填充、TTL）

### 答题框架与答案总览

抓包题三步走：看源/目的 IP 定方向；看 TCP 标志位、序号/确认号定连接阶段与数据量；用以太网最小帧规则和 TTL 规则算填充与路由器跳数。两个关键地址：`c0 a8 00 08` = 192.168.0.8（主机 H），`d3 44 47 50` = 211.68.71.80（服务器 S）。答案：第 1 问——H 发送 1、3、4 号，1、2、3 号完成连接建立，3、5 号填充；第 2 问——16 字节；第 3 问——15 个路由器。

### 第 1 问：方向、握手与填充

- **由 H 发送**：源 IP = 192.168.0.8 的是 **1、3、4 号**（2、5 号的源 IP 是 S）。
- **完成连接建立**：1 号标志 `02H`（SYN，序号 846B41C5）→ 2 号 `12H`（SYN+ACK，确认号 846B41C6 = 对方序号 +1）→ 3 号 `10H`（ACK，确认对方的 SYN）。三次握手齐备 → **1、2、3 号**。
- **需要填充**：以太网数据字段最短 46 B，IP 数据报总长不足 46 B 必须填充。3 号和 5 号总长度都是 `0028H` = 40 B，填充 6 B → 填充的是 **3、5 号**（1、2 号 48 B、4 号 56 B，都不用）。

### 第 2 问：S 已收到的应用层数据

- 逐分组看数据量：1、2 号总长 48 B，减 IP 头 20 B、TCP 头 28 B（数据偏移为 7，含选项）后数据为 0；3、5 号总长 40 B，减去两个 20 B 头后也为 0。
- 只有 4 号携带数据：总长 `0038H` = 56 B − IP 头 20 B − TCP 头 20 B = **16 B**（标志 `18H` = PSH+ACK，序号 846B41C6）。
- 5 号是 S 发回的确认：确认号 `846B41D6` = 4 号序号 + 16，证实这 16 字节已被 S 收到。所以 S 已收到应用层数据 **16 字节**。

### 第 3 问：经过的路由器数

47-b 表与 5 号分组的标识字段同为 `6811H`，是它在 S 发出时的样子：TTL = `40H` = 64。H 捕获到的 5 号分组 TTL = `31H` = 49。每经过一个路由器 TTL 减 1：`64 − 49 = 15`，即经过 **15 个路由器**。

### 易错点

- **TTL 差值数错**：两端都是主机、主机不减 TTL，差值 15 就是路由器台数，不需要再加 1。
- **把 TCP 头一律按 20 B 算**：1、2 号的 TCP 头是 28 B（数据偏移字段为 7），算数据长度时必须用数据偏移。
- **忘记以太网 46 B 下限**：40 B 的 IP 数据报在链路层要填充 6 B，填充字节属于链路层，不改变 IP 总长度。

> 一句话：源 IP 定方向，标志位定握手，总长度定填充，TTL 差值定跳数。
