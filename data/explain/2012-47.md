## 本题讲解：TCP 抓包分析——从 40 字节十六进制读出方向、握手、填充与跳数

### 第 0 步：先建立"读包"的方法——按头部结构逐字段切

抓包题的全部信息都在那 40 字节里，按题 47-a 图（IP 头）与题 47-b 图（TCP 头）的结构切开读：

- **IP 头（前 20B）**：首字节 `45` = 版本 4、头长 5×4B = 20B；第 3~4 字节是**总长度**；第 9 字节是 **TTL**；第 10 字节协议 06 = TCP；末 8 字节是源、目的 IP。先把两个地址认熟：`c0 a8 00 08` = 192.168.0.8（主机 H）、`d3 44 47 50` = 211.68.71.80（服务器 S）——**源 IP 是谁，分组就是谁发的**。
- **TCP 头**：源/目的端口、序号、确认号、数据偏移、标志位。数据偏移的单位是 **4B**（为什么 ×4：TCP 头长必须是 4 字节的整数倍，偏移字段数的是 32 位字的个数），`70` → 7×4 = 28B 头，`50` → 20B 头。标志位低 6 位依次为 FIN、SYN、RST、PSH、ACK、URG：`02` = SYN、`12` = SYN+ACK、`10` = ACK、`18` = PSH+ACK。
- **确认号的语义**（本题两处要用）：确认号 = 期望收到的下一个字节的序号（累积确认）。**SYN 报文要消耗一个序号**，所以对 SYN 的确认号 = 对方 ISN＋1；对数据的确认号 = 已收到的最后一个字节序号＋1。

### 第 1 问：哪些是 H 发的、哪些完成握手、哪些填充

- **方向**：1、3、4 号源 IP = `c0 a8 00 08` → 由 **H 发送**；2、5 号源 IP = `d3 44 47 50` → S 发送。
- **握手**：1 号标志 `02`（SYN，序号 846b41c5）→ 2 号 `12`（SYN+ACK，确认号 846b41c6 = 846b41c5＋1，正是"SYN 占一个序号"）→ 3 号 `10`（ACK，确认号 e0599ff0 = 对方 ISN e0599fef＋1）。SYN、SYN+ACK、ACK 三次握手齐备，且确认号逐个回扣对方序号 → **1、2、3 号完成连接建立**。
- **填充**：机制在以太网帧——MAC 帧数据字段最短 46B（最小帧长 64B − 目的/源地址与长度 14B − FCS 4B = 46B），IP 数据报不足 46B 就在帧层补填充。逐包看 IP 总长度：1、2 号 `0030H` = 48B（不填），3、5 号 `0028H` = 40B（**补 6B**），4 号 `0038H` = 56B（不填）→ **填充的是 3、5 号**。为什么填充不影响后续计算：填充加在帧的数据字段末尾、属于链路层，IP 总长度字段仍是 40，接收方按总长度上交 IP 层后把填充丢弃。

### 第 2 问：S 已经收到的应用层数据字节数

分组携带的应用数据 = IP 总长度 − IP 头长 − TCP 头长（TCP 头长 = 数据偏移 × 4B）：

- 1、2 号：48 − 20 − 7×4 = 0；3、5 号：40 − 20 − 20 = 0——都是纯控制段，不带数据；
- 只有 4 号带数据：56 − 20 − 20 = **16B**（标志 `18` = PSH+ACK，序号 846b41c6，这 16 字节从 846b41c6 编起）。

但"H 发了"不等于"S 收到"，要看 5 号（S 发回的 ACK）的确认号：`846b41d6` = 846b41c6 ＋ 16。按累积确认，确认号之前的字节已全部收齐 → S 已收到应用层数据 **16 字节**。

### 第 3 问：该分组到达 H 时经过了多少个路由器

TTL 的机制：分组每被一台**路由器**转发一次，TTL 减 1；两端主机收发都不减 → 捕获时的 TTL − 发出时的 TTL = 路由器数。47-b 表与 5 号分组的标识字段同为 `6811H`，即 5 号在 S 发出时的样子：TTL = `40H` = 64；H 捕获到的 5 号 TTL = `31H` = 49；64 − 49 = **15 台路由器**。两端都是主机、主机不减 TTL，所以差值不需要再加 1 或减 1。

### 易错点

- **TCP 头一律按 20B 算**：1、2 号的数据偏移是 7，头长 28B（含选项）；算数据量必须用数据偏移 × 4。
- **把"+1 的确认号"当笔误**：SYN 消耗一个序号，SYN 与数据的确认号都指"下一个期望字节"，这是 TCP 的规定。
- **把填充算进 IP 总长度**：填充在帧层、不改变 IP 总长度字段，也不计入应用数据。
- **TTL 差值再 ±1**：只有路由器转发时减 1，两端主机不减，15 就是路由器台数。

> 记忆锚点：源 IP 定方向；标志位＋确认号回扣定握手；IP 总长度 − 头部长定数据与填充（46B 下限定填充）；TTL 差值定跳数。
