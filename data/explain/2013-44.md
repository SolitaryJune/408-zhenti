## 本题讲解：条件转移指令的执行（14 分大题）

### 题目要点回顾

16 位定长指令：5 位操作码 `00000` + 检测位 C、Z、N 各 1 位 + 8 位补码偏移量 OFFSET。检测位为 1 表示要检测对应标志；被检测的标志中**只要有一个为 1 就转移**。转移目标 = (PC) + 2 + 2×OFFSET；顺序执行下条指令地址 = (PC) + 2。

### 第（1）问：编址方式与向后跳转上限

- **按字节编址**：顺序执行时下条指令地址为 (PC)+2，说明每条指令占 2 个地址单元；16 位指令 = 2 字节，故存储器按字节编址。
- **向后最多跳 127 条指令**：OFFSET 是 8 位补码，最小值 −128。向后跳得最远时目标 = (PC)+2+2×(−128) = (PC)−254，相对本指令后退 254B，即 254 ÷ 2 = **127 条指令**。

### 第（2）问：两种标志下的 PC 值

指令地址 200CH，其机器码中 C=0、Z=1、N=1 → 只检测 **ZF 和 NF**；OFFSET = `1110 0011B = E3H`。

**情况一：CF=0，ZF=0，NF=1 → 转移**

- E3H 符号扩展到 16 位：`FFE3H`（−29）；
- 左移一位（×2）：`FFC6H`（−58）；
- 目标地址 = 200CH + 2 + FFC6H = 200EH + FFC6H = **1FD4H**，即 PC = 1FD4H。

**情况二：CF=1，ZF=0，NF=0 → 不转移**

- 被检测的 ZF、NF 都是 0，不满足转移条件 → 顺序执行，PC = 200CH + 2 = **200EH**。

### 第（3）问：无符号数"小于等于转移"

无符号比较中 CF 是借位（小于）标志、ZF 是相等（等于）标志。"小于**或**等于" → 需检测 CF 和 ZF：**C=1，Z=1，N=0**。

### 第（4）问：数据通路部件①~③

| 部件 | 名称 | 功能说明 |
|---|---|---|
| ① | 指令寄存器（IR） | 存放取出的整条指令（OP、CZN、OFFSET） |
| ② | 移位寄存器 | 把符号扩展后的偏移量左移 1 位，实现 ×2 |
| ③ | 加法器 | 求 (PC)+2 与 2×OFFSET 之和，得到转移目标地址 |

### 易错点

- **第（1）问答成按字编址**：判断依据是 (PC)+2 与"16 位指令"的组合——每条指令占 2 个编址单元，单元必是字节。
- **第（2）问漏符号扩展或左移**：E3H 是 8 位补码，须先扩到 16 位 FFE3H 再左移得 FFC6H，直接拿 E3H 加会算错。
- **第（2）问漏加 2**：目标是 (PC)+2+2×OFFSET，先做 200CH+2 = 200EH。
- **第（3）问误用 N**：NF（符号标志）对无符号数比较无意义；无符号"小于等于"只用 CF（小于）与 ZF（等于）。
- **第（4）问部件②答成普通寄存器**：它的功能是"移位"实现 ×2，答"移位寄存器"才完整。

> 一句话结论：按字节编址、向后最多 127 条；转移时 PC = 1FD4H，不转移 PC = 200EH；C=1、Z=1、N=0；① IR、② 移位寄存器、③ 加法器。
