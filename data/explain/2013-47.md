## 本题讲解：路由聚合、最长匹配与 BGP（综合题 9 分）

**答案要点**：(1) R2 路由表 3 项（见下表）；(2) 从接口 **E0** 转发；(3) 用 **BGP**，其报文封装在 **TCP** 分组中传输。

### 第一步（问 1）：数清图中的子网

题 47 图共 **5 个子网**：AS1 内 R1 连接的 153.14.5.0/25 与 153.14.5.128/25；AS2 内 R3 连接的 194.17.20.0/25 与 194.17.21.0/24；R2 直连的 194.17.20.128/25。另有两条点对点链路（R1 侧接口 153.14.3.2，R3 侧接口 194.17.24.2），R2 路由表中用它们作下一跳。

### 第二步（问 1）：逐侧聚合，路由项最少

- **AS1 侧**：153.14.5.0/25 与 153.14.5.128/25 前半、后半恰好拼满一个 /24 → 聚合为 **153.14.5.0/24**，下一跳 153.14.3.2（R1），走 S0。
- **R3 侧**：194.17.20.0/25（194.17.20.0~127）与 194.17.21.0/24（194.17.21.0~255）合并成连续块 194.17.20.0~194.17.21.255 → 聚合为 **194.17.20.0/23**，下一跳 194.17.24.2（R3），走 S1。
- **R2 直连**：194.17.20.128/25 从 E0 直连。注意 /23 的范围（194.17.20.0~194.17.21.255）**包含**这个直连子网，所以这条更精确的直连路由必须单独保留——这正是路由表需要 3 项、而不是 2 项的原因。

R2 路由表：

| 目的网络 | 下一跳 | 接口 |
|---|---|---|
| 153.14.5.0/24 | 153.14.3.2 | S0 |
| 194.17.20.0/23 | 194.17.24.2 | S1 |
| 194.17.20.128/25 | 直连 | E0 |

### 第三步（问 2）：最长前缀匹配定接口

目的 IP 194.17.20.200 同时命中两项：194.17.20.0/23（194.17.20.0~194.17.21.255）与 194.17.20.128/25（194.17.20.128~194.17.20.255）。前缀 /25 比 /23 更长更精确，按**最长前缀匹配**走直连表项 → 从 **E0** 转发。

### 第四步（问 3）：AS 之间用 BGP，封装在 TCP 里

R1 属 AS1、R2 属 AS2，两者是**不同自治系统**的边界路由器，交换路由信息用外部网关协议 **BGP**（BGP-4）。BGP 的可靠性要求高，其报文封装在 **TCP** 分组（端口 179）中传输。对照：RIP 封装在 UDP 中，OSPF 直接封装在 IP 中——三者封装层次是常考点。

### 易错点

- **AS1 侧忘了聚合**：把两个 /25 拆成两条路由 → 路由项不是最少，不合题意。
- **丢掉直连的 /25**：以为 /23 已覆盖它就不用写；一旦丢掉，发往 194.17.20.128~255 的分组会被送进 S1，绕去 R3。
- **问 3 答成 OSPF/RIP**：RIP、OSPF 是自治系统内部协议（IGP），跨 AS 用 BGP；且 BGP 跑在 TCP 之上。

> 三句话：聚合看能否并成更短前缀；查表用最长前缀匹配；跨 AS 用 BGP、BGP 靠 TCP。
