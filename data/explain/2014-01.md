## 本题讲解：双层循环的时间复杂度（乘法法则）

答案：**C**，时间复杂度为 `O(n log2 n)`。

### 第一步：拆出每一层循环各自的执行次数

嵌套循环的总执行次数 = 外层次数 × 内层次数（乘法法则）。

**外层**：`k` 从 1 开始，每轮乘 2：`k = 1, 2, 4, 8, …, 2^t`。条件是 `k <= n`，所以执行次数是满足 `2^t <= n` 的最大 t 再加 1，即 **`log2 n` 下取整 + 1** 次，量级为 `O(log2 n)`。

**内层**：`j` 从 1 到 n 每轮加 1，固定执行 **n** 次，量级为 `O(n)`。

### 第二步：相乘并只保留最高阶

`count++` 的总执行次数 ≈ `n × (log2 n + 1) = n·log2 n + n`。去掉常数和低阶项 n，只保留最高阶：**`O(n log2 n)`**。

用一个具体数验证：设 n = 16，外层 k 取 1,2,4,8,16 共 5 次，内层每轮 16 次，总 80 次 ≈ 16×4，与 `n·log2 n` 同量级。

### 易错点

- **把两层循环相加**：误写成 `O(n + log2 n)` 得 B。嵌套循环是"乘"不是"加"——外层每走一步，内层都要完整跑 n 次。
- **只看外层**：误选 A `O(log2 n)`，漏掉了内层循环的 n。
- **看到两层循环就选 `O(n^2)`**（D）：内层循环次数 n 与外层无关，但外层次数不是 n 而是 `log2 n`，不能机械套用"双层循环 = 平方"。

> 记忆锚点：循环变量**乘 2（或除 2）地跳**，循环次数就是 `log2 n`；嵌套循环复杂度 = 各层次数相乘。
