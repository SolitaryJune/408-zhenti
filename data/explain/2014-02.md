## 本题讲解：中缀转后缀时扫描到 f 的栈内容

答案：**B**，栈内元素（栈底→栈顶）依次为 `+ ( - *`。

### 第一步：明确规则

操作数直接送输出缓冲；运算符入栈前先弹出栈顶所有**优先级不低于它**的运算符（左结合）；左括号直接进栈；右括号把栈中到左括号为止的运算符全部弹出。优先级：`* /` 高于 `+ -`。

### 第二步：逐个扫描 `a/b+(c*d-e*f)/g`

| 扫描到 | 动作 | 栈（底→顶） | 输出 |
|---|---|---|---|
| a | 直接输出 | 空 | a |
| / | 栈空，进栈 | / | a |
| b | 直接输出 | / | a b |
| + | 弹出 / 再进栈 | + | a b / |
| ( | 进栈 | + ( | a b / |
| c | 直接输出 | + ( | a b / c |
| * | 栈顶是 ( ，进栈 | + ( * | a b / c |
| d | 直接输出 | + ( * | a b / c d |
| - | 弹出 *（优先级高于 -），再进栈 | + ( - | a b / c d * |
| e | 直接输出 | + ( - | a b / c d * e |
| * | 栈顶是 - 但 * 优先级更高，进栈 | + ( - * | a b / c d * e |
| f | 尚未输出 | **+ ( - *** | a b / c d * e |

### 第三步：读答案

扫描到 `f` 时，栈从底到顶是 `+ ( - *`，对应选项 **B**。

### 易错点

- **忘记先弹后进**：扫描 `-` 时若不先弹出 `*`，会误得 `+(-*` 之外的 C 选项形态（`/+(-*`），A 选项 `+(*-` 正是"没弹出就直接压"的错误结果。
- **优先级判断反了**：扫描第二个 `*` 时，若以为 `*` 低于 `-` 而先弹栈，会错选 D（`/+-*`，连 `(` 都丢了）。
- **栈方向的读法**：选项串是从**栈底到栈顶**排列，`+` 在最底下。

> 记忆锚点：括号是"墙"——左括号进栈后墙内自成体系；高优先级运算符进栈前会把栈顶"同级及以上"全部弹走。
