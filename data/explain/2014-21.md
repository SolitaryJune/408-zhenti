## 本题讲解：I/O 接口与端口的概念辨析（找错误项）

答案：**D**。

### 第一步：逐项判断对错

- **B 正确**：I/O 接口中 CPU 能直接访问的寄存器就叫 I/O 端口（数据端口、状态端口、控制端口）。
- **A 正确**：状态端口和控制端口可以合用同一个寄存器——对该寄存器执行读命令读出的是状态信息、执行写命令写入的是控制信息，靠读/写命令区分，互不冲突。
- **C 正确**：独立编址时 I/O 端口地址空间与主存地址空间彼此独立，两边各自从 0 编号，端口地址与主存地址**可能相同**，CPU 用专门的 I/O 指令区分两者。
- **D 错误**：统一编址（存储器映射）方式下，I/O 端口占用主存地址空间，CPU 恰恰**用普通访存指令**（load/store 类）访问 I/O 端口——"不能用访存指令访问"正好说反了；不能用访存指令访问 I/O 端口的是独立编址方式（要用专门的 I/O 指令）。

### 易错点

- **两种编址方式特点记反**：统一编址 → 共享地址空间、用访存指令访问 I/O、无需专门 I/O 指令；独立编址 → 地址空间独立、需要专门 I/O 指令。
- **以为 A 错**：一个寄存器"读出状态、写入控制"是接口设计的常见做法，读写命令天然区分。
- **以为 C 错**：两个独立地址空间编号重叠完全合法，靠指令类型区分访问对象。

> 记忆锚点：统一编址 = 访存指令访 I/O；独立编址 = 专门 I/O 指令 + 专用地址空间。
