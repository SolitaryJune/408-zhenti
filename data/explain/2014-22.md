## 本题讲解：中断方式下 CPU 用于 I/O 的时间占比

答案：**B**（25%）。

### 第一步：找一个周期内的开销

设备每 400 ns 发一次中断请求，CPU 每次响应并处理该中断要用 100 ns。以 400 ns 为一个周期：其中 CPU 花在此设备 I/O 上的时间就是 100 ns，其余 300 ns CPU 可以继续执行原程序。

### 第二步：算占比

占比 = 100 ÷ 400 = **25%**，选 **B**。

### 第三步：50 ns 延迟是干扰条件

"中断响应所允许的最长延迟为 50 ns"的意思是：设备允许 CPU 最迟在请求到来后 50 ns 内开始响应，这是对响应及时性的**约束**。在延迟等待期间 CPU 并没有为该设备工作，这 50 ns 不计入 I/O 时间；计入的只有"响应 + 处理"的 100 ns。所以占比与 50 ns 无关，"至少"为 100/400 = 25%。

### 易错点

- **把延迟加进去**：按 (100 + 50)/400 = 37.5% 计算，错选 C——响应延迟期间 CPU 未在服务该设备。
- **只算延迟**：50/400 = 12.5%，错选 A。
- **处理时间翻倍**：200/400 = 50%，错选 D，题干没有依据。

> 记忆锚点：中断 I/O 占比 = 每周期 CPU 服务时间 ÷ 请求周期；"允许的最长响应延迟"是约束不是开销。
