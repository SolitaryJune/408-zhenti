## 本题讲解：OSPF 链路状态信息的存储与最短路径计算

### 先立机制：OSPF 与"图"是怎么接上来的

OSPF 是**链路状态**协议：每台路由器把自己的邻接情况（到谁、本地接口 IP、代价 Metric）封装成链路状态信息（LSI）**泛洪**给全网；每台路由器收齐所有 LSI 后，就能在本地**拼出一幅完整的带权拓扑图**。所以"网络 → 数据结构"的翻译规则是：路由器、子网都是**顶点**，链路/直连网络是**边**，Metric 是**边权**；链路双向可达，边没有方向——抽象为**图（无向图）**。而"已知全图、边权非负、求单源最短路"正是 **Dijkstra 算法**的适用场景——第 3 问用它不是巧合，是 OSPF 的协议设计本身。

### 第 1 问：抽象成什么逻辑结构

按上面的翻译规则作答：本题中的网络可抽象为数据结构中的**图**（带权无向图/网）。**为什么不能答树**：路由器与子网之间是多对多的邻接关系（R1 同时连 R2、R3 和直连子网），拓扑里有回路，不满足树"无回路、双亲唯一"的限制。

### 第 2 问：链式存储结构的设计

LSI 的天然形状是"**按路由器分组、每组条数不定**"：R1 有 3 条信息，别的路由器可能 4 条、5 条——这正是**邻接表**擅长的形状：表头结点存路由器 ID，后面挂一条变长的信息链；既不像邻接矩阵那样为"不存在的关系"浪费空间，也能适应各路由器信息条数的差异。信息分两类：Link（连到某路由器）与 Net（直连某网络），字段不同，所以弧结点用 `Flag` 区分类型、用 `union` 二选一存放（这是本题存储设计的给分点）。

数据类型定义（C 语言）：

`typedef struct { unsigned int ID, IP; } LinkNode;`（Link 记录：所连路由器 ID 与本地 IP）

`typedef struct { unsigned int Prefix, Mask; } NetNode;`（Net 记录：直连网络前缀与掩码）

`typedef struct Node { int Flag; union { LinkNode Lnode; NetNode Nnode; } LinkORNet; unsigned int Metric; struct Node *next; } ArcNode;`（弧结点）

`typedef struct HNode { unsigned int RouterID; ArcNode *LN_link; struct HNode *next; } HNODE;`（表头结点）

示意图组织：R1 的表头结点保存 Router ID `10.1.1.1`，信息链依次挂"到 R2 的 Link（10.1.1.2，费用 3）""到 R3 的 Link（10.1.1.5，费用 2）""直连网络 192.1.1.0/24 的 Net（费用 1）"；其余路由器同样组织，弧结点链尾指针为空。

### 第 3 问：R1 到各子网的最短路径及费用

Dijkstra 的机制一句话：**已定案集合逐点扩大**——每轮从"暂定距离最小的顶点"里挑一个宣布定案（因为所有边权非负，绕路只会更长，它的距离不可能再被改进），再用它松弛邻居。从 R1 出发，初始距离由直连链路给出：N1=1、R3=2、R2=3、其余无穷大。

| 步骤 | 操作 | 结果 |
|---|---|---|
| 1 | 选定 192.1.1.0/24（费用 1） | 直连定案 |
| 2 | 选定 R3（费用 2） | 经 L1 链路 |
| 3 | 经 R3 松弛 | N5=2+1=3；R4=2+6=8 |
| 4 | 选定 192.1.5.0/24（3） | 路径 R1-R3-N5 |
| 5 | 选定 R2（3）；经 R2 松弛 | N6=3+1=4；R4 更新为 3+4=7 |
| 6 | 选定 192.1.6.0/24（4）、R4（7） | 路径 R1-R2-N6 |
| 7 | 经 R4 松弛并选定 192.1.7.0/24 | N7=7+1=8，路径 R1-R2-R4-N7 |

**为什么 N7 取 8 不取 9**：到 N7 有两条候选——R1-R3-R4（2+6+1=9）与 R1-R2-R4（3+4+1=8）；松弛过程会把 R4 的暂定距离从经 R3 的 8 更新为经 R2 的 7，故 N7=7+1=8。

最终答案表：

| 目的网络 | 路径 | 费用 |
|---|---|---|
| 192.1.1.0/24 | 直接到达 | 1 |
| 192.1.5.0/24 | R1-R3-192.1.5.0/24 | 3 |
| 192.1.6.0/24 | R1-R2-192.1.6.0/24 | 4 |
| 192.1.7.0/24 | R1-R2-R4-192.1.7.0/24 | 8 |

### 易错点

- **答成树或线性结构**：多对多邻接 + 有回路，必须答"图（无向图）"。
- **漏掉 Flag/union**：Link 与 Net 字段不同，弧结点必须能区分并二选一存储，这是给分点。
- **最短路径只报费用不报路径**：第 3 问要求"路径及费用"两者都写全。
- **N7 误取 9**：只看了 R1-R3-R4 一条路，忘了 R2 方向的松弛会把 R4 的距离更新得更小。

> 记忆锚点：OSPF 链路状态 → 泛洪 LSI → 全网带权图；存储 → 表头 + 弧结点邻接表；算路 → Dijkstra 逐点定案、逐边松弛。
