## 本题讲解：先序序列固定时不同二叉树的个数

**答案：B（14 个）**

### 第一步：转化问题

先序序列固定为 `a,b,c,d`，意味着：给定一个树形（4 个结点的二叉树形态），按先序次序依次填入 a、b、c、d，标号方式**唯一**。反过来，不同的树形就得到不同的二叉树。所以本题等于问：**4 个结点的二叉树有多少种形态**。

### 第二步：用递推计数

设 f(n) 为 n 个结点的二叉树形态数。取 1 个结点做根，左子树 i 个结点、右子树 n−1−i 个结点，则：

`f(n) = f(0)·f(n−1) + f(1)·f(n−2) + … + f(n−1)·f(0)`，其中 f(0) = 1（空树）。

| n | 计算 | f(n) |
|---|---|---|
| 0 | 边界 | 1 |
| 1 | f0·f0 = 1 | 1 |
| 2 | f0·f1 + f1·f0 = 2 | 2 |
| 3 | f0·f2 + f1·f1 + f2·f0 = 5 | 5 |
| 4 | f0·f3 + f1·f2 + f2·f1 + f3·f0 = 5+2+2+5 | **14** |

### 第三步：卡特兰数验证

n 个结点的二叉树形态数就是卡特兰数：f(n) = C(2n, n) / (n+1)。代入 n=4：C(8,4)/5 = 70/5 = **14**，与递推一致。

### 易错点

- **误选 C（15）或 D（16）**：把"4 个结点的有序树/无标号树"等别的计数对象混进来，或忘记 f(0)=1 这一边界。
- **误以为标号还有自由度**：先序序列已把每个树形的标号唯一确定，不存在"同一树形多种标号"的放大效应。

> 记忆点：先序固定 → 数形态；形态数 = 卡特兰数 C(2n,n)/(n+1)，n=4 时为 14。
