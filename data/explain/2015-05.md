## 本题讲解：有向图从 v0 出发 DFS 的不同序列个数

**答案：D（5 个）**

### 第一步：整理邻接关系

有向图 G：`V={v0,v1,v2,v3}`，`E={⟨v0,v1⟩,⟨v0,v2⟩,⟨v0,v3⟩,⟨v1,v3⟩}`。

| 顶点 | 能直接到达 |
|---|---|
| v0 | v1, v2, v3（次序可任选） |
| v1 | v3 |
| v2 | 无 |
| v3 | 无 |

DFS 深度优先：访问某顶点后先递归访问它的全部可达未访问邻接点，回溯后再访问下一邻接点；起点固定为 v0。

### 第二步：按"第一个访问谁"分类枚举

- **先访问 v1**：v1 只能去 v3，v3 无出边，回溯到 v0 后只剩 v2 → `v0,v1,v3,v2`（1 种）
- **先访问 v2**：v2 无出边，回溯到 v0；第二个可任选 v1 或 v3 → `v0,v2,v1,v3`、`v0,v2,v3,v1`（2 种）
- **先访问 v3**：v3 无出边，回溯到 v0；第二个可任选 v1 或 v2 → `v0,v3,v1,v2`、`v0,v3,v2,v1`（2 种）

合计 1+2+2 = **5 种**。

### 易错点

- **漏数"先访问 v2/v3"的情形**：以为 DFS 必须按编号顺序访问邻居（那样只剩 1 种）。DFS 的邻接点访问次序取决于存储结构，题目问的是"可能得到"的不同序列个数。
- **忘记回溯后继续访问剩余邻居**：如 `v0,v1,v3` 之后必须回到 v0 再访问 v2，否则序列不完整。
- **忽略 v1→v3 的约束**：v1 在前时 v3 一定紧跟其后（v1 的唯一出边），所以 `v0,v1,v2,v3` 是不存在的。

> 记忆点：分类标准取"v0 之后第一个访问的顶点"，每类再枚举回溯后的选择，1+2+2=5。
