## 本题讲解：内存中磁盘缓冲区的主要目的

答案：**A**（减少磁盘 I/O 次数）。

### 第一步：磁盘缓冲区是什么

在**内存**中开辟一块区域缓存磁盘块内容：读盘前先查缓冲区，**命中**则直接从内存取数据，一次磁盘 I/O 都不做；未命中才真正读盘，并把该块存入缓冲区供下次使用。

### 第二步：为什么能省 I/O

- **读**：程序访问具有重复性与局部性，同一磁盘块短时间内常被多次读取，命中缓冲区就省掉一次读盘。
- **写**：写操作可先写入缓冲区，**延迟写 / 合并写**回磁盘，同样减少 I/O 次数。

磁盘 I/O 是慢操作（机械寻道 + 旋转等待），减少 I/O 次数就是提高速度——这就是"主要目的"。

### 第三步：排除干扰项

| 选项 | 为什么不对 |
|---|---|
| B 减少平均寻道时间 | 寻道由磁头机械移动决定，靠磁盘调度算法（SSTF、SCAN 等）优化，内存缓冲帮不上 |
| C 提高数据可靠性 | 靠冗余与备份（RAID、定期备份），缓冲区掉电反而可能丢数据 |
| D 实现设备无关性 | 靠设备独立性软件的逻辑设备表（LUT）等机制，与缓冲无关 |

### 易错点

- **误选 B**：把"缓冲"与"调度"混为一谈——寻道时间取决于磁头移动路线，内存缓冲影响不了它。
- **本末倒置**：提高速度是结果，手段是减少磁盘 I/O 次数；题目问"主要目的"，答手段的直接效果。

> 记忆锚点：缓冲区设在内存里，图的就是"能不碰盘就不碰盘"——减少磁盘 I/O 次数。
