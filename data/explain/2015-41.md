## 本题讲解：单链表按绝对值去重（以空间换时间）

### 问题（1）：算法的基本设计思想

**答案要点**：申请一个大小为 **n+1** 的辅助数组 q（下标对应绝对值 0~n），全部初始化为 0，用来记录"各绝对值是否已出现过"。从头到尾**只扫描链表一趟**：对每个结点取 `m = |data|`——若 `q[m] = 0`，说明首次出现，保留该结点并置 `q[m] = 1`；若 `q[m] = 1`，说明重复，修改前驱的 link 把该结点摘链并 free。用 O(n) 的空间把去重从"两两比较"降为"一趟扫描"，即**以空间换时间**。

示例：`21 → 15 → 15 → −7 → 15` 去重后为 `21 → 15 → −7`（保留每个绝对值的首次出现）。

### 问题（2）：结点数据类型定义

- 结点结构：`typedef struct node { int data; struct node *link; } NODE;`，其中 `data` 为结点数据（|data| ≤ n），`link` 为后继指针；
- 指针别名：`typedef NODE *PNODE;`

### 问题（3）：算法描述（与参考答案一致的 C 语言实现）

1. 函数入口：`void func(PNODE h, int n)`，h 指向链表的头结点；
2. 申请辅助空间：`q = (int *)malloc(sizeof(int) * (n + 1));`，申请 n+1 个辅助单元；
3. 初始化：用 for 循环把 `q[0..n]` 全部置 0（`*(q + i) = 0;`）；
4. 一趟扫描：`while (p->link != NULL)`，取绝对值 `m = p->link->data > 0 ? p->link->data : -p->link->data;`；
5. 若 `*(q + m) == 0`：说明该绝对值首次出现，登记 `*(q + m) = 1;` 并保留结点 `p = p->link;`；
6. 否则：说明重复出现，摘链删除——`r = p->link; p->link = r->link; free(r);`，此时 p 不动，继续检查新的 `p->link`；
7. 扫描结束后释放辅助数组：`free(q);`。

关键点：p 始终指向**已处理部分的前驱**，检查的是 `p->link`；删除结点时 p 保持不动（新的 `p->link` 还要继续检查），保留时 p 才后移。

### 问题（4）：时间与空间复杂度

链表被扫描一遍，每个结点只处理常数次：**时间复杂度 O(m)**（m 为链表结点数）；辅助数组大小 n+1：**空间复杂度 O(n)**。

### 易错点

- **删除结点时让 p 后移**：`p->link` 已换成新的结点，若再 `p = p->link` 会漏检一个结点——删除分支里 p 必须原地不动。
- **用两重循环两两比较**：能得到 O(1) 空间但时间 O(m²)，不符合"时间尽可能高效"的题目要求。
- **辅助数组开成 n 而不是 n+1**：绝对值最大可达 n，下标需要 0~n 共 n+1 个单元。
- **忘记释放 q**：算法结束前应 `free(q)`，避免内存泄漏。

> 一句话结论：辅助数组登记绝对值是否出现过，一趟扫描完成去重，时间 O(m)、空间 O(n)。
