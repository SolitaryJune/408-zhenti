## 本题讲解：批处理系统的三个命题逐个判

### 第一步：先给答案

答案：**A**（仅 II、III 正确）。

### 第二步：逐条判断

- **I 错误**：批处理系统追求吞吐率，作业成批提交、由系统自动依次处理，用户**全程不能干预**，谈不上"与计算机直接交互"。能"多用户直接交互"的是**分时系统**（时间片轮转、人机交互）。
- **II 正确**：批处理按内存中同时容纳的作业道数，分为**单道批处理**（内存一次只放一道作业，顺序执行）和**多道批处理**（多道作业同时驻留内存并发执行）。
- **III 正确**：多道批处理中 CPU 与 I/O 频繁切换：I/O 设备完成工作时发**中断请求**打断 CPU，CPU 执行中断处理程序做收尾并调度下一道作业——正是中断技术使 I/O 设备与 CPU 能并行工作。

### 易错点

- **把交互性安到批处理头上**：这是分时系统的特征，I 项的干扰来源。
- **漏掉 III**：以为"并行"必须多 CPU——单 CPU 下 I/O 与 CPU 并行靠的正是中断 + 多道程序设计。
- **认为单道批处理不算批处理**：II 项明确把两类都归入批处理系统。

> 结论：I 错、II 对、III 对，选 A。
