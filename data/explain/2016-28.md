## 本题讲解：分段地址转换的越界检查

### 第一步：转换流程

逻辑地址（段号 2，段内地址 400）。分段系统的转换顺序：**查段表 → 状态检查 → 权限检查 → 越界检查**（段内地址必须满足 0 ≤ 段内地址 < 段长），任何一步不过都触发异常，地址加法根本做不了。

### 第二步：查段表第 2 项

段 2：段长 **300**，内存起始地址 4000，权限读写，状态**在内存**。

- 状态"在内存"→ 不会产生**段缺失异常**（排除 A）；
- 权限"读写"、本次访问无权限冲突 → 不会产生**越权异常**（排除 C）。

### 第三步：越界检查

段内地址 400 ≥ 段长 300 → **越界异常**，转换到此终止。因为越界检查发生在地址相加之前，所以不可能得到 4000 + 400 = 4400（B 是跳过检查的陷阱）。

### 易错点

- **直接加出 4400**（B 项）：忘了分段的偏移量合法范围是 0 ≤ W < 段长，必须先比段长。
- **误判段缺失**（A 项）：段 2 状态明确是"在内存"，不在内存的是段 1。
- **误判越权**（C 项）：权限为"读写"，题目访问与之无冲突。

> 答案：**D**。段内地址 400 ≥ 段长 300，触发越界异常。
