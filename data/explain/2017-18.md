## 本题讲解：主存 MM 与控制存储器 CS 的对比

### 第一步：列对比表

| 维度 | 主存 MM | 控存 CS |
|---|---|---|
| 位置 | CPU 外 | CPU 内（微程序控制器中） |
| 存放内容 | 指令和数据 | 微指令（微程序） |
| 访问方式 | 按地址访问 | 按微地址访问 |
| 实现介质 | RAM 和 ROM | ROM |

### 第二步：逐项核对找"错误"项

- A：MM 在 CPU 外，CS 在 CPU 内，与上表相符，正确。
- B：说"MM 按地址访问，CS 按内容访问"——**错**。控存里的微指令也是按**微地址**逐条取出执行的；"按内容访问"是相联存储器（如 TLB）的特征。
- C：MM 存指令和数据、CS 存微指令，正确。
- D：MM 用 RAM 和 ROM 实现、CS 用 ROM 实现，正确。

### 第三步：结论

错误的叙述是 B，**答案：B**。

### 易错点

- **把"按内容访问"张冠李戴到控存**：那是相联存储器（CAM）、Cache 标记比较、TLB 的特征。
- **以为 CS 也在 CPU 外**：控存属于微程序控制器，位于 CPU 内部，程序员不能访问。

> 记忆锚点：控存存微指令、在 CPU 内、按微地址访问。
