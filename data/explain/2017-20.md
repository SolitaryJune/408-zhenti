## 本题讲解：多总线结构特性与 PCI-Express 的传输方式

**答案：D**（"PCI-Express×16 采用并行传输方式"错误）。

### 第零步：先立机制——总线为什么要分层次

CPU、主存、高速设备与低速设备速度相差悬殊：把所有设备挂在同一条总线上，最慢的设备会拖低整条总线的时序。所以采用**分层多总线**：越靠近 CPU 的总线越快（存储器总线最快），越往外越慢，让设备"各得其所"；不同总线的协议、时序、速率都不同，**必须通过桥接器**相连，由桥完成信号、协议与速度的转换；存储器总线还支持**突发（burst）传送**——给出一个首地址后连续传送一串数据，正合主存成块访问（如填充缓存行）的规律。

### 第一步：逐项核对

- A 对：靠近 CPU 的总线速度快，这是分层设计的初衷。
- B 对：存储器总线支持突发传送（一次给出首地址、连续读出一串数据）。
- C 对：总线之间必须通过桥接器相连（原因见第零步）。
- D 错：**为什么 ×16 不是并行？** PCI-Express 是**串行**点对点标准，×16 指 16 条 lane（通道），每条 lane 都是独立的串行差分线路对，数据在 lane 内逐位串行传输；并行传输是传统 PCI/ISA 共享总线的方式。

### 第二步：结论

错误的叙述是 D，选 **D**。

### 易错点

- **被"×16"迷惑**：×16 是 16 条串行 lane，不是 16 位并行总线。
- **混淆 PCI 与 PCI-Express**：PCI = 并行共享总线；PCIe = 串行点对点，靠 lane 数扩展带宽。

> 记忆锚点：分层总线 = 近快远慢 + 桥接转换；PCIe = 串行，lane 数只是通道条数。
