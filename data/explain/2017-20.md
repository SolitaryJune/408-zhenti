## 本题讲解：多总线结构特性与 PCI-Express 的传输方式

### 第一步：回忆多总线结构的要点

按速度分层挂接：越靠近 CPU 的总线越快（存储器总线最快），越往外越慢；不同总线之间必须通过桥接器相连，完成协议与速度的转换；存储器总线支持突发（burst）传送，给出一个首地址后连续传送一串数据。

### 第二步：逐项核对

- A 对：靠近 CPU 的总线速度快，这是分层设计的初衷。
- B 对：存储器总线可支持突发传送（如一次读出一个缓存行）。
- C 对：总线之间必须通过桥接器相连。
- D 错：PCI-Express 是**串行**点对点传输标准，×16 指 16 条 lane，每条 lane 都是独立的串行差分线路；并行传输是传统 PCI/ISA 的方式。

### 第三步：结论

错误的叙述是 D，**答案：D**。

### 易错点

- **被"×16"迷惑**：×16 是 16 条串行 lane 的意思，不是 16 位并行总线。
- **混淆 PCI 与 PCI-Express**：PCI 是并行共享总线，PCI-Express 是串行点对点。

> 记忆锚点：PCIe = 串行，lane 数只是通道条数。
