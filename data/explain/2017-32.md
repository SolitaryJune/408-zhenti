## 本题讲解：DMA 方式读磁盘的执行顺序

### 第一步：抓住 DMA 方式的分工

DMA 方式下，整块数据的传送由 **DMA 控制器（硬件）**完成，CPU 只负责两头的"启动"与"结束处理"。

### 第二步：按因果链排序

1. `②初始化 DMA 控制器并启动磁盘`：CPU 设置内存起始地址、传送字数等，发出读命令；
2. `③从磁盘传输一块数据到内存缓冲区`：CPU 转去做别的事，DMA 控制器独立完成整块传送；
3. `①DMA 控制器发出中断请求`：一块数据传完，DMA 向 CPU 报告完成；
4. `④执行"DMA 结束"中断服务程序`：CPU 响应中断做善后处理。

### 第三步：对照选项

正确顺序为 ②→③→①→④，即 **B**。

### 易错点

- **把中断请求放在最前**（对应 D）：中断是"传送完成"的报告，必然发生在数据传送（③）之后。
- **漏掉初始化**（对应 A）：不先初始化 DMA，硬件不知道往哪传、传多少。
- **以为 CPU 全程参与传送**：那是程序查询或中断方式；DMA 的卖点正是传送期间 CPU 可并行工作。

> 答案：**B**（②→③→①→④）。链条：CPU 初始化启动 → DMA 传数据 → DMA 发中断 → CPU 善后。
