## 本题讲解：表达式树转等价中缀表达式（中序遍历 + 动态括号）

答案要点：**中序遍历为骨架，非根非叶的结点在遍历左子树前补 `(`、遍历右子树后补 `)`**，两棵示例树分别输出 `(a+b)*(c*(-d))` 与 `(a*b)+(-(c-d))`。

### 第一问：为什么是"中序遍历 + 括号"——先把机制立起来

表达式树里，**操作符在内部结点、操作数在叶子**。树本身记录了完整的运算次序，但把它摊平成线性序列时信息会丢失：对任意结点，只有"左子树、根、右子树"这个顺序（即**中序遍历**）才能让操作符落在两个操作数中间，呈现"左操作数 ⊕ 右操作数"的中缀形态。

**那为什么还要加括号？** 中序序列本身只有符号、没有树形——不同形状的树可以输出同一段符号序列，运算次序无从恢复。括号的作用就是把丢失的"子表达式边界"标回来：题目要求"通过括号反映操作符的计算次序"，正是在补这条信息。

**括号加在哪，规则从哪来？** 看每个结点的角色：

- **叶子是操作数**——原子成分，它就是边界本身，不需要括号；
- **根结点是整个表达式**——整体之外没有更大的运算要裹住它，加外层括号纯属冗余；
- **其余内部结点是子表达式**——它的输出要作为一个整体去参与父结点的运算，必须把首尾圈起来，否则父结点的运算会"越界"混进来。

所以规则是：**非根且非叶的结点，前 `(` 后 `)`**。这个规则天然不漏——每个非叶结点的一对括号恰好圈住它整个子树的输出；偶尔多一层括号（如 `(a+b)+c` 的内层）不影响正确性，考试要的是"次序无歧义"。

**"根"怎么在递归里识别？** 给遍历函数带一个深度参数 `deep`：根为 1，每深入一层加 1。于是 `deep > 1` 与"非根"等价——这就是参考代码里 `if (deep > 1) printf("(")` 的来历。

### 第二问：算法实现（与参考答案同一口径）

```
void BtreeToExp(BTree *root, int deep) {
    if (root == NULL) return;                       // 空结点返回
    else if (root->left == NULL && root->right == NULL)
        printf("%s", root->data);                   // 叶结点：直接输出操作数
    else {
        if (deep > 1) printf("(");                  // 非根的子表达式先补左括号
        BtreeToExp(root->left, deep + 1);           // 递归左子树（左操作数）
        printf("%s", root->data);                   // 输出操作符
        BtreeToExp(root->right, deep + 1);          // 递归右子树（右操作数）
        if (deep > 1) printf(")");                  // 再补右括号
    }
}
void BtreeToE(BTree *root) { BtreeToExp(root, 1); } // 根深度为 1
```

两个实现细节的"为什么"：

- **判叶必须看孩子指针**：`data[10]` 是字符数组，操作数（如 `ab`）和操作符（如 `+`）都可能存在里面，从内容判叶不可靠；`left`、`right` 同时为 NULL 才是叶子的定义。
- **单目减为什么天然正确**：`−` 只有右孩子，递归左子树时遇到 NULL 直接返回，什么都不输出，于是打印出来就是 `-d`——不需要为单目运算符写任何特殊分支。

### 第三步：用题给两棵树走一遍验证

- 树1：根 `*`（deep=1，不加括号）；左子树 `+`（deep=2）输出 `(a+b)`；右子树 `*`（deep=2）内，`−`（deep=3）输出 `(-d)` → 整体 `(a+b)*(c*(-d))` ✓
- 树2：根 `+`（deep=1）；`*`（deep=2）输出 `(a*b)`；上层 `−`（deep=2，左孩子为空）内，深层 `−`（deep=3）输出 `(c-d)` → 整体 `(a*b)+(-(c-d))` ✓

### 易错点

- **根也加括号**：输出 `((a+b)*(c*(-d)))`，多一层冗余——`deep > 1` 判定正是为排除根。
- **叶结点也套括号**：`(a)+(b)` 不合题意——叶子是原子，加括号说明没分清"操作数"与"子表达式"。
- **单目减按双目处理**：`−` 左孩子为空，中序遍历自然跳过，输出 `-d`，不能人为补左操作数。
- **不处理括号**：输出 `a+b*c*-d`，次序信息全丢——本题考的正是"遍历骨架之外还要补括号"这半截。

> 一句话结论：中序遍历给出中缀骨架，"非根非叶结点前后补括号"补回树形结构信息；入口 `BtreeToE(root)` 调 `BtreeToExp(root, 1)`。
