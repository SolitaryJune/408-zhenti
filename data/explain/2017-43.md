## 本题讲解：unsigned 下溢、int 溢出与 float 舍入

**答题框架**：f(n) = 2^(n+1) − 1，即二进制 n+1 个 1。f1 用 int 累加（看表示范围），f2 用 float 累加（看有效位数与表示范围），循环跑 n 轮（i = 0 … n−1）后 sum = 2^(n+1) − 1。五个小问分别对应：无符号运算规则、24 位有效数字、舍入、int 上限、float 上限。

### 第（1）问：n=0 为何死循环

i、n 均为 unsigned。循环条件先算 `n−1`：无符号运算 0−1 下溢，机器数为 FFFFFFFFH（32 个 1），即 2^32 − 1，是 unsigned 能表示的最大值。于是 `i ≤ n−1` 恒成立，循环永不结束。若把 i、n 都改成 int：n−1 = −1，初始 i = 0，条件 `0 ≤ −1` 不成立，循环体一次都不执行，不会死循环。

### 第（2）问：f1(23) 与 f2(23)

n=23 时和 = 2^24 − 1 = 16 777 215，二进制恰好 24 个 1：

- f1（int）：在 32 位补码范围内，机器数 `00FFFFFFH`。
- f2（float）：IEEE 754 单精度有效数字 24 位（隐含首位 1 + 23 位尾数），24 个 1 恰好装下、无需舍入，机器数 = 0 | 10010110 | 111…1（阶码 23 + 127 = 150），即 `4B7FFFFFH`。

两者返回值相等（都是 16 777 215）。

### 第（3）问：f1(24) 与 f2(24) 为何不等

n=24 时和 = 2^25 − 1 = 33 554 431，二进制 25 个连续的 1，超出 float 的 24 位有效数字，累加时必须舍入：它恰好介于相邻浮点数 33 554 430 与 33 554 432 之间，按就近舍入得 33 554 432.0。int 不舍入，f1(24) = 33 554 431，故两者相差 1。

### 第（4）问：f1(31) 为何是 −1；最大 n

n=31 时和 = 2^32 − 1，超出 int 的表示上限 2^31 − 1，发生溢出：32 位全 1 按补码解释就是 −1。要 f1(n) 与 f(n) 相等，需 2^(n+1) − 1 ≤ 2^31 − 1，即 n ≤ 30，最大 n = 30。

### 第（5）问：f2(127) 与两个边界

| 循环里程碑 | f1 的 sum（int） | f2 的 sum（float） | 说明 |
|---|---|---|---|
| i=22 后（n=23 完成） | 16 777 215（00FFFFFFH） | 16 777 215.0（4B7FFFFFH） | 24 个 1，精确 |
| i=23 后（n=24 完成） | 33 554 431（01FFFFFFH） | 33 554 432.0（4B800000H） | 25 个 1，舍入 |
| i=30 后（n=31 完成） | FFFFFFFFH = −1 | 2^32（4F800000H） | int 溢出，float 是 2 的幂仍精确 |
| i=126 后（n=127 完成） | 早已溢出 | +∞（7F800000H） | 2^127 + 2^127 = 2^128 超上限 |

- f2(127) 的机器数 7F80 0000H 对应的值是**正无穷（+∞）**。
- 不溢出的最大 n：末轮和 2^(n+1) 不得超过 float 上限（约 (2 − 2^−23) × 2^127，略小于 2^128）→ n = 126。
- 结果精确（无舍入）的最大 n：和的有效位数 n+1 ≤ 24 → n = 23。

### 易错点

- **unsigned 的 0−1 不是 −1**：无符号运算直接下溢到 2^32 − 1，这是第（1）问的关键。
- **把 float 有效位数记成 23**：尾数 23 位 + 隐含首位 1 = 24 位有效数字。
- **混淆两个上限**：int 看范围（2^31 − 1，全 1 是 −1），float 既看精度（24 位有效数字）又看范围（约 2^128）。

> 一句话：f1 败在"范围"，f2 先败在"精度"（n ≥ 24 舍入）再败在"范围"（n ≥ 127 溢出）。
