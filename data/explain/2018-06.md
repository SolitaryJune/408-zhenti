## 本题讲解：二叉排序树的中序定序法

**答案：C。**

### 第一步：从图中读出树形

按结点层高与横向位置判定父子及左右：x1 位置最高是根；x2 在 x1 右下方，是 x1 的右孩子；x3 在 x2 左下方，是 x2 的**左**孩子；x4 在 x3 右下方，是 x3 的**右**孩子；x5 在 x4 左下方，是 x4 的**左**孩子。整棵树是一条之字形链。

### 第二步：中序遍历得到递增序列

二叉排序树的中序遍历（左·根·右）给出严格递增序列。逐个输出：x1（根，无左子树）→ 进入 x2 的左子树访问 x3 → x3 的右子树中先访问 x4 的左孩子 x5、再访问 x4 → 最后访问 x2。中序序列为 x1, x3, x5, x4, x2，于是 **x1 < x3 < x5 < x4 < x2**。

### 第三步：对照四个选项

| 选项 | 断言 | 判定 |
|---|---|---|
| A | x1 < x2 < x5 | x5 在 x2 左子树内，x5 < x2，错 |
| B | x1 < x4 < x5 | x5 是 x4 的左孩子，x5 < x4，错 |
| C | x3 < x5 < x4 | 与排序一致，对 |
| D | x4 < x3 < x5 | x4 在 x3 右子树内，x3 < x4，错 |

答案选 **C**。

### 易错点

- **只看相邻父子**：x5 与 x2 是祖先—后代关系，x5 在 x2 的子树中必大于 x2；不能只比较直接父子。
- **左右孩子看错**：左右由图中横向位置决定，x3 在 x2 左侧是左孩子；画得靠下不代表是右孩子。
- **不用中序而逐对猜**：先写出完整中序序列，再对选项逐条核对，又快又稳。

> 一句话：BST 中序即升序，本树中序为 x1 < x3 < x5 < x4 < x2，唯一正确的是 C。
