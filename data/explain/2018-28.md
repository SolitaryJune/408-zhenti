## 本题讲解：管程中条件变量 x.wait() 的语义

**答案：D。**

### 第一步：管程与条件变量的分工

管程保证**互斥**：任一时刻只允许一个进程在管程内活动。进程在管程内发现条件不满足时，用条件变量 x 的两个专用操作来等待与唤醒：

- `x.wait()`：条件不满足时，**把当前进程阻塞，并插入 x 的阻塞（等待）队列**，同时释放管程使用权；
- `x.signal()`：**唤醒** x 阻塞队列上的一个进程。

### 第二步：逐项排除

- **A**：对变量 x 的互斥访问由管程机制（进入/退出管程）自动保证，与 x.wait() 无关；
- **B**：唤醒 x 上阻塞的进程是 `x.signal()` 的职责；
- **C**：条件变量不是普通变量，没有可供判断的「值」，x.wait() 并不根据 x 的值做判断；
- **D**：正是 x.wait() 所做的工作——阻塞该进程并把它插入 x 的阻塞队列。

### 易错点

- **把条件变量当普通变量**：它内部只有等待队列和 wait/signal 两个操作，没有数值。
- **混淆 wait 与 signal**：wait = 阻塞 + 入队，signal = 唤醒。

> 结论：x.wait() 阻塞该进程并将之插入 x 的阻塞队列，选 **D**。
