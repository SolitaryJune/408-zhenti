## 本题讲解：找出未出现的最小正整数（空间换时间）

### 第（1）问：算法基本设计思想

关键观察：**答案只可能是 1 到 n+1 之间的某个整数**。数组只有 n 个元素，即使 1~n 全部出现，也刚好占满，此时答案是 n+1；否则 1~n 中必有缺失。因此只需判断 1~n 中谁没出现。

采用空间换时间：设标记数组 `B[n]`，`B[j]` 表示正整数 j+1 是否在 A 中出现过。先扫一遍 A：若 `1 ≤ A[i] ≤ n`，置 `B[A[i]-1] = 1`，越界值（负数、0、大于 n）一律忽略；再扫一遍 B：遇到第一个 `B[i] = 0` 就返回 `i+1`；若扫完没有 0，说明 1~n 全部出现，返回 `n+1`。

### 第（2）问：C 语言描述

按参考答案口径逐行给出（关键处已注注释）：

1. `int findMissingPositive(int A[], int n) {`
2. `    int i, j, a;`
3. `    int B[n];                    // 标记数组：B[j]=1 表示正整数 j+1 出现过`
4. `    for (j = 0; j < n; j++) B[j] = 0;        // 初始化为全 0`
5. `    for (i = 0; i < n; i++)`
6. `        if (A[i] > 0 && A[i] <= n) {         // 只标记 1~n 的有效值`
7. `            a = A[i];  B[a - 1] = 1;`
8. `        }`
9. `    for (i = 0; i < n; i++)`
10. `        if (B[i] == 0) break;                // 第一个未出现的正整数`
11. `    return i + 1;                            // 下标转数值；全出现时 i=n，返回 n+1`
12. `}`

### 第（3）问：复杂度分析

时间复杂度：初始化、标记、扫描各一遍，均为单重循环，共 **O(n)**。空间复杂度：辅助数组 B 大小为 n，为 **O(n)**。

### 示例演算（与题干两个例子核对）

- A = {-5,3,2,3}：标记 B[2]=1（值 3）、B[1]=1（值 2）、再次 B[2]=1（重复无影响）；第一个 0 在 B[0]，返回 0+1 = 1 ✓
- A = {1,2,3}：B 全部置 1；扫描无 0，i 走到 3，返回 3+1 = 4 ✓

### 易错点

- **答案范围想窄了**：只检查 1~n 会漏掉「全部出现返回 n+1」的情形。
- **不判范围直接标记**：负数、0 或超大值会使 B 下标越界，必须先判 `1 ≤ A[i] ≤ n`。
- **写成双重循环**：对每个正整数枚举查找是 O(n²) 的笨办法，标记法一遍即可。

> 一句话：答案必在 1~n+1；标记数组记「谁出现过」，第一个没标记的下标加 1 就是答案。
