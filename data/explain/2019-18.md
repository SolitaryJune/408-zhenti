## 本题讲解：流水线数据冒险的判定

答案：**C**（I2 和 I4）。

### 第一步：列写每条指令读、写的寄存器

数据冒险看寄存器上的时序冲突：前一条**写**某寄存器、后一条**读 / 写**同一寄存器（RAW / WAW）就有冒险；两条都只是**读**同一寄存器则不冲突。

| 指令 | 读取寄存器 | 写入寄存器 |
|---|---|---|
| I1 add s2, s1, s0 | s1, s0 | s2 |
| I2 load s3, 0(t2) | t2 | s3 |
| I3 add s2, s2, s3 | s2, s3 | s2 |
| I4 store s2, 0(t2) | s2, t2 | （写主存，不写寄存器） |

### 第二步：逐对检查

- I1 与 I3：I1 写 s2，I3 又读又写 s2 → RAW + WAW，有冒险。
- I2 与 I3：I2 写 s3，I3 读 s3 → RAW，有冒险。
- I2 与 I4：I2 只写 s3、读 t2；I4 只读 s2、t2 并写主存 → **没有公共的"写→读"寄存器**，无数据冒险。
- I3 与 I4：I3 写 s2，I4（store）要从 s2 取数据 → RAW，有冒险。

### 易错点

- **把 t2 当成 I2 与 I4 的冲突**：两条指令都"读"t2，多个读者相容，不构成冒险。
- **漏判 I3 与 I4**：store 也要从寄存器读数据（要存的数在 s2 里），写后读照样冒险。
- **以为 store 写寄存器**：store 的"目的地"是主存，不写任何寄存器。

> 记忆锚点：先写后读（RAW）/先写后写（WAW）同一寄存器才有冒险；store 只读寄存器、只写主存。
