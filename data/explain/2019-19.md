## 本题讲解：多通道存储器总线的带宽计算

答案：**B**（约 32 GB/s）。

### 第 0 步：先立机制——带宽在数什么

总线带宽 = 总线上每秒"流过"的字节数 = **每秒传输次数 × 每次传输的字节数**。对应到题目给的两个量：

- 工作频率 1333 MHz → 每秒 1333M 个传输节拍，每拍完成一次总线传输；
- 总线宽度 64 位 = 64 ÷ 8 = **8 B** → 每个节拍并行传送 8 个字节。

**为什么 1333 MHz 直接代入、不用再乘 2？** 题干明确说 1333 MHz 是"存储器总线的工作频率"，即数据在总线上的实际传输节拍已经给定，公式里的"每秒传输次数"就是它。若把 DDR（双倍速率）望文生义、再按双沿翻一倍，就多乘了一个 2——干扰项 C（64 GB/s）正是这么来的。

### 第 1 步：单通道带宽

1333M 次/秒 × 8 B = 10664 MB/s ≈ **10.66 GB/s**（选项 A 的数值）。

### 第 2 步：三通道并行求和

3 通道 = 3 条独立的存储器总线同时传数据，总带宽按倍数相加：

3 × 10.66 GB/s ≈ **31.98 ≈ 32 GB/s**，选 **B**。

| 项目 | 数值 |
|---|---|
| 单通道 | 1333 MHz × 8 B ≈ 10.66 GB/s |
| 三通道合计 | 10.66 × 3 ≈ 32 GB/s |

### 易错点

- **忘乘通道数** → 误选 A：只算了一条通道的 10.66 GB/s。
- **把 DDR 双沿再乘一次** → 误选 C：把题给工作频率当基频翻倍成 2666M 次/秒，得 64 GB/s；频率已代表传输节拍，不能重复翻倍。
- **通道数乘了两遍** → 误选 D：先按 3 通道并进宽度算出 32 GB/s，又把"3 通道"再乘一次得 96 GB/s；通道数只在"单通道 → 总带宽"这一步乘一次。

> 记忆锚点：总带宽 = 工作频率 ×（总线宽度 ÷ 8）× 通道数；每个因子只乘一次。
