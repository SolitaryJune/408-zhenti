## 本题讲解：森林与二叉树遍历的对应 + 由两序重建二叉树求后序

**答案：C**（T 的后根遍历 = b, f, e, d, c, a）。

### 第一步：套用遍历对应关系

森林 F 与对应二叉树 T 的固定映射：F 的**先根遍历 = T 的先序遍历**，F 的**中根遍历 = T 的中序遍历**。所以 T：先序 = a b c d e f，中序 = b a d f e c。

### 第二步：先序定根、中序分左右，递归重建 T

1. 先序第一个 **a 是根**；中序中 a 左侧 {b} 是左子树，右侧 {d, f, e, c} 是右子树。
2. 左子树：先序 b、中序 b → **b 是 a 的左孩子**（叶子）。
3. 右子树：先序 c d e f、中序 d f e c → 根 **c**；中序里 c 右侧为空 → c 无右孩子。
4. c 的左子树：先序 d e f、中序 d f e → 根 **d**；d 左侧为空 → d 无左孩子，{f, e} 是 d 的右子树。
5. 右子树：先序 e f、中序 f e → 根 **e**，其左孩子为 **f**（叶子），e 无右孩子。

树形：a 的左孩子是 b、右孩子是 c；c→d→e→f 为一条方向交替的单链（c 的左、d 的右、e 的左）。

### 第三步：左→右→根，写出后序

左子树只有 b；右子树 c 的子树内部按同样的规则先走深层：f、e、d，再输出 c；最后根 a。

**后序 = b, f, e, d, c, a**，选 **C**。

### 易错点

- **对应关系记反**：森林先根↔二叉树先序、森林中根↔二叉树中序；森林的后根才对应二叉树的中序。
- **单链方向画错**：c 只有左孩子 d，d 只有右孩子 e，e 只有左孩子 f——方向错则后序错。
- **先序定根、中序分左右**的次序不能乱：每次递归都先在先序段取第一个字符作根。

> 记忆：先转成二叉树（先根/中根 → 先序/中序），再按"左→右→根"写出后序。
