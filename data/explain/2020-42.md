## 本题讲解：前缀编码的二叉树保存、译码与判定

### 第一步（问 1）：哪种数据结构适宜

**二叉树**。把每个编码看成从根出发的一条 0/1 路径：左分支记 0、右分支记 1，**字符只存放在叶结点**上。因为叶子不可能出现在另一条路径的中间，任一编码自然不会是其他编码的前缀——前缀特性由这个结构自动保证。

### 第二步（问 2）：从 0/1 串到字符串的译码过程

1. 从**根结点**出发，读 0/1 串的当前位；
2. 该位为 0 走左孩子、为 1 走右孩子；
3. 到达**叶结点**即译出一个字符并输出，然后**回到根**继续读下一位；
4. 0/1 串读完，译码结束。

由于每个字符的根到叶路径唯一，译码结果也唯一。

### 第三步（问 3）：判定前缀特性 = 边建树边检查

初始只有根结点（左右指针均为空）。逐个读入编码 C，按位沿分支下行，遇到空指针就新建结点：

| 检查点 | 现象 | 结论 |
|---|---|---|
| 没扫完 C 就到达已有叶结点 | 已有编码是 C 的前缀 | 不具有前缀特性 |
| 扫完 C 却一个新结点都没建 | C 是某个已有编码的前缀 | 不具有前缀特性 |
| 恰在 C 的最后一位新建了叶结点 | C 与已有编码互不为前缀 | 通过，继续检查下一个 |

所有编码都通过检查，即该字符集的编码具有前缀特性。

### 易错点

- **把字符放进中间结点**：中间结点存字符会直接破坏前缀特性，字符只能放叶子上。
- **译码忘记回根**：每译出一个字符必须回到根，否则后续比特的对应关系全错。
- **判定漏掉第二种违规**：不仅"别人是 C 的前缀"违规，"C 是别人的前缀"（扫完不新建结点）同样违规。

> 记忆锚点：编码在叶、译码从根走、判定边建树边查"撞叶"与"空转"。
