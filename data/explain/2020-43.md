## 本题讲解：没有乘法指令怎么乘 + 乘积溢出判断

### 答题框架

先答"乘法 = 加法 + 移位"的软件循环（第 1 问），再说硬件化时控制逻辑管什么（第 2 问），然后比较三种实现耗时（第 3 问），最后用 64 位乘积做溢出判断（第 4 问）。

### 第 1）问：没有乘法指令为什么也能乘

乘法可以通过**加法和移位组成的循环程序**实现：按乘数的每一位判断，为 1 就把被乘数移位对齐后累加，循环 n 次。M 机的 ALU 能做加法，又有移位指令，所以用加、减、移位等指令写一个循环程序，就能完成 umul() 与 imul() 里的乘法运算。

### 第 2）问：控制逻辑的作用

用 ALU、位移器、寄存器以及相应控制逻辑实现乘法指令时，控制逻辑负责**控制循环次数**，并**控制每一步的加法和移位操作**（何时加、加到哪个寄存器、何时移位、移多少位）。

### 第 3）问：三种实现的执行时间

| 情况 | 实现方式 | 执行时间 |
|---|---|---|
| ① 无乘法指令 | 软件循环，要执行多条指令 | 最长 |
| ② ALU + 位移器 | 一条乘法指令，硬件按步循环 | 居中 |
| ③ 阵列乘法器 | 一条乘法指令，一个时钟周期并行完成 | 最短 |

情况①执行时间最长、情况③最短：①靠软件逐条执行指令；②③都是一条乘法指令，而 ③ 的阵列乘法器不需要逐步循环，一次即可得到结果。

### 第 4）问：64 位乘积与溢出

x = 2^31 − 1 = `7FFF FFFFH`，y = 2，n = 32：

- 真值 x×y = (2^31 − 1) × 2 = 2^32 − 2 = 4294967294，是正数；
- 2n = 64 位乘积，带符号与无符号两种乘法指令得到的结果相同：`00000000FFFFFFFEH`（书写分组即 `0000 0000 FFFF FFFEH`；真值为正且小于 2 的 63 次方，补码与无符号表示一致）；
- **umul()**：只取低 32 位 = `FFFF FFFEH` = 4294967294，与真值一致，**不溢出**；
- **imul()**：低 32 位 `FFFF FFFEH` 按补码解释是 −2，不等于真值 4294967294，**溢出**（低 32 位符号位为 1，高 32 位却是全 0，符号扩展不一致）；
- **无符号溢出判断**：仅取低 n 位作结果时，看 2n 位乘积的**高 n 位是否全为 0**——全 0 则不溢出，否则溢出。

### 易错点

- **以为带符号乘法的 64 位乘积不同**：真值是正数，两种解释的 64 位结果一样，都是 `0000 0000 FFFF FFFEH`。
- **溢出判断看错对象**：无符号乘法看高 n 位是否全 0，不看"符号"。
- **第 3 问排序记反**：软件循环（多条指令）最慢，阵列乘法器（一拍并行）最快。

> 乘法的本质是"加法 + 移位"；无符号溢出只看一句话：2n 位乘积的高 n 位是否全 0。
