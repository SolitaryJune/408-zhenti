## 本题讲解：判定顺序存储的二叉树是否为二叉搜索树

### 答题框架

两问：基本设计思想 + C 代码实现。核心认知：判定 BST **不能只比较“双亲与直接孩子”**，必须比较“双亲与整棵子树的最值”——左子树的最大值要小于双亲，右子树的最小值要大于双亲。用辅助数组 `pmin`、`pmax` 自底向上传播即可，时间 O(n)。

### 第 1）问：基本设计思想

1. 建立与顺序存储数组等长的辅助数组 `pmin`、`pmax`，`pmin[k]`、`pmax[k]` 表示以 k 号结点为根的子树中的最小值、最大值。
2. 初始化：`pmin[k] = pmax[k] = SqBiTNode[k]`（先认为子树最值就是结点自身）。
3. 从最后一个下标向 1 **倒序扫描**（保证处理双亲时其子树信息已就绪）：值为 −1 的空位跳过；`m = (k−1)/2` 为双亲下标。k 为奇数是左孩子：若双亲值 > `pmax[k]` 成立，则把 `pmin[k]` 传播给双亲；k 为偶数是右孩子：若双亲值 < `pmin[k]` 成立，则把 `pmax[k]` 传播给双亲；任一检查失败立即返回 false。
4. 循环完整结束（回到根）返回 true。

### 第 2）问：算法实现（与参考答案同口径）

- 初始化：`for (k = 0; k < bt.ElemNum; k++) pmin[k] = pmax[k] = bt.SqBiTNode[k];`
- 主循环：`for (k = bt.ElemNum - 1; k > 0; k--)`，空位用 `if (bt.SqBiTNode[k] != -1)` 跳过，`m = (k - 1) / 2;` 求双亲。
- 左孩子分支：`if (k % 2 == 1 && bt.SqBiTNode[m] > pmax[k]) pmin[m] = pmin[k];` —— 奇数下标 2m+1 是左孩子，合法才传播最小值。
- 右孩子分支：`else if (k % 2 == 0 && bt.SqBiTNode[m] < pmin[k]) pmax[m] = pmax[k];` —— 偶数下标 2m+2 是右孩子，合法才传播最大值。
- 失败出口：`else return false;`；全部通过后 `return true;`。

用题目数据验证：T1 依次检查 k=9（30 与 27）、k=6（60 与 80）、k=4、k=2、k=1 全部通过 ⇒ true；T2 在 k=10 通过后，k=4 处 30 是 50 的右孩子而 50 < pmin[4]=30 不成立 ⇒ false。

### 复杂度分析

每个下标只处理一次：时间复杂度 **O(n)**；pmin、pmax 两个辅助数组与 n 同规模：空间复杂度 **O(n)**。

### 易错点

- **只比较双亲与直接孩子**：T2 中 30 与 50 直接看是“右孩子比双亲小”可抓到，但若错误藏得更深（如 35 > 30 却越过了 50 的界限），必须靠子树最值传播才能抓住。
- **顺序扫描（k 从 0 递增）**：必须自底向上，否则处理双亲时子树的 pmin/pmax 还没算好，传播链断裂。
- **忘记跳过 −1 空位**：空位不是结点，拿去比较会误判；ElemNum 只限定扫描范围。
- **左右孩子奇偶写反**：奇数下标是左孩子、偶数下标是右孩子，分支判断一旦写反，检查与传播全错。

> 一句话：pmin/pmax 自底向上传播子树最值，左孩子比 pmax、右孩子比 pmin，时间 O(n)、空间 O(n)。
