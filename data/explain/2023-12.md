## 本题讲解：由主频与 CPI 求 GIPS 和用户 CPU 时间

**答案：C**（1.25GIPS，0.4ms）。

### 第一步：求指令执行速度

平均 CPI = 1.2 表示每执行一条指令平均花 1.2 个时钟周期。主频 1.5GHz 即每秒有 `1.5×10^9` 个时钟周期，故每秒执行的指令数 = `1.5×10^9 / 1.2 = 1.25×10^9` 条/秒，即 **1.25 GIPS**。

### 第二步：求用户 CPU 时间

先算程序共花多少周期：`5×10^5 × 1.2 = 6×10^5` 个周期；再除以每秒周期数：`6×10^5 / 1.5×10^9 = 4×10^-4 s = 0.4 ms`。

### 第三步：核对选项

| 选项 | 速度 | 时间 | 判定 |
|---|---|---|---|
| A | 0.8GIPS | 0.4ms | 速度算错 |
| B | 0.8GIPS | 0.4μs | 速度、单位都错 |
| C | 1.25GIPS | 0.4ms | 正确 |
| D | 1.25GIPS | 0.4μs | 单位错 1000 倍 |

### 易错点

- **公式写反**：0.8GIPS 来自 `1.2 / 1.5`，正确的是速度 = 主频/CPI = `1.5 / 1.2`。
- **ms 与 μs 混淆**：0.4ms = 400μs，两者差 1000 倍；先算出秒再化单位。
- **忘乘 CPI**：CPU 时间不是 `指令数/主频`，必须乘平均 CPI；也不是 `指令数×主频`。

> 一句话结论：速度 = 主频/CPI = 1.25 GIPS，用户 CPU 时间 = 指令数×CPI/主频 = 0.4 ms，选 C。
