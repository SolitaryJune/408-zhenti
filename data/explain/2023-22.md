## 本题讲解：三种 I/O 控制方式中「谁在干活」

**答案：C**（错误的是它）。

### 第一步：查询与中断方式——都靠 CPU 执行程序

- **查询方式**：CPU 反复执行查询程序，读设备状态、等就绪、再传数据——A 正确；
- **中断方式**：设备就绪后向 CPU 发中断请求，CPU 执行**中断服务程序**完成 I/O——B 正确。

### 第二步：DMA 方式——数据传送不靠 CPU 执行程序

DMA 方式下，主存与设备之间的数据传送由 **DMA 控制器（专用硬件）**控制：CPU 只需事先执行初始化程序（预处理：设置传送字数、主存起始地址、传输方向、启动 DMA），传送期间 CPU 可执行其他程序，传送结束后才回来做结束处理。数据传送阶段 CPU 并不执行什么「DMA 传送程序」——C 错误。

### 第三步：DMA 的适用场景

SSD、网络适配器等高速设备数据量大、速度快，用 DMA 可避免 CPU 逐字干预——D 正确。

### 易错点

- **以为 DMA 也靠程序**：DMA 的核心正是「硬件控制器接管数据传送」，传送期间不占 CPU 执行程序。
- **忽略 CPU 在 DMA 中的角色**：CPU 仍要做初始化（预置 DMA 控制器）与结束处理，但那不是传送本身。
- **方式与设备搭配记反**：低速设备适合查询/中断，高速块设备适合 DMA 或通道方式。

> 一句话结论：查询、中断由 CPU 执行程序完成 I/O；DMA 的数据传送由 DMA 控制器硬件完成，CPU 只做初始化和结束处理，C 错。
