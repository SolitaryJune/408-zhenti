## 本题讲解：位图法管理空闲页框的空间开销

答案：C（512KB）。

### 第一步：先算页框总数

位图管理空闲页框时，**每个页框对应位图中的 1 个比特**（0 空闲、1 已分配），所以先求物理内存被分成多少个页框：

页框数 = 物理内存 ÷ 页大小 = 16GB ÷ 4KB = 2³⁴ B ÷ 2¹² B = 2²² 个

其中 16GB = 16 × 2³⁰ B = 2³⁴ B，4KB = 2¹² B。

### 第二步：算位图大小并换算单位

位图共 2²² 个比特。注意选项单位都是 B（字节），要除以 8：

位图大小 = 2²² bit ÷ 8 = 2¹⁹ B = 512KB

逐步推导表：

| 步骤 | 计算 | 结果 |
|---|---|---|
| 物理内存换成字节 | 16GB = 2³⁴ B | 2³⁴ B |
| 页框数 | 2³⁴ ÷ 2¹² | 2²² 个 |
| 位图位数 | 每框 1 bit | 2²² bit |
| 位图字节数 | ÷ 8（即 ÷ 2³） | 2¹⁹ B |
| 换算 KB | 2¹⁹ B = 2⁹ KB | 512KB |

### 易错点

- **忘记除以 8**：把 2²² bit 直接当成 2²² B = 4MB，错选 D。
- **进率用错**：GB、KB 按 2 的幂换算（1GB = 2³⁰ B，1KB = 2¹⁰ B），这是 408 的默认口径。
- **混淆「页」与「页框」**：位图跟的是物理页框的个数，页大小只通过「页框数 = 内存 ÷ 页大小」起作用。

> 页框数 2²² 个 → 位图 2²² bit = 2¹⁹ B = 512KB，答案选 C。
