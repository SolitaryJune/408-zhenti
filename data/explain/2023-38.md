## 本题讲解：NAT 转发后的源 IP 地址

答案：A（195.123.0.33）。

### 第一步：NAT 在做什么

R2 是 NAT 路由器。私网主机 H（192.168.0.3）发出的分组源地址是私网地址；R2 向 Internet 转发前，会把**源 IP 改写为自己外网接口的全球（公网）地址**，并在 NAT 表中记录映射。私网地址在公网上不可路由，所以 C（192.168.0.1，R2 内网接口）和 D（192.168.0.3，H 原地址）直接排除。

### 第二步：R2 的外网接口地址是多少

拓扑中 R1 与 R2 之间的链路标注 195.123.0.34/30，即 R1 在这条链路上的接口地址为 195.123.0.34/30。/30 主机位 2 bit，块大小 4：

| 地址 | 角色 |
|---|---|
| 195.123.0.32 | 网络地址（不可分配） |
| **195.123.0.33** | **可用 → R2 的外网接口** |
| 195.123.0.34 | 可用 → 已被 R1 占用 |
| 195.123.0.35 | 广播地址（不可分配，对应干扰项 B） |

/30 只有两个可用主机地址，R1 用了 .34，R2 的外网接口只能是 **195.123.0.33**。

### 第三步：改写后分组的样子

经过 R2 转发后：源 IP 由 192.168.0.3 改写为 **195.123.0.33**（目的地址不变），选 **A**。

### 易错点

- **选 B（195.123.0.35）**：把 /30 的广播地址当成接口地址——/30 的 4 个地址首尾两个（网络地址、广播地址）不可用。
- **选 C 或 D**：以为源地址原样穿透或改写成内网网关地址——NAT 改写用的是**外网侧**的全球地址，内网接口地址和 H 的私网地址都不会出现在公网上。

> NAT 出去用「出接口的全球地址」；/30 只剩 .33 可用，选 A。
