## 本题讲解：四类"指令"中 CPU 能直接执行的是哪些

**答案：B（仅 II、III）**

### 第一步：分清四个层面

| 名称 | 所在层面 | 谁来"理解"它 |
|---|---|---|
| 伪指令 | 汇编源程序 | 汇编程序（翻译/展开，不生成对应机器码） |
| 汇编指令 | 汇编源程序 | 汇编程序（翻译成机器指令） |
| 机器指令 | 机器（ISA）级 | CPU 直接译码、执行 |
| 微指令 | 控制器（微程序级） | CPU 内控制存储器逐条取出执行 |

### 第二步：逐项判断

- **I 伪指令**：不是真正的指令，只是写给汇编程序看的"指示"（如把一段实现特定功能的指令序列定义成一个名字、分配存储单元），CPU 不认识 → 不能直接执行。
- **II 微指令**：存放于 CPU 内部控制存储器中，控制器取出后直接产生控制信号序列 → CPU（控制部件）能直接执行。
- **III 机器指令**：CPU 能理解并直接执行的对象正是机器指令 → 可以。
- **IV 汇编指令**：是机器指令的助记符文本，CPU 硬件"看不懂"符号文本，必须先经汇编程序翻译成机器指令 → 不是"直接"执行。

### 易错点

- **选 C 或 D（把汇编指令算进去）**：汇编指令与机器指令一一对应，但"直接执行"发生在翻译之后，CPU 不直接理解助记符文本。
- **漏掉微指令**：微指令虽在 CPU 内部的微体系结构层，但由控制器硬件直接执行，符合题意。

> 一句话结论：汇编层面的"指令"（伪指令、汇编指令）都要先过汇编程序这道关；机器指令由 CPU 直接执行，微指令由控制器直接执行——选 B。
