## 本题讲解：键盘中断服务结束时数据在哪里

答案：**C**（内核缓冲区）。跟着一个字符的旅程走一遍就清楚了。

### 第一步：字符的旅程

1. 用户敲键 → 键盘控制器把字符放入**自己的数据寄存器**，并向 CPU 发中断请求；
2. CPU 响应键盘中断（若处于用户态先切换到内核态），执行**键盘中断服务例程（ISR）**；
3. ISR 从键盘控制器的数据寄存器读出字符，写入**内核缓冲区**（键盘输入缓冲区）；
4. ISR 执行结束、中断返回。

所以「ISR 结束时」，字符已被搬离控制器寄存器、还没进入用户空间，正躺在**内核缓冲区**里。

### 第二步：排除干扰项

| 选项 | 判断 |
|---|---|
| A 用户缓冲区 | ✗ 要等用户进程发起 read() 时，才从内核缓冲区复制到用户缓冲区 |
| B CPU 通用寄存器 | ✗ 寄存器只是搬运时的临时落点，不是存放地 |
| C 内核缓冲区 | ✓ ISR 把字符写入这里后才结束 |
| D 键盘控制器的数据寄存器 | ✗ ISR 第一步就把它取走了，结束时早已清空 |

### 易错点

- **把「终点」当「中转」**：控制器数据寄存器只是硬件到 ISR 的交接点，不是最终存放位置。
- **提前把数据送到用户区**：读入用户缓冲区是用户进程 read 时的事，与 ISR 无关。

> 一句话结论：键盘中断服务例程把字符从控制器寄存器搬进内核缓冲区后结束——选 **C**。
