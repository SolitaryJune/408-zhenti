## 本题讲解：CSMA/CA 中隐藏站按 CTS 设置的 NAV

答案：**B**（354 μs）。

### 第一步：NAV 记录的是什么

802.11 用 RTS/CTS 预约信道：AP 回复 CTS 时，把「信道将被占用多久」写进 CTS 的持续时间字段；听到 CTS 的站点（包括无法听到 A 的隐藏站 B）据此设置 NAV，在 NAV 递减到 0 前不碰信道。B 听到的是 **AP 发出的 CTS**，所以 NAV 从 **CTS 传输结束**时刻起算，覆盖剩余的全部信道占用。

### 第二步：算数据帧的传输时延

1998 B × 8 = 15984 bit；54 Mb/s 下传输时延 = 15984 ÷ 54 Mb/s = **296 μs**。

### 第三步：从 CTS 结束起逐段累加

| 时段 | 时延 | 累计 |
|---|---|---|
| SIFS | 28 μs | 28 μs |
| 数据帧传输 | 296 μs | 324 μs |
| SIFS | 28 μs | 352 μs |
| ACK 传输 | 2 μs | **354 μs** |

NAV = 28 + 296 + 28 + 2 = **354 μs**，选 **B**。

### 易错点

- **误选 A（326 μs）**：漏掉了 ACK 之前的那一个 SIFS（28 + 296 + 2）。
- **误选 C（385 μs）/ D（513 μs）**：把与本预约无关的 RTS（3 μs）、多出来的 SIFS 甚至 DIFS（128 μs）也累加进去——B 只是听到 CTS 的隐藏站，NAV 只覆盖 CTS 结束之后的占用。
- **数据帧时延算错**：要按 1998×8 = 15984 bit 除以 54 Mb/s，别把字节当比特。

> 一句话结论：NAV = SIFS + 数据帧 + SIFS + ACK = 28 + 296 + 28 + 2 = **354 μs**，选 **B**。
