## 本题讲解：判定拓扑序列是否唯一（2019 编程风大题）

### 第 1 问：基本设计思想（4 分）

核心结论：**DAG 存在唯一拓扑序列 ⇔ 拓扑排序的每一步，入度为 0 的顶点有且仅有一个**。据此设计：

1. 由邻接矩阵统计所有顶点的入度（逐列求和），存入 degree 数组；
2. 重复：扫描入度表，统计入度为 0 的顶点个数——
   - 若 **0 个**：图中有环，不存在拓扑序列，返回 0；
   - 若 **≥2 个**：此时可任选其一排在下一位，拓扑序列不唯一，返回 0；
   - 若 **恰好 1 个**：删除该顶点（入度记 −1），并把它的所有邻接点入度减 1，继续下一轮；
3. 若每轮都恰好 1 个、且最终删除了全部 n 个顶点，返回 1。

### 第 2 问：C 语言描述（9 分）

| 行 | 代码 |
|---|---|
| 1 | `int uniquely(MGraph G) {` |
| 2 | `int *degree, i, j, count = 0;` |
| 3 | `degree = (int *)malloc(G.numVertices * sizeof(int));` |
| 4 | `for (j = 0; j < G.numVertices; j++) {` |
| 5 | `degree[j] = 0;` |
| 6 | `for (i = 0; i < G.numVertices; i++) degree[j] += G.Edge[i][j];  // 逐列求和=入度` |
| 7 | `}` |
| 8 | `int zero_count, zero_vertex;` |
| 9 | `while (count < G.numVertices) {` |
| 10 | `zero_count = 0; zero_vertex = -1;` |
| 11 | `for (j = 0; j < G.numVertices; j++)` |
| 12 | `if (degree[j] == 0) { zero_count++; zero_vertex = j; if (zero_count > 1) break; }` |
| 13 | `if (zero_count != 1) { free(degree); return 0; }  // 0个=有环，多个=不唯一` |
| 14 | `count++; degree[zero_vertex] = -1;  // 删除该顶点` |
| 15 | `for (j = 0; j < G.numVertices; j++)` |
| 16 | `if (G.Edge[zero_vertex][j] > 0) degree[j]--;  // 邻接点入度减1` |
| 17 | `}` |
| 18 | `free(degree); return 1;` |
| 19 | `}` |

### 第三步：复杂度与要点

邻接矩阵下每轮扫描 O(n)，最多 n 轮，时间复杂度 **O(n²)**，辅助空间 O(n)。关键得分点：① 建入度表逐**列**求和；② 每轮必须「有且仅有一个」入度 0 顶点，0 个与多于 1 个都要返回 0；③ 删除顶点用「入度记 −1」标记，避免重复选中。

### 易错点

- **只判有环不判并列**：只检查「是否存在拓扑序列」而漏掉「多于 1 个入度 0 顶点 → 不唯一」，是最常见的丢分点。
- **逐行求和当入度**：`Edge[i][j]` 中 i 是行（起点）、j 是列（终点），入度必须按**列**求和。
- **忘记恢复/释放**：malloc 后应 free；删除标记用 −1 而不是真的改矩阵。

> 一句话结论：跑一遍拓扑排序，每步入度 0 的顶点若始终唯一且能删完全部顶点则返回 1，否则返回 0。
