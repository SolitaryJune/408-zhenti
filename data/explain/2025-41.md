## 本题讲解：calMulMax——后缀最值一遍扫描求最大乘积

### 第 (1) 问：基本设计思想

朴素做法对每个 i 枚举所有 j ∈ [i, n−1]，时间 O(n²)。优化点藏在乘积的性质里：res[i] = max{A[i]·A[j] | i ≤ j ≤ n−1}，j 的取值范围就是"A[i] 及其右侧"，于是：

- 若 **A[i] ≥ 0**：A[i] 乘右侧**最大值** maxSuffix 得最大乘积；
- 若 **A[i] < 0**：负数乘越小的数越大，乘右侧**最小值** minSuffix 得最大乘积（负负得正）。

因此**从右向左**扫描数组，边扫边维护"当前位置及其右侧"的最小值 minSuffix 与最大值 maxSuffix：初值都取 A[n−1]；每到一个 i，先用 A[i] 更新两个后缀最值，再计算 res[i]——"先更新后计算"保证 j = i（与自身相乘）的情形被覆盖，与题设 0 ≤ i ≤ j 一致。

### 第 (2) 问：算法实现

- `void calMulMax(int A[], int res[], int n) {`
- `    if (n <= 0) return;`
- `    int minSuffix = A[n - 1];   // A[i..n-1] 的最小值`
- `    int maxSuffix = A[n - 1];   // A[i..n-1] 的最大值`
- `    for (int i = n - 1; i >= 0; --i) {`
- `        if (A[i] < minSuffix) minSuffix = A[i];   // 先更新后缀最值`
- `        if (A[i] > maxSuffix) maxSuffix = A[i];`
- `        if (A[i] >= 0) res[i] = A[i] * maxSuffix; // 非负 × 后缀最大`
- `        else res[i] = A[i] * minSuffix;           // 负数 × 后缀最小`
- `    }`
- `}`

用题例 A = {1, 4, −9, 6} 验证：i=3 时 res[3]=6×6=36；i=2 时 minSuffix 更新为 −9，res[2]=(−9)×(−9)=81；i=1 时 res[1]=4×6=24；i=0 时 res[0]=1×6=6，得 res={6,24,81,36}，与题面一致。

### 第 (3) 问：复杂度

数组只被扫描一遍、每个元素做常数次比较与乘法：时间复杂度 **O(n)**；只用 minSuffix、maxSuffix 两个辅助变量，额外空间复杂度 **O(1)**。

### 易错点

- **漏掉 j = i（自身相乘）**：−9 的答案是 (−9)×(−9)=81 而不是 −54；"先更新最值、再算 res[i]"正是为此。
- **负数时误配后缀最大值**：负 × 最大反而更小，必须配后缀**最小**值。
- **从左往右扫**：需要的是"右侧"的最值，只能从右向左维护。

> 一句话：res[i] 只由 A[i] 的符号与右侧最值决定，一趟逆序扫描 O(n) 完成、O(1) 空间。
