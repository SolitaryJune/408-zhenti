## 本题讲解：二叉搜索树中找与 k 差值最小的结点

### 第一步：问 1 —— 答题框架（4 分）

设计思想按「怎么走、记什么、何时停」三句话给足：

1. **怎么走**：利用二叉搜索树的有序性，按「查找 k」的方式从根出发沿一条**向下的单一路径**查找：当前结点值大于 k 就进入左子树，小于 k 就进入右子树，直到遇到空指针。
2. **记什么**：行进途中**沿途记录**差值绝对值最小的结点。若某结点值恰好等于 k，差值绝对值为 0，结果只含这一个结点；若不相等，结果最多包含两个结点（k 上下两侧各一个候选），差值绝对值大于 0。
3. **何时停**：走到空指针或已命中 k 时结束，输出差值绝对值与对应结点的关键字。

### 第二步：为什么只需考察路径上的结点（问 1 的得分点）

设当前结点值为 v：
- v > k 时，右子树中所有值都不小于 v，它们与 k 的差都大于 v−k，不可能是更优答案，候选只可能是当前结点或/及左子树中的结点，沿 left 指针继续；
- v < k 时对称，候选只可能是当前结点或/及右子树中的结点，沿 right 指针继续。

每一步要么结束、要么范围缩到一棵子树，因此路径上的结点已覆盖全部候选，时间复杂度为 O(h)（h 为树高），空间 O(1)。

### 第三步：问 2 —— 算法实现（9 分）

用 p 沿路径下行，min 记当前最小差值，pmin1、pmin2 记录取得最小差值的结点（最多两个）：

| 行 | 代码 |
|---|---|
| 1 | `void searchX(BTree root, int k) {` |
| 2 | `    BTree p = root, pmin1, pmin2;` |
| 3 | `    int min = MAX;  // MAX 为能表示的整型最大值` |
| 4 | `    if (p == NULL) return;  // 空树直接返回` |
| 5 | `    while (p != NULL) {` |
| 6 | `        if (p->data == k) {  // 命中 k：差值 0，结果唯一` |
| 7 | `            min = 0;` |
| 8 | `            printf("差值绝对值 = %d 结点 = %d\n", min, p->data);` |
| 9 | `            return;` |
| 10 | `        }` |
| 11 | `        else if (abs(p->data - k) < min) {  // 出现差值更小的结点` |
| 12 | `            min = abs(p->data - k);` |
| 13 | `            pmin1 = pmin2 = p;` |
| 14 | `        }` |
| 15 | `        else if (abs(p->data - k) == min)  // 出现另一个同差值结点` |
| 16 | `            pmin2 = p;` |
| 17 | `        if (p->data > k) p = p->left;   // 候选还可能在左子树` |
| 18 | `        else p = p->right;              // 候选还可能在右子树` |
| 19 | `    }` |
| 20 | `    if (pmin1->data != pmin2->data)  // 两个候选` |
| 21 | `        printf("差值绝对值 = %d 结点 1 = %d 结点 2 = %d\n", min, pmin1->data, pmin2->data);` |
| 22 | `    else  // 只有一个候选` |
| 23 | `        printf("差值绝对值 = %d 结点 = %d\n", min, pmin1->data);` |
| 24 | `}` |

### 第四步：一个演算实例

取 BST：50 的左孩子 30（30 的孩子为 20、40，40 的左孩子 35），右孩子 70（孩子 60、80）。令 k = 45：

| p 指向 | 差值绝对值 | 动作 | min / pmin1 / pmin2 |
|---|---|---|---|
| 50 | 5 | 记录；50 大于 45，走左 | 5 / 50 / 50 |
| 30 | 15 | 不更新；30 小于 45，走右 | 5 / 50 / 50 |
| 40 | 5 | 等于 min，pmin2 = 40；40 小于 45，走右 | 5 / 50 / 40 |
| NULL | — | 循环结束，输出 | 差值 5，结点 50 与 40 |

### 易错点

- **全树遍历**：中序遍历全树虽然正确，但为 O(n)，没有利用 BST 的有序性，不满足「尽可能高效」。
- **只记一个候选**：k 恰好落在两个结点值正中间时，差值最小者有两个，漏掉 pmin2 会丢解。
- **忘记 k 等于某结点值的情形**：此时差值 0 且唯一，应立即输出返回，否则会继续误判。
- **空树未处理**：入口处判 root 是否为 NULL，避免解引用空指针。

> 一句话结论：沿 BST 查找路径边走边记最小差值，命中即返回，走到空指针时路径上的候选至多两个，时间 O(h)、空间 O(1)。
