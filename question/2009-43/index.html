计算机的性能指标I/O方式
综合应用题 8 分

某计算机的 CPU 主频为 500MHz，CPI 为 5（即执行每条指令平均需 5 个时钟周期）。假定某外设的数据传输率为 0.5MB/s，采用中断方式与主机进行数据传送，以 32 位为传输单位，对应的中断服务程序包含 18 条指令，中断服务的其他开销相当于 2 条指令的执行时间。请回答下列问题，要求给出计算过程。
1）在中断方式下，CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少？
2）当该外设的数据传输率达到 5MB/s 时，改用 DMA 方式传送数据。假定每次 DMA 传送块大小为 5000B，且 DMA 预处理和后处理的总开销为 500 个时钟周期，则 CPU 用于该外设 I/O 的时间占整个 CPU 时间的百分比是多少（假设 DMA 与 CPU 之间没有访存冲突）？

答案

（1）外设的数据传输率为 0.5 MB/s，中断方式每次传送 4 B。CPU 每次中断用于数据传送的时钟周期数为

5×18+5×2=100

每秒申请中断的次数为

0.5 MB4 B=125 000

因此，1 s 内的中断开销为

100×125 000=12 500 000=12.5 M 个时钟周期

CPU 主频为 500 MHz，故 CPU 用于该外设 I/O 的时间占比为

12.5 M500 M=2.5%

（2）改用 DMA 后，外设的数据传输率为 5 MB/s，每次 DMA 传送 5000 B，因此每秒产生的 DMA 次数为

5 MB5000 B=1000

CPU 每次 DMA 处理需 500 个时钟周期，故每秒总开销为

1000×500=500 000=0.5 M 个时钟周期

CPU 用于该外设 I/O 的时间占比为

0.5 M500 M=0.1%

本题讲解：中断方式与 DMA 方式的 CPU 时间占比

第一步：答题框架

占比 = 每秒 CPU 为该外设花掉的时钟周期数 ÷ CPU 每秒总时钟周期数（主频 500MHz）。两条路线都按「每秒事件次数 × 每次开销」先算分子。

第二步：问 1——中断方式（0.5MB/s，每次传 32 位 = 4B）

  1. 每秒中断次数：0.5MB ÷ 4B = 125000 次
  2. 每次中断开销：服务程序 18 条指令 + 其他开销折合 2 条 = 20 条 × CPI 5 = 100 个时钟周期
  3. 每秒开销：100 × 125000 = 12.5M 个周期
  4. 占比：12.5M ÷ 500M = 2.5%

第三步：问 2——DMA 方式（5MB/s，块 5000B）

  1. 每秒 DMA 次数：5MB ÷ 5000B = 1000 次
  2. CPU 只承担预处理和后处理，每次共 500 个周期；数据传送本身由 DMA 控制器完成，不占 CPU 时间
  3. 每秒开销：1000 × 500 = 0.5M 个周期
  4. 占比：0.5M ÷ 500M = 0.1%

易错点

  • 漏掉「其他开销相当于 2 条指令」：只按 18 条算得 90 周期、占比 2.25%。
  • 把 DMA 数据传送时间计入 CPU 开销：题目假设 DMA 与 CPU 无访存冲突，传送不占 CPU。
  • 单位换算：0.5MB/s 即每秒 0.5 × 10^6 字节；主频 500MHz 即每秒 500 × 10^6 个时钟周期，直接用 M 比较即可。
结论：中断方式 2.5%，DMA 方式 0.1%——DMA 用「整块一次预处理/后处理」替代「每 4B 一次中断」，CPU 负担大幅减轻。
