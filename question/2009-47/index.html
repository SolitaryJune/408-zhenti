计算机网络

2009-47

IPv4网络层设备
essay 9 分

（9分）某网络拓扑如下图所示，路由器 R1 通过接口 E1、E2 分别连接局域网 1、局域网 2，通过接口 L0 连接路由器 R2，并通过路由器 R2 连接域名服务器与互联网。R1 的 L0 接口的 IP 地址是 202.118.2.1，R2 的 L0 接口的 IP 地址是 202.118.2.2，L1 接口的 IP 地址是 130.11.120.1，E0 接口的 IP 地址是 202.118.3.1，域名服务器的 IP 地址是 202.118.3.2。
R1 和 R2 的路由表结构为

[目的网络 IP 地址 | 子网掩码 | 下一跳 IP 地址 | 接口]

1）将 IP 地址空间 202.118.1.0/24 划分为 2 个子网 分别分配给局域网 1、局域网 2，每个局域网需分配的 IP 地址数不少于 120 个。请给出子网划分结果，说明理由或给出必要的计算过程。
2）请给出 R1 的路由表，使其明确包括到局域网 1 的路由、局域网 2 的路由、域名服务器的主机路由和互联网的路由。
3）请采用路由聚合技术，给出 R2 到局域网 1 和局域网 2 的路由。

答案

【答案】

1）子网划分结果：

  • 子网1：202.118.1.0/25
  • 子网2：202.118.1.128/25
  • 分配方案（两种均可）：
  • 方案一：子网1分配给局域网1，子网2分配给局域网2。
  • 方案二：子网1分配给局域网2，子网2分配给局域网1。
  • 理由： 为满足每个局域网不少于120个主机地址的需求（27-2=126），主机位需至少7位，子网位需1位，故子网掩码为 /25。

本题讲解：子网划分与两级路由表配置

第 0 步：机制先行——路由器查表的三条规则

后面三问全都建立在这几条机制上，先立起来：

  1. 掩码匹配：表项匹配的条件是「目的地址 AND 子网掩码 = 表项里的目的网络地址」；掩码中 1 的位数就是前缀长度（/25 → 前 25 位全 1）。
  2. 最长前缀优先：多条表项同时匹配时，取前缀最长的——这条规则解释了为什么 /32 主机路由能压过 /0 默认路由被优先选中。
  3. 直连路由免下一跳：目的网络直接挂在本路由器接口所在的链路上，交付由本机接口完成，下一跳写「直接」。

问 1：划分两个子网——先定主机位，再借子网位

为什么计算要减 2？ 一个子网内主机位全 0 是网络地址、全 1 是广播地址，都不能分配给主机，可用地址数 = 2h − 2。

设主机位为 h：2⁶ − 2 = 62 < 120 不够；2⁷ − 2 = 126 ≥ 120 够 → h = 7。/24 本有 8 个主机位，只用 7 位，剩下 1 位借作子网位 → 前缀 /25，掩码 255.255.255.128。子网位取 0/1，把原 /24 从中间一分为二：

子网地址范围分配（方案一）
202.118.1.0/25202.118.1.0 ～ 202.118.1.127局域网 1（E1）
202.118.1.128/25202.118.1.128 ～ 202.118.1.255局域网 2（E2）

（两子网对调分配的方案二同样得分，但第 2、3 问的表必须与所选方案前后一致。）

问 2：R1 的路由表——四条路由各自的道理

目的网络 IP 地址子网掩码下一跳 IP 地址接口
202.118.1.0255.255.255.128直接E1
202.118.1.128255.255.255.128直接E2
202.118.3.2255.255.255.255202.118.2.2L0
0.0.0.00.0.0.0202.118.2.2L0
  • 两条直连路由：两个局域网分别挂在 E1、E2 上，按规则 3 下一跳写「直接」。
  • 主机路由为什么是 /32：域名服务器 202.118.3.2 是一台主机，题目点名要「主机路由」——掩码 32 位全 1，使该表项只匹配它自己；若写成 /24 匹配的就是整个 202.118.3.0/24 网段，不是主机路由。它不在 R1 的直连链路上，须先交给 R2，故下一跳 = R2 的 L0 地址 202.118.2.2，从 L0 口发出。
  • 默认路由为什么是 0.0.0.0/0：掩码全 0 时「目的地址 AND 0 = 0」对任何地址恒成立——它匹配一切目的地址，是兜底表项；去互联网的流量除以上三条外全部走它，下一跳同样是 R2。它只在其他三条都不匹配时才被选中，这一优先顺序正是由最长前缀规则（规则 2）保证的。

问 3：R2 的聚合路由——为什么能合成一条

R2 到两个局域网的下一跳完全相同（都是 R1 的 L0 接口 202.118.2.1），这是聚合的前提。两个 /25 子网地址连续（0～127 与 128～255）、前 24 位完全相同，合并后边界对齐恰好铺满一个 /24 → 聚合为一条：

目的网络 IP 地址子网掩码下一跳 IP 地址接口
202.118.1.0255.255.255.0202.118.2.1L0

聚合后 R2 凡见 202.118.1.x 一律交给 R1，再由 R1 用自己的两条 /25 表项区分两个局域网——聚合只发生在「下一跳相同」的边界处，表项数从两条减为一条，这正是路由聚合的价值所在。

易错点

  • 主机位算少：2⁶ = 64 忘了减 2 → 62 < 120 不满足；必须 2⁷ − 2 = 126 才够。
  • 主机路由掩码写 /24：匹配的是网段不是主机，不符合「主机路由」要求。
  • 聚合掩码写 /25：题目要求「采用路由聚合技术」给出一条路由，须聚合到 /24（255.255.255.0）。
  • 下一跳方向写反：R1 的下一跳指向 R2 的 L0（202.118.2.2），R2 的聚合路由下一跳指回 R1 的 L0（202.118.2.1）。
一句话结论：/25 一切为二（126 ≥ 120）；R1 = 两条直连 + 一条 /32 主机路由 + 一条默认路由；R2 聚合为 202.118.1.0/24 交给 R1。
