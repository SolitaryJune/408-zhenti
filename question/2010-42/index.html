线性表的顺序表示算法和算法评价
综合应用题 13 分

设将 n（n > 1）个整数存放到一维数组 R 中。试设计一个在时间和空间两方面都尽可能高效的算法，将 R 中保存的序列循环左移 p（0 < p < n）个位置，即将 R 中的数据由 (x0, x1, …, xn-1) 变换为 (xp, xp+1, …, xn-1, x0, x1, …, xp-1)。要求：
1）给出算法的基本设计思想。
2）根据设计思想，采用C、C++或Java语言描述算法，关键之处给出注释。
3）说明你所设计算法的时间复杂度和空间复杂度。

答案

答案：

（1）算法基本设计思想
将数组视为前p个元素组成的子数组a和后n-p个元素组成的子数组b。通过三次逆置操作实现循环左移：先逆置a，再逆置b，最后逆置整个数组。即先将数组ab转换为a⁻¹b，再转换为a⁻¹b⁻¹，最终得到ba。

（2）算法描述（C语言）

void Reverse(int R[], int from, int to) {
    int i, temp;
    for (i = 0; i < (to - from + 1) / 2; i++) {
        temp = R[from + i];
        R[from + i] = R[to - i];
        R[to - i] = temp;
    }
}

void Converse(int R[], int n, int p) {
    Reverse(R, 0, p - 1);       // 逆置前p个元素
    Reverse(R, p, n - 1);       // 逆置后n-p个元素
    Reverse(R, 0, n - 1);       // 逆置整个数组
}

（3）时间复杂度和空间复杂度
时间复杂度：O(n)，其中三次逆置操作总代价为O(p + (n-p) + n) = O(n)。
空间复杂度：O(1)，仅使用常数个临时变量。

本题讲解：三次逆置实现循环左移 p 个位置

第 1 问：算法基本设计思想

把数组看成两段：a = 前 p 个元素（下标 0 到 p−1），b = 后 n−p 个元素（下标 p 到 n−1），目标就是把 ab 变成 ba。直接搬移需要辅助数组，而三次逆置可以原地完成：记 aR 表示把 a 逆置，

  1. 先逆置 a：数组变为 aR b；
  2. 再逆置 b：变为 aR bR；
  3. 最后整体逆置：aR bR 的逆置恰为 b a，即循环左移 p 位的结果。

第 2 问：算法描述（C 语言）

逆置函数与主函数的关键语句：

  • void Reverse(int R[], int from, int to)：下标 i 从 from 起走到区间中点，循环体做三步——temp = R[from+i]，R[from+i] = R[to-i]，R[to-i] = temp，即两端逐对交换；
  • 主函数 Converse(int R[], int n, int p) 依次调用三次：Reverse(R, 0, p-1) 注释为「逆置前 p 个元素」；Reverse(R, p, n-1) 注释为「逆置后 n-p 个元素」；Reverse(R, 0, n-1) 注释为「逆置整个数组」。

以 n=6、p=2、R = (x0, x1, x2, x3, x4, x5) 演示：

操作结果
初始x0 x1 x2 x3 x4 x5
逆置前 p 个x1 x0 x2 x3 x4 x5
逆置后 n−p 个x1 x0 x5 x4 x3 x2
整体逆置x2 x3 x4 x5 x0 x1

末行正是循环左移 2 位后的序列。

第 3 问：时间复杂度与空间复杂度

三次逆置的对换总次数为 p + (n−p) + n = 2n，时间复杂度 O(n)；整个过程只用一个辅助变量 temp，空间复杂度 O(1)。

易错点

  • 逆置顺序颠倒：必须「先局部、后整体」；先整体逆置再局部会得到错误排列。
  • 边界写错：前段是 0 到 p−1，后段是 p 到 n−1，两段恰好拼满 n 个元素；把 p−1 写成 p 会多翻一个元素。
结论：三次逆置、原地完成，时间 O(n)、空间 O(1)，是该问题的最优解法之一。
