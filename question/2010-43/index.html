指令系统指令的寻址方式CPU的功能和基本结构
综合应用题 11 分

某计算机字长为16位，主存地址空间大小为128KB，按字编址。采用单字长指令格式，指令各字段定义如下图所示。

转移指令采用相对寻址方式，相对偏移量用补码表示，寻址方式定义见下表。

请回答下列问题：
1）该指令系统最多可有多少条指令？该计算机最多有多少个通用寄存器？存储器地址寄存器（MAR）和存储器数据寄存器（MDR）至少各需要多少位？
2）转移指令的目标地址范围是多少？
3）若操作码 0010B 表示加法操作（助记符为 add），寄存器 R4 和 R5 的编号分别为 100B 和 101B，R4 的内容为 1234H，R5 的内容为 5678H，地址 1234H 中的内容为 5678H，地址 5678H 中的内容为 1234H，则汇编语言为 “add(R4),(R5)+”（逗号前为源操作数，逗号后为目的操作数）对应的机器码是什么（用十六进制表示）？该指令执行后，哪些寄存器和存储单元中的内容会改变？改变后的内容是什么？

答案

（1）指令系统最多有16条指令，最多有8个通用寄存器，MAR至少需要16位，MDR至少需要16位。

（2）转移指令的目标地址范围是0000H-FFFFH（0～65535）。

（3）机器码为2315H。指令执行后，寄存器R5的内容变为5679H，存储单元5678H中的内容变为68ACH。

自评得分：
43

本题讲解：单字长指令格式与 add (R4),(R5)+ 的机器码

答题框架：先由字段宽度推出指令数、寄存器数与 MAR/MDR 位数 → 再由相对寻址定目标地址范围 → 最后按字段把汇编拼成机器码并推演执行。

第(1)问：指令数、寄存器数与 MAR/MDR

  • 指令字长 16 位，操作码占 4 位 → 最多 2^4 = 16 条指令。
  • 寄存器编号占 3 位 → 最多 2^3 = 8 个通用寄存器。
  • 主存 128KB、按字编址、字长 16 位（2B）→ 共 128KB ÷ 2B = 64K = 2^16 个字单元 → MAR 至少 16 位；每次按字存取 → MDR 至少 16 位。

第(2)问：转移指令的目标地址范围

相对寻址：目标地址 = (PC) + 偏移量（补码）。PC 为 16 位、偏移量按 16 位参加运算（模 2^16），结果落回 16 位地址空间 → 目标地址可覆盖整个主存空间 0000H ~ FFFFH（0～65535）。

第(3)问：机器码与执行结果

按字段拆解汇编 add (R4),(R5)+（逗号前为源、逗号后为目的）：

字段含义编码
OPadd 操作码0010
Ms / Rs源：寄存器间接 (R4)，R4 编号 100001 / 100
Md / Rd目的：寄存器间接自增 (R5)+，R5 编号 101010 / 101

拼接：0010 0011 0001 0101B = 2315H。

执行推演（(Rn)+ 先取数、后自增）：

步骤结果
取源操作数(R4) = 1234H → 访存读 (1234H) = 5678H
取目的操作数(R5) = 5678H → 访存读 (5678H) = 1234H
加法写回5678H + 1234H = 68ACH → 送存储单元 5678H
目的寄存器自增(R5) + 1 = 5679H → 写回 R5

即执行后 R5 = 5679H、存储单元 5678H 的内容 = 68ACH；R4 与 1234H 单元内容不变。

易错点

  • 源/目的字段位置弄反：机器码低 3 位 Rd = 101 对应目的 (R5)+，拼出来才是 2315H。
  • 漏掉 (Rn)+ 的自增：先按 (R5) 取目的操作数，取完才 +1，R5 变为 5679H。
  • 加法写回位置搞错：是"目的 ← 源 + 目的"，68ACH = 5678H + 1234H，写回 5678H 单元，1234H 单元不动。
一句话结论：16 条指令、8 个通用寄存器、MAR/MDR 至少各 16 位；转移目标地址 0000H~FFFFH；机器码 2315H，执行后 R5 = 5679H、(5678H) = 68ACH。
