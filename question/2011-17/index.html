某机器有一个标志寄存器，其中有进位/借位标志CF、零标志ZF、符号标志SF和溢出标志OF，条件转移指令bgt（无符号整数比较大于时转移）的转移条件是__。

答案

答案：C

17

本题讲解：无符号整数 bgt 的转移条件

第一步：先给答案

答案：C，即"CF + ZF 取反 = 1"，等价于 CF = 0 且 ZF = 0（无借位且结果非零）。

第二步：为什么是这两个标志

bgt 是无符号整数比较"大于"时转移。硬件比较用减法 A − B 完成，结果由标志位判读：

比较结果借位/进位 CF零标志 ZFCF + ZF取反后转移？
A > B0（无借位）0（结果非零）01转移
A < B1（不够减有借位）010不转移
A = B01（结果为零）10不转移

"大于"要同时满足两个条件：减法无借位（CF = 0）且结果不为零（ZF = 0，排除相等）。两者用"或"合并后正好为 0，对其取反得 1，转移条件即 (CF + ZF) 取反 = 1。

第三步：排除其他选项

  • A（CF 取反 + OF = 1）：带上了溢出标志 OF，OF 用于带符号运算；无符号比较"大于"不需要它。
  • B（SF 取反 + ZF = 1）：SF 是符号标志，判读带符号数的大小/正负用，无符号数没有"符号"概念。
  • D（CF 取反 + SF = 1）：同样混入了带符号的 SF。

易错点

  • 漏掉 ZF：只写"CF = 0"会把 A = B 也误判为"大于"——大于必须排除相等。
  • 把带符号标志当无符号用：SF、OF 是带符号比较（如 bgt 的有符号版本 bgt 对应 jg）才用的标志。
记忆锚点：无符号大于 = 无借位且非零 = CF 与 ZF 全 0 = "CF + ZF" 取反为 1。
