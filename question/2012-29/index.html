操作系统

2012-29

CPU调度
选择题 2 分

一个多道批处理系统中仅有 P1 和 P2 两个作业，P2 比 P1 晚5ms到达，它们的计算和I/O操作顺序如下：

P1：计算60ms，I/O 80ms，计算20ms

P2：计算120ms，I/O 40ms，计算40ms

若不考虑调度和切换时间，则完成两个作业需要的时间最少是。

答案

答案：B

本题讲解：多道批处理系统的作业完成时间

答案：B（260ms）。

第一步：梳理并行条件

单处理机上计算不能并行，但计算与 I/O 可以并行。P1 在 t=0 到达，P2 在 t=5 到达；P1 的流程是「计算 60 → I/O 80 → 计算 20」，P2 是「计算 120 → I/O 40 → 计算 40」。

第二步：画时间线逐步推演

时间段处理机 CPUI/O 设备说明
0 – 60P1 计算①空P2 还没到（t=5 到达后只能就绪等待）
60 – 140P2 计算①P1 I/OP1 计算完转 I/O，CPU 让给 P2，两者并行
140 – 180P2 计算①空P1 的 I/O 完成，但 CPU 被 P2 占着，P1 等待
180 – 200P1 计算②P2 I/OP2 第一段算完转 I/O，P1 上 CPU 做 20ms 收尾
200 – 220空闲P2 I/OP1 已完成（200ms）；CPU 空闲等 P2 从 I/O 回来
220 – 260P2 计算②空P2 的 I/O 完成，做最后 40ms 计算
  • P1 完成时刻 = 200ms；P2 完成时刻 = 260ms。
  • 两个作业全部完成需要的时间 = max(200, 260) = 260ms。

易错点

  • 误选 C/D（顺序执行）：若两道作业严格串行、计算与 I/O 不并行，总时间会超过 340ms——多道系统的意义就在于 I/O 与计算并行。
  • 误选 A（240ms）：忽略了 t=200–220 这段 CPU 空闲——P2 的 I/O 没结束，最后 40ms 计算必须等它回到 CPU。
  • 忘记 P2 到达时刻：P2 晚 5ms 到达，但这 5ms 内 CPU 正被 P1 占用，不影响结果。
结论：P1 于 200ms、P2 于 260ms 完成，两个作业完成最少需要 260ms，选 B。
