计算机的性能指标主存储器高速缓冲存储器虚拟存储器I/O方式
综合应用题 10 分

假定某计算机的 CPU 主频为 80MHz，CPI 为 4，平均每条指令访存 1.5 次，主存与 Cache 之间交换的块大小为 16B，Cache 的命中率为 99%，存储器总线宽度为 32 位。请回答下列问题。
1）该计算机的 MIPS 数是多少？平均每秒 Cache 缺失的次数是多少？在不考虑 DMA 传送的情况下，主存带宽至少达到多少才能满足 CPU 的访存要求？
2）假定在 Cache 缺失的情况下访问主存时，存在 0.0005% 的缺页率，则 CPU 平均每秒产生多少次缺页异常？若页面大小为 4KB，每次缺页都需要访问磁盘，访问磁盘时 DMA 传送采用周期挪用方式，磁盘 I/O 接口的数据缓冲寄存器为 32 位，则磁盘 I/O 接口平均每秒发出的 DMA 请求次数至少是多少？
3）CPU 和 DMA 控制器同时要求使用存储器总线时，哪个优先级更高？为什么？
4）为了提高性能，主存采用四体低位交叉存储模式，工作时每 1/4 个存储周期启动一个体。若每个体的存储周期为 50ns，则该主存能提供的最大带宽是多少？

答案

（1）MIPS数为20；平均每秒Cache缺失次数为300,000次；主存带宽至少为4.8MB/s。
（2）CPU平均每秒产生缺页异常1.5次；磁盘I/O接口平均每秒发出DMA请求次数至少为1536次。
（3）DMA控制器优先级更高；因为DMA请求若得不到及时响应，I/O传输数据可能会丢失。
（4）主存能提供的最大带宽为320MB/s。

本题讲解：从 MIPS 到 DMA 请求与多体交叉带宽的性能折算链

答题框架：先把 CPU 每秒执行的指令数算出来，再沿「指令 → 访存 → Cache 缺失 → 缺页 → DMA 请求」逐级折算，第 3 问答优先级比较，第 4 问用多体交叉的流水思想算带宽。

结论：MIPS = 20；每秒 Cache 缺失 30 万次；主存带宽至少 4.8MB/s；每秒缺页 1.5 次；DMA 请求至少 1536 次/秒；DMA 优先级更高；最大带宽 320MB/s。

第 1 问：MIPS、Cache 缺失次数与主存带宽

  • 主频 80MHz、CPI = 4 → 每秒执行指令数 = 80M ÷ 4 = 20M 条，即 MIPS = 20。
  • 每条指令平均访存 1.5 次 → 每秒访存 20M × 1.5 = 30M 次；Cache 命中率 99%，缺失率 1% → 每秒缺失 30M × 0.01 = 0.3M = 300,000 次。
  • 每次缺失主存与 Cache 交换一块 16B → 主存带宽至少 16B × 0.3M/s = 4.8MB/s。

第 2 问：缺页异常与 DMA 请求次数

  • 缺页率 0.0005% 作用在"Cache 缺失后访问主存"上 → 每秒缺页 0.3M × 0.0005% = 1.5 次。
  • 页面大小 4KB，磁盘 I/O 接口的数据缓冲寄存器 32 位 = 4B → 每页要分 4KB ÷ 4B = 1024 次传送；周期挪用方式下每挪用一个存储周期传 4B、发一次 DMA 请求 → 每秒 DMA 请求至少 1.5 × 1024 = 1536 次。

第 3 问：CPU 与 DMA 控制器谁优先级高

DMA 控制器优先级更高。DMA 请求若得不到及时响应，I/O 传输的数据可能丢失（设备有实时性要求，等不起）；而 CPU 稍等一两个存储周期只是慢一点，不造成错误。

第 4 问：四体低位交叉主存的最大带宽

四体低位交叉按「每 1/4 个存储周期启动一个体」流水工作：体启动间隔 = 50ns ÷ 4 = 12.5ns。流水满载时，每隔 12.5ns 就读出总线宽度 32 位（4B）的一个字 → 最大带宽 = 4B ÷ 12.5ns = 320MB/s（等于 16B ÷ 50ns，即四个体并行）。

易错点

  • 缺失次数忘乘 1.5：缺失率作用在每秒 30M 次"访存"上，不是 20M 条指令上。
  • 缺页率的作用对象找错：0.0005% 作用在每秒 0.3M 次"Cache 缺失后访问主存"上，不是全部访存或指令上。
  • DMA 请求次数算错：要按缓冲寄存器宽度 4B 把每页 4KB 分成 1024 次，再乘每秒 1.5 次缺页。
  • 带宽按单体算：单体只有 4B ÷ 50ns = 80MB/s；四体流水满载才能提供 4 倍的 320MB/s。
记忆点：性能折算题的关键是找准每一级"每秒次数"的作用对象，逐级相乘；交叉存储器的带宽 = 一次读出的总字节数 ÷ 一个存储周期。
