运算方法和运算电路程序的机器级代码表示指令流水线

某 16 位计算机中，带符号整数用补码表示，数据 Cache 和指令 Cache 分离。题 44 表给出了指令系统中部分指令格式，其中 Rs 和 Rd 表示寄存器，mem 表示存储单元地址，(x)表示寄存器 x 或存储单元 x 的内容。

名称指令的汇编格式指令功能
加法指令ADD Rs, Rd(Rs)+(Rd)→Rd
算术/逻辑左移SHL Rd2×(Rd)→Rd
算术右移SHR Rd(Rd)/2→Rd

该计算机采用 5 段流水方式执行指令，各流水段分别是取指（IF）、译码/读寄存器（ID）、执行/计算有效地址（EX）、访问存储器（M）和结果写回寄存器（WB），流水线采用“按序发射，按序完成”方式，没有采用转发技术处理数据相关，并且同一个寄存器的读和写操作不能在同一个时钟周期内进行。请回答下列问题：
1）若 int 型变量 x 的值为 -513，存放在寄存器 R1 中，则执行指令“SHR R1”后，R1 的内容是多少？（用十六进制表示）
2）若某个时间段中，有连续的 4 条指令进入流水线，在其执行过程中没有发生任何阻塞，则执行这 4 条指令所需的时钟周期数为多少？
3）若高级语言程序中某赋值语句为 x = a + b，x、a 和 b 均为 int 型变量，它们的存储单元地址分别表示为 [x]、[a] 和 [b]。该语句对应的指令序列及其在指令流水线中的执行过程如题 44 图所示。

则这 4 条指令执行过程中，I3 的 ID 段和 I4 的 IF 段被阻塞的原因各是什么？

4）若高级语言程序中某赋值语句为 x = x * 2 + a，x 和 a 均为 unsigned int 型变量，它们的存储单元地址分别表示为 [x]、[a]，则执行这条语句至少需要多少个时钟周期？要求模仿题 44 图画出这条语句对应的指令序列及其在流水线中的执行过程示意图。

本题讲解：16 位机补码右移与 5 段流水线阻塞分析

答题框架：第 1 问按补码规则手工移位；第 2 问用「k + (5 − 1)」数无阻塞周期；第 3 问按「无转发 + 同寄存器读写不同周期 + 按序发射」定位阻塞原因；第 4 问排出含阻塞的完整时空图数总周期。

结论：R1 = FEFFH；8 个时钟周期；I3 的 ID 等 I1、I2 写回、I4 的 IF 因按序发射被 I3 拖住；17 个时钟周期。

第 1 问：执行 SHR R1 后 R1 的内容

x = −513 = −(2^9 + 1)，16 位补码：原码 1000 0001 0000 0001 → 补码 1111 1101 1111 1111（即 FDFFH）。SHR 是算术右移，高位补符号位 1：

1111 1101 1111 1111 → 1111 1110 1111 1111 = FEFFH

（等价于 −513 ÷ 2 向下取整为 −257，−257 的补码正是 FEFFH。）

第 2 问：4 条指令无阻塞的周期数

5 段流水线执行 k 条指令需 k + (5 − 1) 个周期：4 + 4 = 8 个时钟周期。

第 3 问：I3 的 ID 段与 I4 的 IF 段为何被阻塞

指令序列：I1 LOAD R1,[a]、I2 LOAD R2,[b]、I3 ADD R1,R2、I4 STORE R2,[x]。

  • I3 的 ID 段被阻塞的原因：I3 与 I1、I2 存在数据相关，要读 R1 和 R2。流水线未采用转发技术，且同一寄存器的读和写不能在同一时钟周期进行，所以必须等 I1（周期 5 写回 R1）、I2（周期 6 写回 R2）都写回之后，I3 才能读寄存器内容 → ID 推迟到周期 7。
  • I4 的 IF 段被阻塞的原因：流水线按"按序发射、按序完成"工作，前一条指令 I3 在 ID 段被阻塞，I4 不能越过它取指前进 → I4 的 IF 被阻塞（直到周期 7 才完成取指）。
指令1234567891011121314
I1IFIDEXMWB
I2IFIDEXMWB
I3IF———IDEXMWB
I4———IF———IDEXMWB

（表中"—"为等待周期；I4 的 ID 还要等 I3 在周期 10 写回 R2 后才能读，故排在周期 11。）

第 4 问：x = x*2 + a 的最少时钟周期

2×x 可用移位实现，指令序列如下（按指令功能表，ADD Rs,Rd 的结果存入 Rd）：

指令汇编功能
I1LOAD R1,[x]R1 ← x
I2LOAD R2,[a]R2 ← a
I3SHL R1R1 ← 2×R1
I4ADD R1,R2R2 ← R1 + R2
I5STORE R2,[x][x] ← R2

时空图（"—"为被阻塞的等待周期）：

指令1234567891011121314151617
I1IFIDEXMWB
I2IFIDEXMWB
I3IF——IDEXMWB
I4——IF———IDEXMWB
I5————IF——IDEXMWB
  • I3 要读 R1，等 I1 在周期 5 写回 → ID 在周期 6；
  • I4 要读 R1，等 I3 在周期 9 写回 → ID 在周期 10；I4 的 IF 因按序发射排在周期 6；
  • I5 要读 R2，等 I4 在周期 13 写回 → ID 在周期 14；其 IF 因按序发射排在周期 11。

I5 的 WB 在周期 17 完成，共 17 个时钟周期。

易错点

  • 算术右移补符号位：负数 SHR 高位补 1 得 FEFFH；按逻辑右移补 0 会错成 7EFFH。
  • 无阻塞周期数公式：k + (5 − 1) = 8，不是 5 × 4 = 20。
  • 忽略"读写不能同周期"：使用者（ID 读）必须排在写者（WB 写回）的下一个周期，这是所有阻塞的量化依据。
  • 忽略按序发射的连锁效应：前一条指令卡在 ID，后面的指令连 IF 都不能前进，I4、I5 的 IF 都被拖后。
记忆点：无转发 + 写后读相关 → 使用者的 ID 排在写者 WB 的下一周期；按序发射把阻塞向后传染到取指段。
