二叉树的概念树与二叉树的应用

二叉树的带权路径长度（WPL）是二叉树中所有叶结点的带权路径长度之和。给定一棵二叉树T，采用二叉链表存储，结点结构如下：

其中叶结点的weight域保存该结点的非负权值。设root为指向T的根结点的指针，请设计求T的WPL的算法，要求：
1）给出算法的基本设计思想。
2）使用C或C++语言，给出二叉树结点的数据类型定义。
3）根据设计思想，采用C或C++语言描述算法，关键之处给出注释。

答案

【答案】

（1）算法基本设计思想
方法一：基于先序递归遍历。定义递归函数，将当前结点的深度作为参数传递。若结点为叶子结点，则累加 深度 * 权值 到结果；否则，递归遍历其左右子树，并将深度参数加1。
方法二：基于层次遍历（BFS）。使用队列实现层次遍历，并记录当前层数 deep。利用指针 lastNode 标记当前层最后一个结点。当遍历到叶子结点时，累加 deep * 权值。每当处理完 lastNode 结点，就更新 lastNode 为下一层的最后一个结点，并将 deep 加1。

（2）二叉树结点的数据类型定义（C语言）

typedef struct BiTNode {
    int weight;                     // 存储权值
    struct BiTNode *lchild, *rchild; // 左、右孩子指针
} BiTNode, *BiTree;

（3）算法描述（C语言）
方法一：先序递归

int wpl_PreOrder(BiTree root, int deep);
int wpl_LevelOrder(BiTree root);

int WPL(BiTree root) {
    return wpl_PreOrder(root, 0); // 基于先序遍历
    // 如需使用层次遍历，可改为：return wpl_LevelOrder(root);
}

int wpl_PreOrder(BiTree root, int deep) {
    if (root == NULL) return 0; // 空树返回0
    if (root->lchild == NULL && root->rchild == NULL)
        return deep * root->weight;
    return wpl_PreOrder(root->lchild, deep + 1)
         + wpl_PreOrder(root->rchild, deep + 1);
}

方法二：层次遍历

int wpl_LevelOrder(BiTree root) {
    BiTree q[MaxSize]; // 声明队列，end1为头指针，end2为尾指针
    int end1, end2 = 0;
    end1 = end2 = 0;
    int wpl = 0, deep = 0;
    BiTree lastNode;
    BiTree newlastNode;
    lastNode = root;
    newlastNode = NULL;
    q[end2++] = root;
    while (end1 != end2) {
        BiTree t = q[end1++];
        if (t->lchild == NULL && t->rchild == NULL) {
            wpl += deep * t->weight;
        }
        if (t->lchild != NULL) {
            q[end2++] = t->lchild;
            newlastNode = t->lchild;
        }
        if (t->rchild != NULL) {
            q[end2++] = t->rchild;
            newlastNode = t->rchild;
        }
        if (t == lastNode) {
            lastNode = newlastNode;
            deep += 1;
        }
    }
    return wpl; // 返回wpl
}

本题讲解：求二叉树带权路径长度 WPL 的算法设计

先立机制：WPL 到底在算什么

WPL = 所有叶结点的（结点深度 × 权值）之和。它把"成本"拆成两半：权值存在叶结点里，深度却不存在任何结点里——深度等于从根走到该结点经过的边数，只随遍历过程"顺路"产生。所以本题的核心是：遍历走到哪儿，深度就得跟到哪儿。两条路线都能做到：

  • 先序递归：递归每下降一层，就给参数 deep 加 1 再传下去——深度天然"挂在"递归参数上；
  • 层次遍历：队列逐层出队，用 lastNode 哨兵标记"本层最后一个结点"，跨过它就把 deep 加 1。

有了这条主线，三问就是把它落实成代码。

第 1 问：算法基本设计思想

方法一（先序递归，推荐）：从根出发先序遍历，参数 deep 记当前结点深度，根为 0。访问到结点时：若是叶结点（左、右孩子均为空），把 deep × weight 累加进 wpl；否则递归左、右子树且 deep + 1。

  • 为什么深度能当参数传：树中结点的深度由"根到它的唯一路径"决定，先序递归正是沿这条路径走，每层递归调用对应路径上多走一条边——参数 deep 就是这条路径的长度，不需要任何额外存储。
  • 为什么只在叶结点累加：WPL 的定义只统计叶结点，内部结点的权值不计入。

方法二（层次遍历）：用队列逐层遍历，deep 记当前层数。为什么要 lastNode 哨兵：普通出队是一个"结点流"，队列里相邻两个出队结点可能属于不同层，光看出队顺序分不清层边界；让 lastNode 指向本层最后入队的结点，出队遇到它就说明本层走完，把它更新为本层出队期间最后入队的 newlastNode（即下一层最后一个），deep 加 1。遇到叶结点同样累加 deep × weight。

第 2 问：结点的数据类型定义

二叉链表结点只需"权值 + 左右孩子指针"两个字段族：

typedef struct BiTNode { int weight; struct BiTNode *lchild, *rchild; } BiTNode, *BiTree;

第 3 问：算法描述（方法一）

int wpl_PreOrder(BiTree root, int deep) 的逻辑：

  1. root == NULL 返回 0——空指针没有权值也没有深度，贡献为 0（同时防止空指针访问崩溃）；
  2. 左右孩子均为空（叶结点）时返回 deep * root->weight；
  3. 否则返回 wpl_PreOrder(root->lchild, deep+1) + wpl_PreOrder(root->rchild, deep+1)。

调用入口 WPL(root) = wpl_PreOrder(root, 0)。关键注释点：根深度为 0、仅在叶结点累加、递归下探时深度加 1。

示例树：根 A0（深 0）有两个孩子；左孩子（深 1）下挂叶 L1（权 2，深 2）与内部结点 A1（深 2），A1 下叶 L2（权 3）、L3（权 4）深 3；右孩子（深 1）下叶 L4（权 5，深 2）。

易错点

  • 把内部结点的权值也累加：WPL 只算叶结点；本题内部结点没有有效权值。
  • 深度起点记错：本题按根深度为 0 计算；若按 1 起算须全文口径一致，否则每个叶子都多算一层。
  • 层次遍历漏掉 lastNode：没有哨兵就感知不到换层，deep 停在第 1 层，所有累加全错。
  • 忘了传深度参数：不开参数就只能靠全局变量或额外结构记深度，逻辑易乱。
  • 空树不判 NULL：root == NULL 返回 0，防止空指针崩溃。
复杂度：两种方法都使每个结点恰好被访问一次，时间 O(n)；递归法空间 O(h)（栈深等于树高），层次法空间 O(n)（队列最长时是宽度最大的一层）。
