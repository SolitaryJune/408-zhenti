图的基本概念图的存储及基本操作图的应用
综合应用题 10 分

某网络中的路由器运行OSPF路由协议，题42表是路由器R1维护的主要链路状态信息（LSI），题42图是根据题42表及R1的接口名构造出来的网络拓扑。

请回答下列问题。
1）本题中的网络可抽象为数据结构中的哪种逻辑结构？
2）针对题42表中的内容，设计合理的链式存储结构，以保存题42表中的链路状态信息（LSI）。要求给出链式存储结构的数据类型定义，并画出对应题42表的链式存储结构示意图（示意图中可仅以ID标识结点）。

3）按照迪杰斯特拉（Dijkstra）算法的策略，依次给出R1到达题42图中子网192.1.x.x的最短路径及费用。

答案

（1）本题中的网络可抽象为数据结构中的图（具体为无向图）。

（2）采用带表头结点的链式存储。每个表头结点保存路由器 ID，并指向该路由器的链路/网络信息链；弧结点用 Flag 区分 Link 和 Net 两种记录。数据类型可定义为：

typedef struct {
    unsigned int ID, IP;
} LinkNode;                 // Link的结构

typedef struct {
    unsigned int Prefix, Mask;
} NetNode;                  // Net的结构

typedef struct Node {
    int Flag;               // Flag=1为Link，Flag=2为Net
    union {
        LinkNode Lnode;
        NetNode Nnode;
    } LinkORNet;
    unsigned int Metric;
    struct Node *next;
} ArcNode;                  // 弧结点

typedef struct HNode {
    unsigned int RouterID;
    ArcNode *LN_link;
    struct HNode *next;
} HNODE;                    // 表头结点

例如，R1 的表头结点保存 Router ID 10.1.1.1，其信息链依次记录到 R2 的 Link、到 R3 的 Link 以及直连网络 192.1.1.0/24 的 Net；其他路由器按同样方式组织。这样既能表示题表中的全部 LSI，也与题图中的无向图相对应。

本题讲解：OSPF 链路状态信息的存储与最短路径计算

第 1 问：抽象成什么逻辑结构

路由器与子网都可看作顶点，链路/直连网络看作边，费用（Metric）就是边上的权值，且链路是双向的——所以本题网络可抽象为数据结构中的图（具体为无向图，或称带权无向图/网）。

第 2 问：链式存储结构的设计

采用带表头结点的邻接表思想：每个表头结点保存一个路由器 ID，指向该路由器的链路信息链；信息链上每个弧结点用 Flag 区分记录类型（Flag=1 是 Link、Flag=2 是 Net），联合体存两种记录，Metric 存费用，next 串起同一路由器的多条信息。数据类型定义（C 语言）：

typedef struct { unsigned int ID, IP; } LinkNode;（Link 记录：所连路由器 ID 与本地 IP）

typedef struct { unsigned int Prefix, Mask; } NetNode;（Net 记录：直连网络前缀与掩码）

typedef struct Node { int Flag; union { LinkNode Lnode; NetNode Nnode; } LinkORNet; unsigned int Metric; struct Node *next; } ArcNode;（弧结点）

typedef struct HNode { unsigned int RouterID; ArcNode *LN_link; struct HNode *next; } HNODE;（表头结点）

示意图的组织方式：R1 的表头结点保存 Router ID 10.1.1.1，信息链依次挂"到 R2 的 Link（10.1.1.2，费用 3）""到 R3 的 Link（10.1.1.5，费用 2）""直连网络 192.1.1.0/24 的 Net（费用 1）"；其余路由器同样组织，弧结点链尾指针为空。

第 3 问：R1 到各子网的最短路径及费用

按 Dijkstra 算法从 R1 出发（每次选当前距离最小的顶点定案并松弛邻居），初始距离由 R1 的直连链路给出：N1=1、R3=2、R2=3、其余无穷大。

步骤操作结果
1选定 192.1.1.0/24（费用 1）直连定案
2选定 R3（费用 2）经 L1 链路
3经 R3 松弛N5=2+1=3；R4=2+6=8
4选定 192.1.5.0/24（3）路径 R1-R3-N5
5选定 R2（3）；经 R2 松弛N6=3+1=4；R4 更新为 3+4=7
6选定 192.1.6.0/24（4）、R4（7）路径 R1-R2-N6
7经 R4 松弛并选定 192.1.7.0/24N7=7+1=8，路径 R1-R2-R4-N7

最终答案表：

目的网络路径费用
192.1.1.0/24直接到达1
192.1.5.0/24R1-R3-192.1.5.0/243
192.1.6.0/24R1-R2-192.1.6.0/244
192.1.7.0/24R1-R2-R4-192.1.7.0/248

易错点

  • 答成树或线性结构：路由器与子网之间是多对多的邻接关系，必须答"图（无向图）"。
  • 漏掉 Flag/union：Link 与 Net 两种记录字段不同，弧结点必须能区分并二选一存储，这是本题存储设计的给分点。
  • 最短路径只报费用不报路径：第 3 问要求"路径及费用"两者都写全。
  • 忘记比较两条路：到 192.1.7.0/24 有 R1-R3-R4（2+6+1=9）和 R1-R2-R4（3+4+1=8）两条，要选费用小的 8。
记忆锚点：OSPF 链路状态 → 图；存储 → 表头 + 弧结点邻接表；算路 → Dijkstra 逐点定案、逐边松弛。
