2014-47

同步与互斥
综合应用题 9 分

系统中有多个生产者进程和多个消费者进程，共享一个能存放 1000 件产品的环形缓冲区（初始为空）。当缓冲区未满时，生产者进程可以放入其生产的一件产品，否则等待；当缓冲区未空时，消费者进程可以从缓冲区取走一件产品，否则等待。要求一个消费者进程从缓冲区连续取出 10 件产品后，其他消费者进程才可以取产品。请使用信号量 P，V（或 wait()，signal()）操作实现进程间的互斥与同步，要求写出完整的过程，并说明所用信号量的含义和初值。

答案

(1) 信号量的含义和初值

  • mutex1：用于控制一个消费者进程连续取出10件产品的互斥，初值为1。
  • mutex2：用于进程单次互斥访问缓冲区，初值为1。
  • empty：表示缓冲区中的空位数量，初值为1000。
  • full：表示缓冲区中的产品数量，初值为0。

(2) 生产者进程的伪代码

producer() {
    while (1) {
        生产一个产品;
        P(empty);          // 等待空位
        P(mutex2);         // 互斥访问缓冲区
        把产品放入缓冲区;
        V(mutex2);         // 释放缓冲区访问权
        V(full);           // 产品数加1
    }
}

(3) 消费者进程的伪代码

consumer() {
    while (1) {
        P(mutex1);         // 确保连续取10次产品期间独占
        for (int i = 0; i < 10; i++) {
            P(full);       // 等待产品
            P(mutex2);     // 互斥访问缓冲区
            从缓冲区取出一件产品;
            V(mutex2);     // 释放缓冲区访问权
            V(empty);      // 空位数加1
            消费这件产品;
        }
        V(mutex1);         // 释放连续取产品的控制权
    }
}

本题讲解：多生产者多消费者 + "连续取 10 件"的信号量设计（9 分）

答案要点：四个信号量——mutex1（初值 1，保证一个消费者连续取 10 件的互斥）、mutex2（初值 1，单次互斥访问缓冲区）、empty（初值 1000，缓冲区空位数）、full（初值 0，缓冲区产品数）；生产者与消费者各一段伪代码，消费者用 P(mutex1) 把"连续取 10 件"整体包住。

第一步：拆要求、定信号量

信号量含义初值
mutex1一个消费者连续取 10 件期间的互斥1
mutex2各进程单次互斥访问缓冲区1
empty缓冲区空位数（生产者的同步信号量）1000
full缓冲区产品数（消费者的同步信号量）0

第二步：生产者进程

  1. 生产一个产品;
  2. P(empty);——先等空位
  3. P(mutex2); 再申请缓冲区
  4. 把产品放入缓冲区; V(mutex2); V(full);

第三步：消费者进程（关键在 mutex1）

  1. P(mutex1);——拿到"连续取 10 件"的控制权，其他消费者在此排队
  2. 循环 10 次：P(full); → P(mutex2); → 从缓冲区取出一件产品; → V(mutex2); → V(empty); → 消费这件产品;
  3. V(mutex1);——10 件取完才释放，其他消费者才能开始

易错点

  • 同步 P 写在互斥 P 之后：若先 P(mutex2) 再 P(empty)，进程可能抱着缓冲区锁等空位而死锁。
  • 漏掉 mutex1：只有 mutex2 时每取一件就放锁，其他消费者可以插进来，"连续取 10 件"被破坏。
  • 把 mutex1 写进生产者：mutex1 只约束消费者之间；生产者只碰 empty、mutex2、full。
  • empty 初值写成 0 或 1：它是空位计数，初值 = 缓冲区容量 1000。
一句话结论：empty/full 管数量同步，mutex2 管单次互斥，mutex1 把"连续取 10 件"当一个整体锁起来。
