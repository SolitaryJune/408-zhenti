栈和队列的应用
选择题 2 分

已知程序如下：

int S(int n)
{
    return (n <= 0) ? 0 : S(n - 1) + n;
}

void main()
{
    cout << S(1);
}

程序运行时使用栈来保存调用过程的信息，自栈底到栈顶保存的信息依次对应的是__。

答案

本题讲解：递归调用时栈内保存信息的排列次序

答案：A

第一步：理清调用链

程序从 main() 开始执行，main() 调用 S(1)；S(1) 中 n=1 大于 0，于是要计算 S(0)+1，又调用 S(0)；S(0) 满足 n≤0 直接返回 0。所以调用链为 main() → S(1) → S(0)。

第二步：按"先调用先入栈"排栈

程序运行时用栈保存函数调用的信息（返回地址、参数、局部变量等），规则是：先调用的函数先入栈，后调用的压在栈顶。

时刻动作栈内（自底向上）
1main() 开始执行main()
2main 调用 S(1)main() → S(1)
3S(1) 调用 S(0)（最深时刻）main() → S(1) → S(0)
4S(0) 返回 0 出栈，S(1) 算出 1 出栈main()
5main 输出 1，结束出栈（空）

在递归到达最深、S(0) 尚未返回的那一刻，栈内自栈底到栈顶依次是 main() → S(1) → S(0)。

易错点

  • 把栈顶当成栈底：若按 B/D 那样把后调用的写在前面，就颠倒了"栈顶是最后入栈元素"这一基本性质。
  • 漏掉某一层调用：C 选项写成 main()→S(0)→S(1)，忽略了 S(1) 先于 S(0) 被调用。
记忆点：调用栈的入栈次序 = 调用发生的先后次序；栈顶永远是"当前正在执行"的函数。
