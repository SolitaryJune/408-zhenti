I/O接口I/O方式
选择题 2 分

在采用中断I/O方式控制打印输出的情况下，CPU和打印控制接口中的I/O端口之间交换的信息不可能是__。

答案

答案：B

本题讲解：中断 I/O 方式下 CPU 与 I/O 端口交换的信息

第一步：先给答案

答案：B（不可能是主存地址）。

第二步：接口里有哪几类端口

打印控制接口面向 CPU 的端口通常有三类，CPU 用 I/O 指令访问：

端口方向交换的信息
数据端口CPU → 接口待打印的字符（A）
状态端口接口 → CPU忙/闲、出错等设备状态（C）
控制端口CPU → 接口启动/停止等控制命令（D）

所以"打印字符、设备状态、控制命令"都是 CPU 与 I/O 端口之间正常交换的信息。

第三步：为什么不可能交换主存地址

  • 中断 I/O 方式下，数据始终走"CPU ↔ 接口数据端口"的通路，逐字节由 CPU 搬运，主存地址与接口无关。
  • 需要"主存地址"参与的是 DMA 方式：DMA 控制器接管总线后，按给定的主存首地址在主存与设备间直接批量传送。
  • 别把"端口地址"混进来：CPU 访问端口的编号（I/O 指令中的地址码）是寻址信息，不是双方交换的信息本身。

易错点

  • 混淆中断与 DMA：中断方式 CPU 全程参与、经端口逐字交换；DMA 才由 DMA 控制器给出主存地址直传。
  • 把端口地址当成交换的信息：端口地址是 CPU 找端口的"门牌号"，不是端口里传的数据/状态/命令。
中断 I/O 交换数据、状态、命令三类信息；主存地址只属于 DMA 传送。
