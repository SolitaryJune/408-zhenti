指令流水线
选择题 2 分

在无转发机制的五段基本流水线（取指、译码/读寄存器、运算、访存、写回寄存器）中，下列指令序列存在数据冒险的指令对是__。
I1: add R1,R2,R3; (R2)+(R3)→R1
I2: add R5,R2,R4; (R2)+(R4)→R5
I3: add R4,R5,R3; (R5)+(R3)→R4
I4: add R5,R2,R6; (R2)+(R6)→R5

答案

答案：B

本题讲解：无转发流水线的数据冒险定位

答案：B（I2 和 I3）。

第一步：列出每条指令"读哪些、写哪些"

指令源寄存器（读）目的寄存器（写）
I1: add R1,R2,R3R2、R3R1
I2: add R5,R2,R4R2、R4R5
I3: add R4,R5,R3R5、R3R4
I4: add R5,R2,R6R2、R6R5

数据冒险（RAW，先写后读）：后条指令要读的寄存器，恰好是前条指令要写的。

第二步：逐对检查

  • I1 与 I2：I2 读 R2、R4，写 R5；I1 只写 R1，无交集 → 无冒险（排除 A）。
  • I2 与 I3：I3 要读 R5，而 R5 正是 I2 的目的寄存器 → RAW 冒险。按五段流水线排布：I3 在译码段（第 4 拍）读 R5，I2 却要到写回段（第 6 拍）才写入新值，无转发通路时 I3 读到的是旧值。
  • I2 与 I4：两条都写 R5（写-写相关 WAW）；顺序流动的流水线按序写回不会出错，也不是"先写后读"型数据冒险。
  • I3 与 I4：I4 写 R5 发生在 I3 读 R5 之后（程序顺序先读后写）→ 不冲突。

第三步：无转发时怎么办

I3 必须在译码段暂停等待，直到 I2 写回 R5 之后才能读到新值——即插入气泡（暂停）。

易错点

  • 选 C（I2 和 I4）：被"都写 R5"迷惑——这是 WAW 相关，顺序五段流水线按序写回不构成数据冒险。
  • 只看寄存器名相同：I1、I2、I4 都读 R2，但整个序列中 R2 没有被任何指令写过，同名不等于有冒险。
  • 忽略时序方向：I4 写 R5 在 I3 读 R5 之后，"先读后写"不产生错误数据。
判据一句话：后条指令读的寄存器 = 前条指令写的寄存器（RAW）才是数据冒险；本题只有 I2 写 R5 → I3 读 R5。
