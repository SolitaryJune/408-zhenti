选择题 2 分

下列 IP 地址中，只能作为 IP 分组的源 IP 地址但不能作为目的 IP 地址的是__。

答案

答案：A

36

本题讲解：特殊 IP 地址"只能作源"的辨析

第一步：回忆特殊地址的用途

答案：A（0.0.0.0）。
逐项检查四个地址在"作源地址 / 作目的地址"两个方向上的合法性。

第二步：逐项判断

地址身份作源作目的
0.0.0.0本机尚未分得 IP 时的"本主机"可以（典型：DHCP 发现报文的源）不可以（不会被当作交付目标）
127.0.0.1环回地址可以可以（不出本机）
200.10.10.3普通 C 类单播地址可以可以
255.255.255.255受限广播地址不可以可以（本网络所有主机）

只有 0.0.0.0 满足"只能作源、不能作目的"。典型场景：主机开机时还没有 IP 地址，发出的 DHCP 报文源地址填 0.0.0.0、目的地址填 255.255.255.255。

易错点

  • 选 D（255.255.255.255）：方向记反了——它是"只能作目的、不能作源"的受限广播地址。
  • 选 B（127.0.0.1）：环回地址在本机收发都可以（ping 127.0.0.1 能通），不是"只能作源"。
  • 选 C（200.10.10.3）：普通单播地址双向都合法，没有任何限制。
记忆锚点：0.0.0.0 只源不目的；255.255.255.255 只目的不源；127.0.0.1 双可但不出网。
