数制与编码运算方法和运算电路浮点数的表示与运算
essay 13 分

已知 f(n)=∑i=0n2i=2n+1-1=(11…1)2，计算 f(n) 的 C 语言函数 f1 如下：

int f1(unsigned n){
    int sum=1, power=1;
    for(unsigned i=0; i<=n-1; i++){
        power *= 2;
        sum += power;
    }
    return sum;
}

将 f1 中的 int 都改为 float，可得到计算 f(n) 的另一个函数 f2。假设 unsigned 和 int 型数据都占 32 位，float 采用 IEEE 754 单精度标准。请回答下列问题。
（1）当 n=0 时，f1 会出现死循环，为什么？若将 f1 中的变量 i 和 n 都定义为 int 型，则 f1 是否还会出现死循环？为什么？
（2）f1(23)和 f2(23)的返回值是否相等？机器数各是什么（用十六进制表示）？
（3）f1(24)和 f2(24)的返回值分别为 33 554 431 和 33 554 432.0，为什么不相等？
（4）f(31)=232-1，而 f1(31) 的返回值却为 -1，为什么？若使 f1(n) 的返回值与 f(n) 相等，则最大的 n 是多少？
（5）f2(127)的机器数为 7F80 0000H，对应的值是什么？若使 f2(n)的结果不溢出，则最大的 n 是多少？若使 f2(n)的结果精确（无舍入），则最大的 n 是多少？

答案

（1）当 n=0 时，i 和 n 均为 unsigned 型，表达式 n-1 下溢，其机器数为 32 个 1，即 232-1，这是 unsigned 可表示的最大值。因此 i <= n-1 始终成立，循环不会结束。若把 i 和 n 都改为 int 型，则不会死循环：此时 n-1=-1，初始 i=0，循环条件不成立。

（2）f1(23) 和 f2(23) 返回值相等。f1(23) 的机器数为 00FFFFFFH，f2(23) 的机器数为 4B7FFFFFH。

（3）不相等。f(24)=33 554 431 的二进制形式为 25 个连续的 1，而单精度 float 只有 24 位有效数字，必须舍入，因此 f2(24) 得到 33 554 432.0，比 f1(24) 的 33 554 431 大 1。

（4）f1(31) 返回 -1 是因为 int 溢出，全 1 解释为 -1。使 f1(n) 与 f(n) 相等的最大 n 为 30。

（5）f2(127) 对应 +∞。使 f2(n) 不溢出的最大 n 为 126；使 f2(n) 精确的最大 n 为 23。

本题讲解：unsigned 下溢、int 溢出与 float 的精度/范围

答题框架：f(n) = 2n+1 − 1，即二进制 n+1 个连续的 1；循环跑 n 轮（i = 0 … n−1）。f1 用 int 累加、f2 用 float 累加，五个小问全是这两套记数系统与"n+1 个 1"的碰撞：无符号模运算（第(1)问）、24 位有效数字（第(2)(3)问）、补码范围（第(4)问）、float 范围（第(5)问）。

第 0 步：先立两套记数系统的模型

  • int（补码）：32 位补码是模 232 的记数——最高位为 1 的位串，真值 = 无符号值 − 232；可表示范围 −231 ~ 231−1，全 1 位串 = −1。
  • float（IEEE 754 单精度）：1 位符号 + 8 位阶码 + 23 位尾数，隐含首位 1 后有 24 位有效数字；可表示数值上限约 (2 − 2−23) × 2127 = 2128 − 2104，略小于 2128。

int 只受范围限制；float 先受精度限制（有效位数），再受范围限制。这条主轴贯穿全题。

第（1）问：n=0 为什么死循环；改成 int 为什么就没事

i、n 均为 unsigned。无符号运算是模 232 运算：条件式里的 n−1 先算，0 − 1 在模 232 下同余于 232 − 1，机器数就是 32 个 1（FFFFFFFFH）——恰好是 unsigned 的最大值。于是 i ≤ n−1 恒成立，i 一路加到 0xFFFFFFFF 再回绕也出不去，死循环。

为什么可以"减模"求真值？ 位串 FFFFFFFFH 之所以代表 232 − 1（无符号）就是这么定义的模运算余数；0−1 的余数即 232 − 1，没有"负数"一说。

若把 i、n 都改成 int：n−1 = −1（补码真值），首次判断 0 ≤ −1 不成立，循环体一次都不执行，直接返回 sum = 1——恰好等于 f(0) = 21 − 1，根本进不了循环，自然不会死循环。

第（2）问：f1(23) 与 f2(23) 是否相等

n=23 时和 = 224 − 1 = 16 777 215，二进制恰好 24 个 1。

  • f1（int）：24 个 1 < 231，范围内，机器数 00FFFFFFH。
  • f2（float）：规格化形式 1.11…1 × 223，有效数字 24 位恰好装下 24 个 1，无需舍入；阶码真值 23 + 偏置 127 = 150 = 10010110B，机器数 = 0｜10010110｜111…1 = 4B7FFFFFH。

两者返回值相等（都是 16 777 215）。

第（3）问：f1(24) 与 f2(24) 为什么差 1

n=24 时和 = 225 − 1 = 33 554 431，二进制 25 个 1——比 float 的 24 位有效数字多一位，必须舍入。

为什么恰好舍到 33 554 432？ 24 位有效数字意味着 float 在 [224, 225) 区间内每 2 个整数才取一个（相邻可表示数间隔为 2），33 554 431 恰好落在 33 554 430 与 33 554 432 的正中间；IEEE 754 默认"就近舍入、并列取偶"，33 554 432（尾数全 0，偶）胜过 33 554 430（尾数全 1，奇）→ f2(24) = 33 554 432.0。f1 不舍入，f1(24) = 33 554 431，故相差 1。

第（4）问：f1(31) 为什么返回 −1；最大 n

n=31 时和 = 232 − 1，超出 int 上限 231 − 1，溢出：留下的 32 位全 1 位串，按补码规则读回真值就是 232 − 1 − 232 = −1（无符号值减模）。要 f1(n) 与 f(n) 相等，需 2n+1 − 1 ≤ 231 − 1，即 n ≤ 30，最大 n = 30。

第（5）问：f2(127) 是什么；两个边界各在哪

n=127 时末轮和 = 2128 − 1。float 的上限是 2128 − 2104（比 2128 小一点点），2128 − 1 已越过它，就近舍入只能落到正无穷 +∞，机器数 7F80 0000H。所以：

  • 不溢出的最大 n = 126：末轮和 2127 − 1 < 上限，仍是有限值（虽然要舍入，但"不溢出"只要求有限）。
  • 精确（无舍入）的最大 n = 23：和的有效位数是 n+1，float 只有 24 位有效数字，n+1 ≤ 24 ⇒ n ≤ 23；从 n=24 起（25 个 1）必舍入，即第(3)问的场景。

用一张里程碑表对号入座（第二层汇总）：

循环里程碑f1 的 sum（int）f2 的 sum（float）说明
i=22 后（n=23 完成）16 777 215（00FFFFFFH）16 777 215.0（4B7FFFFFH）24 个 1，精确
i=23 后（n=24 完成）33 554 431（01FFFFFFH）33 554 432.0（4C000000H）25 个 1，舍入
i=30 后（n=31 完成）FFFFFFFFH = −1232（4F800000H）int 溢出；float 对 2 的幂仍精确
i=125 后（n=127 的末轮前）早已溢出2127（有限，舍入）2127−1 舍入为 2127，即 n=126 的结果
i=126 后（n=127 完成）—+∞（7F80 0000H）2127 + 2127 = 2128 越过 float 上限

易错点

  • unsigned 的 0−1 不是 −1：无符号是模 232 运算，0−1 ≡ 232 − 1，这是第(1)问死循环的根源。
  • 把 float 有效位数记成 23：尾数 23 位 + 隐含首位 1 = 24 位有效数字；24 个 1 能装下、25 个 1 装不下。
  • 混淆两个边界：不溢出看范围（n ≤ 126），精确看有效位数（n ≤ 23），两问分开答。
  • int 全 1 想不起是 −1：补码 = 模记数，全 1 = 232 − 1 − 232 = −1。
一句话：f1 败在"范围"（n=31 溢出成 −1），f2 先败在"精度"（n ≥ 24 舍入）再败在"范围"（n ≥ 127 变 +∞）。
