图的存储及基本操作图的应用IPv4
综合应用题 12 分

拟建设一个光通信骨干网络连通 BJ、CS、XA、QD、JN、NJ、TL 和 WH 等 8 个城市，题 42 图中无向边上的权值表示两个城市间备选光纤的铺设费用。

请回答下列问题。
（1）仅从铺设费用角度出发，给出所有可能的最经济的光纤铺设方案（用带权图表示），并计算相应方案的总费用。
（2）题 42 图可采用图的哪种存储结构？给出求解问题（1）所使用的算法名称。
（3）假设每个城市采用一个路由器按（1）中得到的最经济方案组网，主机 H1 直接连接在 TL 的路由器上，主机 H2 直接连接在 BJ 的路由器上。若 H1 向 H2 发送一个 TTL = 5 的 IP 分组，则 H2 是否可以收到该 IP 分组？

答案

（1）题图如下。所有可能的最经济方案为最小生成树，共有两种方案，总费用均为16。

（2）存储结构可采用邻接矩阵或邻接表；求解算法为Prim算法或Kruskal算法。

（3）在方案1中，TL与BJ间距离过长，TTL=0时会丢弃数据报无法到达，H2不能收到分组；在方案2中，TL与BJ相邻，最短路径长度为1，H2可以收到分组。

本题讲解：光通信骨干网的最小生成树与 TTL 判定

第（1）问：最经济方案 = 最小生成树，共两种、总费用均 16

8 个城市连通需要 7 条边，最经济方案就是图的最小生成树。用 Kruskal 思路按边权从小到大选边：

  1. 权 2 的 5 条边全部可用：XA–BJ、XA–WH 连成块 {XA,BJ,WH}；TL–JN、QD–JN、QD–NJ 连成块 {TL,JN,QD,NJ}；
  2. 权 3 的边中：BJ–TL 恰好连接上述两大块，选入；CS–QD 把 CS 接入，选入；
  3. WH–BJ、WH–QD、JN–NJ 都会成环，舍去；权 4 的边不再需要。

按上面顺序得到 7 条边：XA–BJ(2)、XA–WH(2)、TL–JN(2)、QD–JN(2)、QD–NJ(2)、BJ–TL(3)、CS–QD(3)，总费用 2+2+2+2+2+3+3 = 16。

注意「所有可能方案」：连接两大块的权 3 桥边有 BJ–TL 和 WH–QD 两条（BJ–JN 权 4 更贵不能选），二者任选其一都构成最小生成树，故共有两种方案，总费用均为 16：

方案7 条边总费用
方案 1（桥边 WH–QD）XA–BJ、XA–WH、WH–QD、QD–CS、QD–JN、QD–NJ、TL–JN16
方案 2（桥边 BJ–TL）XA–BJ、XA–WH、BJ–TL、TL–JN、JN–QD、QD–NJ、QD–CS16

第（2）问：存储结构与算法名称

题图是无向带权图，用邻接矩阵或邻接表均可存储；求最小生成树可用 Prim 算法或 Kruskal 算法。

第（3）问：TTL = 5 的 IP 分组能否从 H1（TL）到 H2（BJ）

路由器转发分组时才把 TTL 减 1，减到 0 就丢弃。

  • 方案 2：TL 与 BJ 相邻（有边 BJ–TL），TL 路由器转发后 TTL = 4，BJ 路由器收到即可交付 H2，H2 可以收到。
  • 方案 1：TL 到 BJ 的路径为 TL → JN → QD → WH → XA → BJ，共 5 跳。TTL 变化：TL 转发后 4、JN 后 3、QD 后 2、WH 后 1、XA 后 0 —— TTL 减为 0 的分组在 XA 路由器被丢弃，H2 收不到。

易错点

  • 只给一棵生成树：题目问「所有可能的最经济方案」，漏掉桥边的第二种选择会丢一半分。
  • 把成环的边当必选：WH–BJ、WH–QD、JN–NJ 权值虽小但会成环；其中 WH–QD 又是另一棵 MST 的桥边，要认真区分。
  • TTL 减 1 的时机：主机 H1 发出时 TTL = 5 未减；TL 是第一个减 1 的设备。按 5 跳减 5 次恰在 XA 归零被丢弃。
  • 第（1）问只答费用：必须同时给出用带权图表示的方案和总费用 16。
一句话：两棵 MST 桥边二选一、总费用均 16；方案 2 相邻一跳可达，方案 1 五跳在 XA 处 TTL 归零被丢弃。
