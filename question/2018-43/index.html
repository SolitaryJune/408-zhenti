计算机的性能指标I/O方式
综合应用题 8 分

假定计算机的主频为 500MHz，CPI 为 4。现有设备 A 和 B，其数据传输率分别为 2MB/s 和 40MB/s，对应 I/O 接口中各有一个 32 位数据缓冲寄存器。请回答下列问题，要求给出计算过程。
（1）若设备 A 采用定时查询 I/O 方式，每次输入/输出都至少执行 10 条指令。设备 A 最多间隔多长时间查询一次才能不丢失数据？CPU 用于设备 A 输入/输出的时间占 CPU 总时间的百分比至少是多少？
（2）在中断 I/O 方式下，若每次中断响应和中断处理的总时钟周期数至少为 400，则设备 B 能否采用中断 I/O 方式？为什么？
（3）若设备 B 采用 DMA 方式，每次 DMA 传送的数据块大小为 1000B，CPU 用于 DMA 预处理和后处理的总时钟周期数为 500，则 CPU 用于设备 B 输入/输出的时间占 CPU 总时间的百分比最多是多少？

答案

答案：

（1）设备 A 最多间隔 2 µs 查询一次；CPU 用于设备 A 输入/输出的时间占 CPU 总时间的百分比至少为 4%。
（2）设备 B 不能采用中断 I/O 方式，因为设备 B 准备数据的时间（0.1 µs）小于中断响应和处理时间（0.8 µs），数据可能丢失。
（3）CPU 用于设备 B 输入/输出的时间占 CPU 总时间的百分比最多为 4%。

本题讲解：三种 I/O 方式的时间账

先算统一口径：主频 500MHz，时钟周期 = 1/500MHz = 2ns；CPI = 4，执行一条指令 = 4 × 2ns = 8ns。两个设备接口的数据缓冲寄存器都是 32 位 = 4B——每装满 4B 就必须被取走一次，否则新数据会把旧数据冲掉。

第（1）问：设备 A 的定时查询

答题框架：先求"多长时间装满缓冲"，再求"每次查询花多少 CPU 时间"，后者除以前者。

  • 设备 A 速率 2MB/s，装满 4B 缓冲需要 4B ÷ 2MB/s = 2µs。所以最多间隔 2µs 就要查询一次，否则数据丢失。
  • 每次查询至少执行 10 条指令：10 × 8ns = 80ns。
  • CPU 用于设备 A 输入/输出的时间占比 = 80ns ÷ 2µs = 4%（题目问"至少"，因为 10 条指令是下限）。

第（2）问：设备 B 能否用中断方式

框架：比较"数据到达间隔"与"一次中断响应和处理的总耗时"。

  • 设备 B 每 4B 的到达间隔 = 4B ÷ 40MB/s = 0.1µs。
  • 一次中断响应和处理至少 400 × 2ns = 0.8µs。
  • 0.8µs 大于 0.1µs：一个数据还没处理完，下一个 4B 已经到达，数据必然丢失 → 设备 B 不能采用中断 I/O 方式。

第（3）问：设备 B 的 DMA 方式

框架：DMA 传送期间 CPU 不参与，CPU 只花在预处理和后处理上，按每块传送时间分摊。

  • 每块 1000B，传送一块耗时 = 1000B ÷ 40MB/s = 25µs，期间 CPU 可执行程序。
  • CPU 每块只投入预处理 + 后处理 = 500 × 2ns = 1µs。
  • 占比 = 1µs ÷ 25µs = 4%，即 CPU 用于设备 B 输入/输出的时间占比最多是 4%。

易错点

  • 把 MB/s 当成 Mb/s：40MB/s 下 4B 的到达间隔是 0.1µs，不是 0.8µs。
  • 第（3）问把 25µs 的 DMA 传送计入 CPU 时间：传送由 DMA 控制器完成，CPU 只承担预处理/后处理的 1µs。
  • 忘记换算：10 条指令、400 周期、500 周期都要先乘时钟周期 2ns 换算成 ns/µs，再与设备时间比较。
三问一个节奏：设备时间（装满缓冲/到达间隔/一块的传送时间）作分母，CPU 介入时间作分子。
