操作系统的运行环境
choice 2 分

下列关于系统调用的叙述中，正确的是__。
I. 在执行系统调用服务程序的过程中，CPU处于内核态
II. 操作系统通过提供系统调用避免用户程序直接访问外设
III. 不同的操作系统为应用程序提供了统一的系统调用接口
IV. 系统调用是操作系统内核为应用程序提供服务的接口

答案

答案：C

本题讲解：系统调用的本质（判断四句正误）

答案：C（仅 I、II、IV）。

第一步：抓住系统调用的定位

系统调用是操作系统内核为应用程序提供服务的接口，也是用户程序获得内核服务的唯一合法入口；调用时 CPU 从用户态陷入内核态执行服务程序。

第二步：逐句判断

句分析判断
I系统调用服务程序是内核代码，执行期间 CPU 处于内核态对
II外设是关键资源，用户程序不能直接访问，须经系统调用间接使用对
III不同操作系统的系统调用接口互不相同（调用号、参数、功能均有差异）错
IV系统调用正是内核为应用程序提供服务的接口，即定义本身对

易错点

  • 被 III 迷惑：统一的是 C 标准库这类"封装层"，系统调用接口本身各 OS 并不统一，如 Linux 与 Windows 的调用完全不同。
  • 状态搞混：发出调用前 CPU 在用户态，执行服务程序期间在内核态，I 说的正是执行期间。
一句话结论：系统调用 = 内核的服务接口 + 用户态/内核态的分界，II 体现了它对外设的保护；"各 OS 统一"是错的，故选 C。
