408 操作系统
操作系统

2020-45

同步与互斥
综合应用题 7 分

现有5个操作A、B、C、D和E，操作C必须在A和B完成后执行，操作E必须在C和D完成后执行，请使用信号量的wait()、signal()操作（P、V操作）描述上述操作之间的同步关系，并说明所用信号量及其初值。

答案

(1) 设四个同步信号量 S_AC、S_BC、S_CE、S_DE，初值均为 0，分别描述 A→C、B→C、C→E、D→E 四个先后关系。

(2) 操作同步伪代码（wait/signal 即 P/V 操作）：

S_AC = 0;
S_BC = 0;
S_CE = 0;
S_DE = 0;

cobegin {
    A() {
        A;
        signal(S_AC);
    }

    B() {
        B;
        signal(S_BC);
    }

    C() {
        wait(S_AC);
        wait(S_BC);
        C;
        signal(S_CE);
    }

    D() {
        D;
        signal(S_DE);
    }

    E() {
        wait(S_CE);
        wait(S_DE);
        E;
    }
} coend

(3) C 分别等待 A、B 发出的完成信号后才能执行；E 分别等待 C、D 发出的完成信号后才能执行。本题只有同步关系，没有互斥关系。

本题讲解：用信号量描述前趋关系（A、B → C → E，D → E）

答题框架：前趋图中每条边设一个同步信号量，初值均为 0；箭头起点做完 signal()，箭头终点开始前 wait()。本题 4 条边，设 4 个信号量。

第一步：设信号量及初值

  • S_AC：描述 A→C；S_BC：描述 B→C；S_CE：描述 C→E；S_DE：描述 D→E。
  • 四个信号量初值均为 0（表示"许可尚未产生"：前驱没完成，后继不能开始）。

第二步：写出各操作的伪代码

操作代码
AA; signal(S_AC);
BB; signal(S_BC);
Cwait(S_AC); wait(S_BC); C; signal(S_CE);
DD; signal(S_DE);
Ewait(S_CE); wait(S_DE); E;

五个操作放在 cobegin … coend 之间并发启动。C 要先等到 A、B 发来的两个完成信号（两次 wait 都通过）才能执行；E 要先等到 C、D 发来的两个完成信号才能执行。

第三步：检查

  • 信号量值的含义：signal 使值加 1 表示"某条前趋边已满足"；wait 使值减 1 表示"领取一次许可"。全部执行完后四个信号量都回到 0。
  • 本题操作之间只有同步关系，没有互斥关系，因此不需要互斥信号量。

易错点

  • 信号量初值设为 1：那是互斥信号量的用法；同步信号量初值应为 0。
  • wait/signal 位置写反：后继必须先 wait 再做事，前驱必须先做事再 signal。
  • 漏掉 C→E 这条边：C 完成后也要向 E 发信号，只写 A、B→C 会丢掉 S_CE，E 可能提前执行。
一句话结论：每条前趋边一个信号量、初值 0；前驱完成时 signal，后继开始前 wait。设 S_AC、S_BC、S_CE、S_DE 四个初值 0 的信号量即可。
