choice 2 分

假设主机 H 通过 HTTP/1.1 请求浏览某 Web 服务器 S 上的 Web 页 news408.html，news408.html 引用了同目录下的 1 幅图像，news408.html 文件大小为 1 MSS（最大段长），图像文件大小为 3 MSS，H 访问 S 的往返时间 RTT = 10 ms，忽略 HTTP 响应报文的首部开销和 TCP 段传输时延。若 H 已完成域名解析，则从 H 请求与 S 建立 TCP 连接时刻起，到接收到全部内容止，所需的时间至少是（ ）。

答案

答案：B

本题讲解：HTTP/1.1 持久连接取回页面与图像至少要几个 RTT

答案：B（40 ms）

第一步：两个前提

  • HTTP/1.1 默认持久连接：HTML 和图像来自同一服务器，只建立一次 TCP 连接，取图像不必重新握手。
  • 已完成域名解析 → 无 DNS 开销。TCP 三次握手的第三次握手可以携带数据，慢开始从 cwnd = 1 MSS 起步。

第二步：按传输轮次（RTT）推演

轮次本轮发生什么本轮结束 H 已收到
第 1 个 RTT前两次握手：SYN / SYN+ACK—
第 2 个 RTT第三次握手捎带请求 news408.html；cwnd = 1 MSS ≥ 1 MSS，S 发完 HTMLHTML（1 MSS）
第 3 个 RTTH 的确认捎带请求图像；S 收到确认后 cwnd = 2 MSS < 3 MSS，先发图像前 2 个 MSS图像 MSS1、MSS2
第 4 个 RTTcwnd = 4 MSS ≥ 剩余 1 MSS，S 发图像最后 1 个 MSS全部内容

第三步：合计

共 4 个 RTT，RTT = 10 ms → 至少 40 ms，选 B。

易错点

  • 选 A（30 ms）：按"每对象 1 RTT"的理想模型算成 3 RTT，忽略了拥塞窗口的限制——图像 3 MSS 在 cwnd = 2 MSS 的一轮里发不完，必须分两轮。
  • 以为要重建连接：HTTP/1.0 非持久连接才要为图像再握手（多 2 RTT）；HTTP/1.1 默认持久连接直接复用。
  • 忽略慢开始起步：cwnd 从 1 MSS 逐步翻倍（1→2→4），不是一开始就能以任意窗口发送。
记忆口径：HTTP/1.1 持久连接只握一次手；第三个 RTT 只能发 2 MSS，最后一个 MSS 拖到第 4 个 RTT 才到齐。
