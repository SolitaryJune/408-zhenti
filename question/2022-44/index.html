外部存储器I/O方式
综合应用题 8 分

假设某磁盘驱动器中有 4 个双面盘片，每个盘面有 20000 个磁道，每个磁道有 500 个扇区，每个扇区可记录 512 字节的数据，盘片转速为 7200 RPM(转/分)，平均寻道时间为 5 ms。 请回答下列问题。

1）每个扇区包含数据及其地址信息，地址信息分为 3 个字段。这 3 个字段的名称各是什么？对于该磁盘，各字段至少占多少位？
2）一个扇区的平均访问时间约为多少？
3）若采用周期挪用 DMA 方式进行磁盘与主机之间的数据传送，磁盘控制器中的数据缓冲区大小为 64 位，则在一个扇区读写过程中，DMA 控制器向 CPU 发送了多少次总线请求？若 CPU 检测到 DMA 控制器的总线请求信号时也需要访问主存，则 DMA 控制器是否可以获得总线使用权？为什么？

答案

（1）三个字段为柱面号（磁道号）、磁头号（盘面号）和扇区号，至少分别占 15 位、3 位和 9 位。

（2）平均访问时间约为：

5+60×103/72002+60×103/7200500 ≈ 9.18 ms

（3）每扇区 512 B，缓冲区为 64 bit（8 B），因此 DMA 控制器发送 512/8=64 次总线请求。采用周期挪用 DMA 时，CPU 与 DMA 同时请求主存，DMA 可优先获得总线使用权，以免磁盘连续传送的数据丢失。

本题讲解：磁盘扇区地址、平均访问时间与周期挪用 DMA

第 1）问：扇区地址的 3 个字段与最少位数

先立机制：一个扇区在盘上的位置由三个依次收窄的问题定位——哪个记录面（磁头号/盘面号）、该面的哪一圈磁道（柱面号/磁道号）、这条磁道上的第几个扇区（扇区号）。三段地址各管一维，合起来唯一确定一个扇区。

为什么用“柱面号”而不是“磁道号”：所有盘面上半径相同的磁道构成一个圆柱面，所有磁头都装在同一小车上、同时指向同一柱面——寻道一次，8 个记录面的同号磁道全部就位。用柱面号统一描述“第几圈”，正是这个机械事实的反映。

位数由“至少能区分多少个”决定，一律向上取幂：

字段要区分的个数计算最少位数
柱面号（磁道号）每盘面 20000 道2¹⁴ = 16384 不够，2¹⁵ = 32768 够15 位
磁头号（盘面号）4 个双面盘片 = 8 个盘面2³ = 8 恰好3 位
扇区号每磁道 500 扇区2⁸ = 256 不够，2⁹ = 512 够9 位

第 2）问：一个扇区的平均访问时间

机制：一次访问 = 寻道 + 旋转延迟 + 传输，三项“平均”各有来历。寻道时间题目直接给定平均 5 ms；旋转延迟取决于“磁头到位那一刻，目标扇区在它前方多远”——这个距离在 0 到一转之间均匀分布，平均半转；传输时间是扇区数据扫过磁头的时间——每道 500 个扇区均分一圈，一个扇区就是一转的 1/500。

转速 7200 RPM → 一转 = 60×10³ ÷ 7200 ≈ 8.333 ms，于是：

平均访问时间 = 5 + 8.333/2 + 8.333/500 = 5 + 4.167 + 0.017 ≈ 9.18 ms

第 3）问：DMA 总线请求次数与优先权

周期挪用（周期窃取）DMA 的机制：磁盘把数据送进控制器缓冲区，缓冲区装满一批，DMA 才向 CPU 申请一个存储周期把这一批搬进主存——搬运以缓冲区为单位，不是逐字节。缓冲区 64 位 = 8 B，每扇区 512 B → 512 ÷ 8 = 64 次总线请求。

CPU 与 DMA 同时请求主存时，DMA 可以优先获得总线使用权。为什么让 DMA 先走：磁盘按转速机械地连续吐数据，来多少就得接多少，不能暂停重放；若 DMA 让 CPU 插队一个存储周期，缓冲区里刚到的 8 B 还没搬走，下一批就来了，数据会被覆盖丢失。而 CPU 被推迟一个存储周期对程序执行几乎没有影响。两害相权，周期挪用规则规定冲突时 DMA 优先。

易错点

  • 位数算成“恰好够的幂”：500 个扇区要 9 位（2⁸ 不够），20000 道要 15 位（2¹⁴ 不够），一律向上取幂。
  • 把一整转当旋转延迟：平均旋转延迟是半转——目标扇区初始位置均匀分布所致。
  • 漏加传输时间：9.18 = 5 + 4.167 + 0.017，三项缺一不可。
  • 以为 DMA 一定让 CPU：周期挪用的原则恰恰是 DMA 优先，防的是磁盘数据流不可暂停导致的丢失。
一句话结论：地址 15 + 3 + 9 位；平均访问 ≈ 5 + 4.167 + 0.017 ≈ 9.18 ms；每扇区 64 次总线请求，同时请求时 DMA 优先。
