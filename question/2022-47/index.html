介质访问控制局域网IPv4网络层设备
综合应用题 9 分

某网络拓扑如题 47 图所示，R 为路由器，S 为以太网交换机，AP 是 802.11 接入点，路由器的 E0 接口和 DHCP 服务器的 IP 地址配置如图中所示；H1 与 H2 属于同一个广播域，但不属于同一个冲突域；H2 和 H3 属于同一个冲突域；H4 和 H5 已经接入网络，并通过 DHCP 动态获取了 IP 地址。现有路由器、100BaseT 以太网交换机和 100BaseT 集线器（Hub）三类设备各若干台。

请回答下列问题。
1）设备 1 和设备 2 应该分别选择哪类设备？
2）若信号传播速度为 2×108 m/s，以太网最小帧长为 64 B，信号通过设备 2 时会产生额外的 1.51 μs 的时间延迟，则 H2 与 H3 之间可以相距的最远距离是多少？
3）在 H4 通过 DHCP 动态获取 IP 地址过程中，H4 首先发送了 DHCP 报文 M，M 是哪种 DHCP 报文？路由器 E0 接口能否收到封装 M 的以太网帧？S 向 DHCP 服务器转发的封装 M 的以太网帧的目的 MAC 地址是什么？
4）若 H4 向 H5 发送一个 IP 分组 P，则 H5 收到的封装 P 的 802.11 帧的地址 1、地址 2 和地址 3 分别是什么？

答案

1）设备1选择100BaseT以太网交换机；设备2选择100BaseT集线器。
2）H2与H3之间可以相距的最远距离是210米。
3）M是DHCP Discover报文；路由器E0接口能收到封装M的以太网帧；目的MAC地址是FF-FF-FF-FF-FF-FF。
4）地址1为H5的MAC地址 00-11-11-11-11-E1，地址2为AP的MAC地址 00-11-11-11-11-C1，地址3为H4的MAC地址 00-11-11-11-11-D1。

本题讲解：设备选型、冲突域最远距离、DHCP 广播与 802.11 帧地址

第 1 问：设备 1、设备 2 选谁

先立机制——三类设备对帧的转发方式不同，冲突域/广播域的差异全源于此。集线器（Hub）是物理层转发器：把一个端口收到的信号放大后向所有其他端口重发，所有端口共享同一介质，任意两个端口同时发送必然碰撞——整个 Hub 是一个冲突域，且广播、单播一律泛洪，也不隔离广播域。交换机是链路层设备：按目的 MAC 查表把帧送往单一端口，各端口独立跑 CSMA/CD——每个端口一个冲突域，但广播帧仍向所有端口泛洪，不隔离广播域。路由器是网络层设备：广播帧过不了路由器——隔离广播域。

拿机制对线索：H1 与 H2 属于同一个广播域、不属于同一个冲突域 → 设备 1 必须“隔冲突、不隔广播” → 100BaseT 以太网交换机（Hub 会让 H1/H2 同处一个冲突域，路由器会把二者分进不同广播域，均与线索矛盾）。H2 和 H3 属于同一个冲突域 → 设备 2 不隔离冲突域 → 100BaseT 集线器。

第 2 问：H2 与 H3 的最远距离

机制：H2、H3 经 Hub 同处一个冲突域，半双工 CSMA/CD。为什么最小帧长能定距离上限——发送方必须在发完帧之前得知碰撞：碰撞信号从发送端传到冲突点再返回，最远要 2τ；若帧发完了碰撞消息还没回来，发送方会误判成功。所以“最小帧长的发送时间 ≥ 2τ”，反过来看，争用期（2τ 上限）= 最小帧长 ÷ 速率。

  1. 100BaseT 速率 100 Mb/s：争用期 = 64 × 8 bit ÷ 100 Mb/s = 5.12 μs。
  2. 单程上限 τ = 5.12 ÷ 2 = 2.56 μs。这 2.56 μs 里既有线路传播、也含信号过设备 2 的额外 1.51 μs，扣掉后线路传播上限 = 2.56 − 1.51 = 1.05 μs（τ 是单程，H2→H3 单程只穿过设备 2 一次，所以只减一次 1.51）。
  3. 最远距离 d = 1.05 μs × 2×10⁸ m/s = 210 m。

第 3 问：DHCP 报文 M 与广播帧去向

机制：DHCP 的四步交互是 Discover → Offer → Request → ACK。H4 刚接入，还没有 IP 地址，也不知道 DHCP 服务器的 IP 和 MAC——唯一能做的就是“全网喊话”：首先发送 DHCP Discover 报文（M），IP 层目的地址 255.255.255.255，链路层封装为目的 MAC 全 1 的广播帧。

  • H4、AP、交换机 S、路由器 E0 接口、DHCP 服务器同在 192.168.0.0/25 这一个广播域里。S 收到广播帧，按交换机规则从除入端口外的所有端口泛洪 → 路由器 E0 接口能收到封装 M 的以太网帧（DHCP 服务器同样收到）。
  • S 向 DHCP 服务器转发的仍是这个广播帧，目的 MAC = FF-FF-FF-FF-FF-FF。路由器会收下该帧，但不会把这个 IP 受限广播再转发到别的网络。

第 4 问：802.11 帧的地址 1、2、3

机制：802.11 帧最多带 4 个地址字段，具体含义随 To DS / From DS 变化，但骨架不变——地址 1 = 本跳接收者（ACK 发给谁），地址 2 = 本跳发送者（谁负责重传），地址 3 = 端到端的源或目的（无线段只是路径的最后一跳，必须把真正的起点/终点带上，对端才知道来龙去脉）；地址 4 只在无线分布式系统（mesh）中用。

H5 收到的帧由 AP 发往无线站点（“来自 AP”，From DS = 1）：

地址字段角色本题取值
地址 1本跳接收者 = 目的站H5 的 MAC 00-11-11-11-11-E1
地址 2本跳发送者 = AP00-11-11-11-11-C1
地址 3端到端源 = H4H4 的 MAC 00-11-11-11-11-D1

为什么地址 2 不是 H4：最后一跳是 AP 发出的，ACK 与重传都对着 AP；端到端源 H4 放在地址 3。

易错点

  • 第 1 问把设备 1 当成集线器：Hub 连冲突域都不隔离，与“不属于同一个冲突域”直接矛盾。
  • 第 2 问忘扣 1.51 μs：设备延迟也在单程 2.56 μs 的预算里，必须扣除；不扣会得 512 m。
  • 第 2 问忘除 2：5.12 μs 是往返（2τ），单程 τ = 2.56 μs；也不能把 1.51 扣两次（单程只过一次设备 2）。
  • 第 3 问以为 E0 收不到：广播帧被交换机泛洪到所有端口，E0 在链路上必然收到——只是路由器不把该 IP 广播转发出去。
  • 第 4 问地址 2、3 弄反：“来自 AP”的帧地址 2 一定是 AP 自己（00-…-C1），地址 3 才是端到端源 H4（00-…-D1）。
一句话总括：交换机隔冲突不隔广播、Hub 全不隔；5.12 μs 争用期扣设备延迟剩 1.05 μs 得 210 m；DHCP 先发 Discover 全 1 广播；来自 AP 的 802.11 帧 = 地址 1 目的、地址 2 AP、地址 3 源。
