下列关于硬件和异常/中断关系的叙述中，错误的是（ ）。

本题讲解：硬件与异常、中断的关系辨析

答案：D（错误的是它）。

第一步：分清异常与中断的检测时机

  • 异常（内中断）：由指令执行本身引起（除 0、溢出、缺页、非法操作码等），CPU 在执行一条指令的过程中检测——A 说法正确；
  • 中断（外中断）：由外设请求引起，CPU 在每条指令执行完后（指令周期结束时）检测中断请求信号——B 说法正确。

第二步：中断响应条件

CPU 响应中断还要求处于开中断状态（IF = 1）：开中断时检测到中断请求就进入中断响应周期；关中断时不响应——C 说法正确。

第三步：D 为什么错（信号方向）

「中断结束」信号（EOI）的方向是 CPU → 中断控制器 → 外部设备：中断服务程序处理完，由 CPU 向中断控制器发中断结束命令，控制器再据此通知设备。选项把方向说反了——不是设备向 CPU 发中断结束信号。

易错点

  • 方向记反：中断请求是设备 → CPU；中断应答、中断结束是 CPU → 设备（经中断控制器）。
  • 把异常的检测时机记成指令末：异常在指令执行过程中即时检测，中断请求在指令执行完后采样。
  • 忽略开中断条件：检测到请求不等于立即响应，还需 IF = 1 且无更高优先级请求。
一句话结论：异常在指令执行中检测、中断请求在指令执行完检测、开中断才响应；中断结束信号由 CPU 经中断控制器发给设备，D 方向反了。
