内存管理概念
选择题 2 分

进程 R 和 S 共享数据 data，若 data 在 R 和 S 中所在页的页号分别为 p1 和 p2，两个页所对应的页框号分别为 f1 和 f2，则下列叙述中，正确的是（ ）。

答案

答案：C

本题讲解：共享页面的页号与页框号

答案：C（p1 和 p2 不一定相等，f1 和 f2 一定相等）。

第一步：页号由各进程自己的虚拟地址空间决定

页号 = 虚拟地址 ÷ 页大小，是进程虚拟地址空间里的编号。进程 R 和 S 的虚拟空间布局各不相同，data 在两个进程中的虚拟地址没有必然联系，所以页号 p1 与 p2 不一定相等。

第二步：页框号由「共享同一份物理副本」决定

共享数据在物理内存中只有一份，R 和 S 要访问的是同一个物理副本，各自的页表项必须指向同一个页框，所以页框号 f1 与 f2 一定相等。

第三步：举一个具体例子验证

设页大小 4KB，data 放在物理页框 2：

进程页表项映射结果
R虚拟页 5→ 页框 2
S虚拟页 9→ 页框 2

p1 = 5 ≠ p2 = 9，但 f1 = f2 = 2，验证了 C。

易错点

  • 以为「共享同一数据」就必须共享同一虚拟页号：共享的是物理页框，不是虚拟地址；两个进程可以在各自不同的虚拟页位置上挂接同一页框。
  • 误选 B（p1、p2 一定相等）：虚拟空间彼此独立，页号没有相等的保证。
  • 误选 D（f1、f2 不一定相等）：若 f1 ≠ f2，两个进程访问到的就不是同一份数据，「共享」就失效了。
页号看各进程自己的虚拟空间（不一定相等），页框号看物理内存（共享必同页框），答案选 C。
