计算机组成原理

2023-43

高速缓冲存储器虚拟存储器
综合应用题 14 分

已知计算机 M 字长为 32 位，按字节编址，采用请求调页策略的虚拟存储管理方式，虚拟地址为 32 位，页大小为 4 KB；数据 Cache 采用 4 路组相联映射方式，数据区大小为 8KB，主存块大小为 32B。现有 C 语言程序段如下：

int a[24][64];
/* …… */
for (i = 0; i < 24; i++)
    for (j = 0; j < 64; j++)
        a[i][j] = 10;

已知二维数组 a 按行优先存放，在虚拟地址空间中分配的起始地址为 0042 2000H，sizeof(int) = 4，假定在 M 上执行上述程序段之前数组 a 不在主存，且在该程序段执行过程中不会发生页面置换。请回答下列问题。
1）数组 a 分布在几个页面中？对于数组 a 的访问，会发生几次缺页异常？页故障地址各是什么？
2）不考虑变量 i 和 j，该程序段的数据访问是否具有时间局部性？为什么？
3）计算机 M 的虚拟地址（A31～A0）中哪几位用作块内地址？哪几位用作 Cache 组号？a[1][0]的虚拟地址是多少？其所在主存块对应的 Cache 组号是多少？
4）数组 a 占用多少主存块？假设上述程序段执行过程中数组 a 的访问不会和其他数据发生 Cache 访问冲突，则数组 a 的 Cache 命中率是多少？若将循环中 i 和 j 的次序按如下方式调换：

for (j = 0; j < 64; j++)
    for (i = 0; i < 24; i++)
        a[i][j] = 10;

则数组 a 的 Cache 命中率又是多少？

答案

解答

1）数组 a 分布在几个页面中？对于数组 a 的访问，会发生几次缺页异常？页故障地址各是什么？

  • 页面数：2 个页面（页面大小 4KB，数组总大小 6144 字节）。
  • 缺页异常次数：2 次（每个页面首次访问时缺页）。
  • 页故障地址：00422000H（访问 a[0][0] 时）和 00423000H（访问 a[16][0] 时）。

2）不考虑变量 i 和 j，该程序段的数据访问是否具有时间局部性？为什么？

  • 不具有时间局部性。因为数组 a 的每个元素只被访问一次，没有重复访问。

3）计算机 M 的虚拟地址（A31～A0）中哪几位用作块内地址？哪几位用作 Cache 组号？a[1][0] 的虚拟地址是多少？其所在主存块对应的 Cache 组号是多少？

  • 块内地址：A4～A0（低 5 位，主存块大小 32B）。
  • Cache 组号：A10～A5（共 6 位，Cache 组数 64）。
  • a[1][0] 虚拟地址：00422100H。
  • Cache 组号：8（由 A10～A5 决定，001000₂ = 8₁₀）。

4）数组 a 占用多少主存块？假设上述程序段执行过程中数组 a 的访问不会和其他数据发生 Cache 访问冲突，则数组 a 的 Cache 命中率是多少？若将循环中 i 和 j 的次序调换，则数组 a 的 Cache 命中率又是多少？

  • 主存块数：192 块（总大小 6144B，块大小 32B）。
  • 按行优先访问命中率：87.5%（总访问 1536 次，Cache 缺失 192 次）。
  • 按列优先访问命中率：87.5%（同样缺页 192 次）。

本题讲解：数组访问的缺页、局部性与 Cache 命中率

答题框架：数组 a 共 24×64×4 = 6144B。四问分别落在三个机制上：页机制（请求调页按页整体调入）、地址划分模型（虚地址从低到高三段：块内偏移 | Cache 组号 | 其余位）、命中率统计（每主存块只缺一次，其余访问命中）。

第 0 步：先立地址模型——为什么各位数"自己长出来"

页机制：页大小 4KB = 2¹²B，虚地址低 12 位是页内偏移，其余高位是虚页号。请求调页以页为单位整体调入：首次触碰某页的访问触发缺页，页调入后整页常驻（题设期间不置换），此后该页上成百上千次访问都不再缺页。页故障地址就是引发缺页的那条访存指令给出的虚拟地址——缺页异常由地址变换机构在翻译这个地址时发现页不在主存而触发，硬件把这个虚地址锁存上报。

Cache 划分模型：一个虚地址从低位往高位切三段——

  • 块内偏移（最低 5 位）：主存块 32B = 2⁵B，按字节编址时块内连续存放，块内偏移天然就是地址的最低 5 位 A4～A0；
  • 组号（接着 6 位）：组数 = 数据区 8KB ÷（4 路 × 32B）= 64 = 2⁶ 组。为什么组号取"块号的低 6 位"？ 4 路组相联下，主存块号 b 落在 b mod 64 组；模 2⁶ 在二进制里就是砍掉高位于下取低 6 位，而块号 = 虚地址右移 5 位（去掉块内偏移），所以块号的低 6 位恰是地址的 A10～A5。为什么与 4 路无关？ 路数只决定每组能并列放几块、参与替换决策，不参与地址划分——组数 64 一旦确定，组号就是这 6 位。

第 1）问：页面数、缺页次数与页故障地址

起始地址 0042 2000H 的低 12 位为 0，恰好压在页首；6144B 跨 2 个页面：

页面虚拟地址范围装入的元素
第 1 页0042 2000H～0042 2FFFH（4096B）a[0][0]～a[15][63]
第 2 页0042 3000H～0042 37FFH（2048B）a[16][0]～a[23][63]

执行前数组不在主存，每页首次被触碰时各缺页一次：第一次访问 a[0][0]（地址 0042 2000H）触发第 1 页缺页；行优先推进到 a[16][0]，地址 = 0042 2000H + 16×64×4 = 0042 3000H，首次访问它时触发第 2 页缺页。故共 2 次缺页，页故障地址为 0042 2000H 与 0042 3000H。为什么 1536 次访问只有 2 次缺页？ 两次缺页后整页常驻且不置换，剩下 1534 次访问全部命中页表，与 Cache 命中与否无关——页机制在 Cache 之前已经把"要不要访主存"之外的问题解决了。

第 2）问：时间局部性

不具有时间局部性。时间局部性指"刚被访问过的信息，不久后还会被再次访问"；本程序每个元素 a[i][j] 赋值一次后不再被碰，整个程序段对同一数组元素只有一次访问。按行连续访问让相邻元素先后被使用，体现的是空间局部性；变量 i、j 按题意排除在外。

第 3）问：地址划分与 a[1][0]

由第 0 步的模型直接落位：块内地址 A4～A0，组号 A10～A5。

a[1][0] 的虚拟地址 = 0042 2000H + 1×64×4 = 0042 2100H（每行 64 个元素、每元素 4B，一行正好 256 = 100H）。其页内偏移 100H = 二进制 0001 0000 0000，取 A10～A5 = 001000 = 十进制 8，即所在主存块对应的 Cache 组号为 8。

第 4）问：主存块数与两种循环的命中率

数组占 6144 / 32 = 192 个主存块；总访问 24×64 = 1536 次。命中率的算法是每个主存块只缺失一次，其余访问命中——关键是论证两种循环下"每块只缺一次"都成立：

  • 原循环（行优先）：同一块里的 8 个相邻元素（32B ÷ 4B）被内层循环连续访问，每块只有第一次访问缺失 → 缺失 192 次，命中率 = (1536−192)/1536 = 87.5%；
  • 调换后（列优先）：内层一轮访问 a[0][j]～a[23][j]，相邻两次相距 256B，必属不同块，看起来要缺很多次；但换个视角——同一行的 8 个连续列元素同属一块，会在连续 8 轮外层循环中被先后重访。此时块还在不在 Cache？Cache 容量 64 组 × 4 路 = 256 块，而一轮内层循环同时活跃的块只有 24 块；这些块的块号彼此相差 8（每行 256B = 8 块），按 64 取模恰好集中到 8 个组里，每组最多 3 块，仍在 4 路容量之内，无冲突替换 → 每块仍只缺失一次，命中率仍 87.5%。

为什么两问答案一样？ 缺失次数由"每块是否被重复用到"决定，两种顺序下 192 块都恰好各被"冷启动"一次；差异只体现在缺页/装块的时序上，而题设恰好让 Cache 容量兜住了行距造成的跨度。

易错点

  • 页故障地址答成页号或物理地址：页故障地址是引发缺页的虚拟地址本身。
  • 组号位数算错或带上路数：组号位数由组数决定（64 组 → 6 位），组号 = 块号 mod 组数 = 块号低 6 位，路数不参与划分。
  • 以为列优先命中率大跳水：列优先跨块是事实，但"同块元素会在 8 轮内被重访 + Cache 装得下活跃块"两个条件保证了每块仍只缺一次。
  • 缺页次数答成 1536 或与 Cache 混算：缺页以页为单位、发生在每页首次触碰时，之后与 Cache 无关。
一句话结论：2 个页面、2 次缺页（00422000H、00423000H）；无时间局部性；块内 A4～A0、组号 A10～A5（组号=块号低 6 位）；a[1][0] = 00422100H、组号 8；192 块；两种循环命中率都是 87.5%（每块只缺一次）。
