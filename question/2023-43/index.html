高速缓冲存储器虚拟存储器
综合应用题 14 分

已知计算机 M 字长为 32 位，按字节编址，采用请求调页策略的虚拟存储管理方式，虚拟地址为 32 位，页大小为 4 KB；数据 Cache 采用 4 路组相联映射方式，数据区大小为 8KB，主存块大小为 32B。现有 C 语言程序段如下：

int a[24][64];
/* …… */
for (i = 0; i < 24; i++)
    for (j = 0; j < 64; j++)
        a[i][j] = 10;

已知二维数组 a 按行优先存放，在虚拟地址空间中分配的起始地址为 0042 2000H，sizeof(int) = 4，假定在 M 上执行上述程序段之前数组 a 不在主存，且在该程序段执行过程中不会发生页面置换。请回答下列问题。
1）数组 a 分布在几个页面中？对于数组 a 的访问，会发生几次缺页异常？页故障地址各是什么？
2）不考虑变量 i 和 j，该程序段的数据访问是否具有时间局部性？为什么？
3）计算机 M 的虚拟地址（A31～A0）中哪几位用作块内地址？哪几位用作 Cache 组号？a[1][0]的虚拟地址是多少？其所在主存块对应的 Cache 组号是多少？
4）数组 a 占用多少主存块？假设上述程序段执行过程中数组 a 的访问不会和其他数据发生 Cache 访问冲突，则数组 a 的 Cache 命中率是多少？若将循环中 i 和 j 的次序按如下方式调换：

for (j = 0; j < 64; j++)
    for (i = 0; i < 24; i++)
        a[i][j] = 10;

则数组 a 的 Cache 命中率又是多少？

答案

解答

1）数组 a 分布在几个页面中？对于数组 a 的访问，会发生几次缺页异常？页故障地址各是什么？

  • 页面数：2 个页面（页面大小 4KB，数组总大小 6144 字节）。
  • 缺页异常次数：2 次（每个页面首次访问时缺页）。
  • 页故障地址：00422000H（访问 a[0][0] 时）和 00423000H（访问 a[16][0] 时）。

2）不考虑变量 i 和 j，该程序段的数据访问是否具有时间局部性？为什么？

  • 不具有时间局部性。因为数组 a 的每个元素只被访问一次，没有重复访问。

3）计算机 M 的虚拟地址（A31～A0）中哪几位用作块内地址？哪几位用作 Cache 组号？a[1][0] 的虚拟地址是多少？其所在主存块对应的 Cache 组号是多少？

  • 块内地址：A4～A0（低 5 位，主存块大小 32B）。
  • Cache 组号：A10～A5（共 6 位，Cache 组数 64）。
  • a[1][0] 虚拟地址：00422100H。
  • Cache 组号：8（由 A10～A5 决定，001000₂ = 8₁₀）。

4）数组 a 占用多少主存块？假设上述程序段执行过程中数组 a 的访问不会和其他数据发生 Cache 访问冲突，则数组 a 的 Cache 命中率是多少？若将循环中 i 和 j 的次序调换，则数组 a 的 Cache 命中率又是多少？

  • 主存块数：192 块（总大小 6144B，块大小 32B）。
  • 按行优先访问命中率：87.5%（总访问 1536 次，Cache 缺失 192 次）。
  • 按列优先访问命中率：87.5%（同样缺页 192 次）。

本题讲解：数组访问的缺页、局部性与 Cache 命中率

答题框架

数组 a 共 24×64×4 = 6144B。四个问题分别对应：页划分（页 4KB）、时间局部性判断、Cache 地址划分（块 32B、数据区 8KB、4 路组相联）、命中率统计（总访问 24×64 = 1536 次）。

第 1）问：页面数、缺页次数与页故障地址

数组起始地址 0042 2000H（恰在页首，页内偏移 0），共 6144B，跨 2 个页面：

页面虚拟地址范围装入的元素
第 1 页0042 2000H～0042 2FFFH（4096B）a[0][0]～a[15][63]
第 2 页0042 3000H～0042 37FFH（2048B）a[16][0]～a[23][63]

请求调页方式下，每个页面首次被访问时各缺页一次，共 2 次。页故障地址就是引发缺页的虚拟地址：首次访问 a[0][0] 时为 0042 2000H；a[16][0] 的地址 = 0042 2000H + 16×64×4 = 0042 3000H，首次访问它时页故障地址为 0042 3000H。

第 2）问：时间局部性

不具有时间局部性。数组每个元素 a[i][j] 在整个程序段中只被赋值一次，被访问后不会再被重复访问；按行连续访问体现的是空间局部性。变量 i、j 不在考虑范围内。

第 3）问：地址划分与 a[1][0]

  • 主存块 32B = 2^5 B → 块内地址为 A4～A0（低 5 位）；
  • Cache 数据区 8KB、4 路组相联、块 32B → 组数 = 8KB / (4×32B) = 64 组 → 组号占 6 位，为 A10～A5；
  • a[1][0] 虚拟地址 = 0042 2000H + 1×64×4 = 0042 2100H；
  • 其页内偏移为 100H = 二进制 0001 0000 0000，取 A10～A5 = 001000 = 十进制 8，即所在主存块对应的 Cache 组号为 8。

第 4）问：主存块数与两种循环的命中率

数组占 6144 / 32 = 192 个主存块；总访问 1536 次。

  • 原循环（行优先）：按行访问时同一块内的 8 个元素被连续访问，每块只有第一次访问缺失 → 缺失 192 次，命中率 = (1536−192)/1536 = 87.5%；
  • 调换后（列优先）：内层一轮访问 a[0][j]～a[23][j]，相邻元素相距 256B、各属不同块；但同一行连续 8 列的元素同属一块，会在连续 8 轮外层循环中被重访。Cache 共 64 组×4 路 = 256 块容量，远大于同时活跃的块数（一轮 24 块，平均每组仅 3 块，不会冲突替换），因此每块仍只缺失一次 → 缺失仍 192 次，命中率仍 87.5%。

易错点

  • 页故障地址答成页号或物理地址：页故障地址是引发缺页的虚拟地址本身。
  • 组号位数算错：组号位数由组数决定（64 组 → 6 位），与路数无关。
  • 以为列优先命中率大跳水：Cache 容量足够且无冲突替换时，每个块仍只装调一次，命中率不变。
一句话结论：2 个页面、2 次缺页（00422000H、00423000H）；无时间局部性；块内 A4～A0、组号 A10～A5；a[1][0] = 00422100H、组号 8；192 块；两种循环命中率都是 87.5%。
