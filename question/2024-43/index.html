指令系统指令的寻址方式运算方法和运算电路数据通路的功能和基本结构控制器的功能和工作原理
综合应用题 13 分

假定计算机M字长为32位，按字节编址，采用32位定长指令字，指令add、slli和lw的格式、编码和功能说明如题43图(a)所示。

其中，R[x] 表示通用寄存器 x 的内容，M[x] 表示地址为 x 的存储单元内容，shamt 为移位位数，imm 为补码表示的偏移量。
题43图（b）给出了计算机 M 的部分数据通路及其控制信号（用带箭头虚线表示），其中，A 和 B 分别表示从通用寄存器 rs1 和 rs2 中读出的内容；IR[31:20] 表示指令寄存器中的高 12 位；控制信号 Ext 为 0、1 时扩展器分别实现零扩展、符号扩展，ALUctr 为 000、001、010 时 ALU 分别实现加、减、逻辑左移运算。

请回答下列问题。
（1）计算机 M 最多有多少个通用寄存器？为什么 shamt 字段占 5 位？（2 分）
（2）执行 add 指令时，控制信号 ALUBsrc 的取值应是什么？若 rs1 和 rs2 寄存器内容分别是 8765 4321H 和 9876 5432H，则 add 指令执行后，ALU 输出端 F、OF 和 CF 的结果分别是什么？若该 add 指令处理的是无符号整数，则应根据哪个标志判断是否溢出？（5 分）
(3) 执行 slli 指令时，控制信号 Ext 的取值可以是 0 也可以是 1，为什么？(2分)
(4) 执行 lw 指令时，控制信号 Ext、ALUctr 的取值分别是什么？(2分)
(5) 若一条指令的机器码是 A040 A103H，则该指令一定是 lw 指令，为什么？若执行该指令时，R[01H]=FFFF A2D0H，则所读取数据的存储地址是什么？(2分)

答案

（1）最多有32个通用寄存器。因为指令中rs1、rs2字段各占5位，可表示2⁵=32个不同寄存器编号。shamt字段占5位，是因为字长为32位，移位位数范围为0~31，需要5位二进制表示。

（2）ALUBsrc取值应为0（选择寄存器B作为ALU第二操作数）。
F = 87654321H + 98765432H = 1FDB9753H。
OF = 1（有符号溢出），CF = 1（无符号进位）。
若处理无符号整数，应根据CF判断是否溢出。

（3）因为slli指令的移位位数只使用IR[31:20]字段中的低5位（shamt），扩展器扩展的高位结果不会被使用，所以Ext取值可以是0或1。

（4）Ext取值应为1（符号扩展偏移量），ALUctr取值应为000（ALU执行加法，计算有效地址）。

（5）机器码A040A103H对应的二进制指令格式中，操作码IR[6:0]=0000011B（对应lw），功能码IR[14:12]=010B，符合题43图(a)中lw指令的编码规则，因此一定是lw指令。
存储地址 = R[01H] + 符号扩展(A04H) = FFFFA2D0H + FFFFFA04H = FFFF9CD4H。

本题讲解：从位段到控制信号——add/slli/lw 在同一条数据通路上走一遍

第 0 步：机制先行——一条指令如何变成数据通路上的动作

机器指令是位段的拼装：32 位定长，操作码 IR[6:0] 决定"这是哪条指令"（add=0110011、slli=0010011、lw=0000011，三条互不相同），功能码 IR[14:12] 在需要时进一步细分，rd、rs1、rs2 各占 5 位指名寄存器编号；lw 的 IR[31:20] 是 12 位补码偏移 imm，slli 的 IR[24:20] 是移位量 shamt。

取指之后，控制器按位段译码，产生控制信号指挥数据通路这条"流水线"：rs1 读出的内容走 A 进 ALU 左输入；rs2 读出的内容走 B 进多路选择器（MUX）的 0 端；IR[31:20] 先过扩展器（Ext=0 零扩展、Ext=1 符号扩展）再进 MUX 的 1 端；ALUBsrc 决定 MUX 放行哪一路；ALUctr（000 加、001 减、010 逻辑左移）决定 ALU 做什么运算，同时产出 F、OF、SF、ZF、CF。

于是每一问的解法都是同一句口诀：看指令需要什么操作数、什么运算，就把 MUX 拨到对应挡位、给 ALUctr 对应编码。

第（1）问：寄存器个数与 shamt 位数（2 分）

rs1、rs2 字段各占 5 位，5 位二进制能表示 2⁵ = 32 个不同编号，所以最多有 32 个通用寄存器。shamt 占 5 位：字长 32 位，逻辑左移的移位位数有效范围是 0~31，恰好 32 种取值，5 位编码正好覆盖——超过 31 的移位量对 32 位数没有意义。寄存器编号与移位位数"巧合地"同为 5 位，本质是同一个原理：32 种取值需要 5 个比特。

第（2）问：ALUBsrc 取值、加法结果与标志位（5 分）

add 的功能是 R[rd] ← R[rs1] + R[rs2]：两个操作数都是寄存器内容，第二个操作数要选 rs2 读出的 B，而不是扩展器输出的立即数 → MUX 走 0 端，ALUBsrc = 0。

加法 87654321H + 98765432H 按字节从低到高逐段算：最低字节 21H+32H=53H，无进位；43H+54H=97H，无进位；65H+76H=DBH，无进位；最高字节 87H+98H=11FH——本位留下 1FH，并向第 33 位溢出一位进位。所以：

  • F = 1FDB9753H：ALU 输出端是 32 位结果，第 33 位的进位不进 F；
  • CF = 1：CF 记录的就是"最高位向前的进位"，那个 11FH 里多出来的 1；
  • OF = 1：两个操作数的符号位都是 1（补码意义下都是负数），负数加负数，真值只会更负，结果符号位理应还是 1；现在结果符号位却是 0（1FDB9753H 首位是 0001）——"同号相加得异号"是有符号溢出的铁证。它的电路根源是：进位进入符号位（0）与进位传出符号位（1）不一致，ALU 对两者做异或得 OF=1。
  • 若该 add 处理的是无符号整数，应根据 CF 判断溢出：无符号数没有"符号"概念，它的"溢出"就是和超出 0 ~ 2³²−1，表现恰好是最高位产生进位；而 OF 盯的是补码（有符号）范围。两套标志、两种视角——本题两者恰好都为 1。

第（3）问：slli 的 Ext 为什么 0、1 都可以（2 分）

slli 需要的只是 IR[31:20] 中的低 5 位 shamt：32 位移位量只可能取 0~31，移位器只读这 5 位，扩展器补出来的高 27 位根本不参与运算。既然"高位补 0"和"高位补 1"两种结果在使用时毫无区别，这个信号对本指令就是无效的——控制器填 0 还是 1 都行，硬件功能不受影响。

第（4）问：lw 的 Ext 与 ALUctr（2 分）

lw 的功能是 R[rd] ← M[R[rs1] + imm]。imm 是补码表示的偏移量，可为负：地址计算是带符号的加法，若按零扩展，负偏移会被错读成一个巨大的正数；而补码扩展的规则是高位补符号位、数值不变（FFFH 的"欠账"没变，只是换了个更大的模来记账）→ Ext = 1。有效地址 R[rs1] + imm 是一次加法 → ALUctr = 000。

第（5）问：A040 A103H 为什么一定是 lw、访存地址是多少（2 分）

A040 A103H = 1010 0000 0100 0000 1010 0001 0000 0011B，按位段拆开：

位段IR[31:20]IR[19:15]IR[14:12]IR[11:7]IR[6:0]
值A04H（imm）00001（rs1=01H）01000010（rd）0000011

"一定"的底气来自操作码的唯一性：三条指令的操作码互不相同（add 0110011、slli 0010011、lw 0000011），操作码一锁定，指令身份就唯一。机器码的操作码 0000011 与 lw 吻合（功能码 010 也与 lw 一致），与 add、slli 均不符——所以它只能是 lw。

地址计算：imm = A04H = 1010 0000 0100B，最高位为 1，是负数——A04H ≡ −1532 (mod 1000H)（1000H − A04H = 5FCH = 1532）。符号扩展到 32 位，就是同一个负数在更大模下的化身 FFFF FA04H，数值不变。有效地址 = R[01H] + FFFFFA04H = FFFFA2D0H + FFFFFA04H = FFFF 9CD4H（32 位截断进位）。

易错点

  • F 答成 33 位：进位 1 是给 CF 的，ALU 输出端 F 只保留 32 位 1FDB9753H。
  • OF/CF 混用：有符号数溢出看 OF（判据"同号相加得异号"），无符号数溢出看 CF，别答反。
  • slli 的 Ext 答死值：关键不在"必须零扩展"，而在"扩展出的高位不被使用"，信号无效才两可。
  • imm 按无符号读：把 A04H 当 2564 加进去，地址会错成 FFFFACD4H；最高位 1 是负数记号，必须符号扩展。
  • 第（5）问只凭"像 lw"下结论：要落实到位段逐位比对——操作码与功能码同时吻合，且与另两条指令的编码不符，才配得上"一定"二字。
一句话结论：32 个寄存器、shamt 5 位；ALUBsrc=0，F=1FDB9753H，OF=CF=1，无符号看 CF；slli 的 Ext 0/1 均可；lw 的 Ext=1、ALUctr=000；A040A103H 因操作码 0000011（加功能码 010）唯一命中 lw，有效地址 FFFF9CD4H。
