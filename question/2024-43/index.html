指令系统指令的寻址方式运算方法和运算电路数据通路的功能和基本结构控制器的功能和工作原理
综合应用题 13 分

假定计算机M字长为32位，按字节编址，采用32位定长指令字，指令add、slli和lw的格式、编码和功能说明如题43图(a)所示。

其中，R[x] 表示通用寄存器 x 的内容，M[x] 表示地址为 x 的存储单元内容，shamt 为移位位数，imm 为补码表示的偏移量。
题43图（b）给出了计算机 M 的部分数据通路及其控制信号（用带箭头虚线表示），其中，A 和 B 分别表示从通用寄存器 rs1 和 rs2 中读出的内容；IR[31:20] 表示指令寄存器中的高 12 位；控制信号 Ext 为 0、1 时扩展器分别实现零扩展、符号扩展，ALUctr 为 000、001、010 时 ALU 分别实现加、减、逻辑左移运算。

请回答下列问题。
（1）计算机 M 最多有多少个通用寄存器？为什么 shamt 字段占 5 位？（2 分）
（2）执行 add 指令时，控制信号 ALUBsrc 的取值应是什么？若 rs1 和 rs2 寄存器内容分别是 8765 4321H 和 9876 5432H，则 add 指令执行后，ALU 输出端 F、OF 和 CF 的结果分别是什么？若该 add 指令处理的是无符号整数，则应根据哪个标志判断是否溢出？（5 分）
(3) 执行 slli 指令时，控制信号 Ext 的取值可以是 0 也可以是 1，为什么？(2分)
(4) 执行 lw 指令时，控制信号 Ext、ALUctr 的取值分别是什么？(2分)
(5) 若一条指令的机器码是 A040 A103H，则该指令一定是 lw 指令，为什么？若执行该指令时，R[01H]=FFFF A2D0H，则所读取数据的存储地址是什么？(2分)

答案

（1）最多有32个通用寄存器。因为指令中rs1、rs2字段各占5位，可表示2⁵=32个不同寄存器编号。shamt字段占5位，是因为字长为32位，移位位数范围为0~31，需要5位二进制表示。

（2）ALUBsrc取值应为0（选择寄存器B作为ALU第二操作数）。
F = 87654321H + 98765432H = 1FDB9753H。
OF = 1（有符号溢出），CF = 1（无符号进位）。
若处理无符号整数，应根据CF判断是否溢出。

（3）因为slli指令的移位位数只使用IR[31:20]字段中的低5位（shamt），扩展器扩展的高位结果不会被使用，所以Ext取值可以是0或1。

（4）Ext取值应为1（符号扩展偏移量），ALUctr取值应为000（ALU执行加法，计算有效地址）。

（5）机器码A040A103H对应的二进制指令格式中，操作码IR[6:0]=0000011B（对应lw），功能码IR[14:12]=010B，符合题43图(a)中lw指令的编码规则，因此一定是lw指令。
存储地址 = R[01H] + 符号扩展(A04H) = FFFFA2D0H + FFFFFA04H = FFFF9CD4H。

本题讲解：指令格式、ALU 标志位与数据通路控制信号

答题框架

三条指令共用 32 位定长格式，位段划分一致：操作码 IR[6:0]、rd IR[11:7]、功能码 IR[14:12]、rs1 IR[19:15]、rs2/shamt IR[24:20]、imm IR[31:20]。数据通路关键点：A = rs1 读出值（ALU 左输入），B = rs2 读出值（MUX 的 0 端），扩展器输出（MUX 的 1 端）来自 IR[31:20]，ALUctr 中 000=加、001=减、010=逻辑左移。五问的主线都是"先定位段，再定控制信号，最后代入数值算"。

第（1）问：寄存器个数与 shamt 位数（2 分）

rs1、rs2 字段各占 5 位，可表示 2^5 = 32 个寄存器编号，故最多有 32 个通用寄存器。shamt 占 5 位：字长为 32 位，逻辑左移的移位位数范围是 0～31，共 32 种取值，需要 2^5 = 32 个编码，恰好 5 位。

第（2）问：ALUBsrc 取值与加法结果（5 分）

add 功能为 R[rd] <- R[rs1] + R[rs2]，ALU 第二操作数应选寄存器 B（而不是扩展器输出）→ ALUBsrc = 0。

加法 87654321H + 98765432H，按十六进制逐位验算：

权值16^716^616^516^416^316^216^116^0
加数 187654321
加数 298765432
和1FDB9753

从低位起：1+2=3、2+3=5、3+4=7、4+5=9、5+6=B、6+7=D、7+8=F；最高位 8+9=17（十进制），本位写 1、产生进位。

  • ALU 输出端 F = 1FDB9753H（32 位结果）；
  • OF = 1：两个操作数的符号位都是 1（负数），而结果的符号位是 0（正数）——负加负得正，有符号溢出；
  • CF = 1：最高位相加产生了进位；
  • 若该 add 处理的是无符号整数，应根据 CF 判断是否溢出（CF=1 即无符号溢出）。

第（3）问：slli 的 Ext 可 0 可 1（2 分）

slli 的移位位数只使用 IR[31:20] 字段中的低 5 位（shamt），扩展器扩展出的高位结果不会被使用，所以无论零扩展还是符号扩展，对移位操作没有影响——Ext 取 0 或 1 都可以。

第（4）问：lw 的 Ext 与 ALUctr（2 分）

lw 功能为 R[rd] <- M[R[rs1] + imm]：

  • imm 是补码表示的偏移量，可能为负 → Ext = 1（符号扩展）；
  • 有效地址 = R[rs1] + imm，做加法 → ALUctr = 000（加法）。

第（5）问：A040 A103H 一定是 lw（2 分）

A040 A103H = 1010 0000 0100 0000 1010 0001 0000 0011B，按位段拆开：

位段IR[31:20]IR[19:15]IR[14:12]IR[11:7]IR[6:0]
值A04H（imm）00001（rs1=1）01000010（rd=2）0000011
  • 操作码 IR[6:0] = 0000011，与题 43 图(a) 中 lw 的操作码一致；功能码 IR[14:12] = 010 也与 lw 一致；
  • 而 add 的操作码是 0110011、slli 的操作码是 0010011，均不符——三个操作码互不相同，对上唯一的一个就是 lw，故该指令一定是 lw；
  • 地址计算：imm = A04H，符号位为 1，符号扩展为 FFFF FA04H（值 −1532）；有效地址 = R[01H] + FFFFFA04H = FFFFA2D0H + FFFFFA04H = FFFF 9CD4H。

易错点

  • F 答成 33 位：最高位 8+9=17 的进位送 CF，ALU 输出端 F 是 32 位结果 1FDB9753H。
  • OF/CF 用反：有符号数溢出看 OF，无符号数溢出看 CF。
  • slli 的 Ext 答死值：关键在"扩展结果的高位不被使用"，而不是"必须零扩展"。
  • 第（5）问只答"像 lw"：要落实到位段逐位比对——操作码与功能码同时吻合，且与 add/slli 的编码不符，才能下"一定"的结论。
一句话结论：32 个寄存器、shamt 5 位；ALUBsrc=0，F=1FDB9753H，OF=CF=1，无符号看 CF；slli 的 Ext 0/1 均可；lw 的 Ext=1、ALUctr=000；A040A103H 因操作码 0000011 与功能码 010 双吻合必为 lw，有效地址 FFFF9CD4H。
