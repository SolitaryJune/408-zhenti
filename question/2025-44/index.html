指令系统运算方法和运算电路程序的机器级代码表示异常和中断机制
综合应用题 9 分

补充条件（来源：2025 年第 43 题）

运行程序 P 的计算机 M 字长为 32 位，按字节编址。程序 P 的相关代码如下：

int x, d[2048], i;
...
for (i = 0; i < 2048; i++)
    d[i] = d[i] / x;
...

本题题干

对于题 43 中的计算机 M 和程序 P，假定 P 的部分机器级代码如下，其中 R0～R4 为通用寄存器，SEXT 表示按符号扩展；M 中补码除法器的逻辑结构如图所示。

...
// x 在 R2 中，i 在 R4 中
// 数组 d 的首地址在 R3 中
mov  R1, (R3 + R4 * 4)    // R1 <- d[i]
scov R1                   // {R0, R1} <- SEXT(R1)
idiv R1, R3               // R1 <- ({R0, R1} / R2)
...

请回答下列问题，并说明理由：

(1) 若执行 idiv 指令的除运算时，d[i]=0x87654321，x=0xFF，则补码除法器中寄存器 R、Q 和 Y 的初始内容分别是什么（用十六进制表示）？图中哪个部件包含计数器？在补码除法器执行过程中，由 ALUop 所控制的 ALU 运算有哪几种？（4 分）
(2) 假设 idiv 指令执行过程中会检测并触发除法异常，则执行 idiv 指令时，哪些情况会发生除法异常（要求给出此时 d[i] 和 x 的十六进制机器数）？发生除法异常时，在异常响应过程中 CPU 需要完成哪些操作？（5 分）

答案

（1）R=FFFFFFFFH，Q=87654321H，Y=000000FFH。控制逻辑计数器 Cn 中包含计数器。控制的运算有加法和减法两种。

（2）两种情况会发生除法异常：

  • x 为 0000 0000H 时，发生除 0 异常，此时 d[i] 可以是表达范围内的任意值；
  • d[i]=8000 0000H 时，发生溢出异常，此时 x=FFFF FFFFH。

异常响应过程中 CPU 需要完成的操作为：

  1. 保存断点和程序状态；
  2. 关中断；
  3. 跳转到异常处理程序执行。

本题讲解：补码除法器的初始寄存器内容与除法异常

答题框架

先按机器级代码顺序推 idiv 执行前的寄存器内容：mov 装入被除数，scov 把 32 位被除数符号扩展成 64 位存入 {R0, R1}，除数 x 在 R2；再对照除法器结构答出 R、Q、Y 的初始内容与计数器位置；最后按「除数为 0」和「商溢出」两种情形分析除法异常及响应过程。

第（1）问：R、Q、Y 的初始内容、计数器与 ALU 运算

  • 执行到 idiv 时：R1 = d[i] = 87654321H（最高位为 1，是负数）；除数 x = 0xFF；
  • scov R1 把 R1 按符号扩展成 64 位：{R0, R1} = FFFF FFFF 8765 4321H，即 R0 = FFFFFFFFH、R1 = 87654321H；
  • 对照补码除法器结构，三个寄存器的初始内容见下表：
寄存器初始内容说明
RFFFFFFFFH被除数的高 32 位，由符号扩展产生
Q87654321H被除数的低 32 位
Y000000FFH除数 x
  • 计数器：控制逻辑（部件）中包含计数器 Cn，用来控制加/减与移位的步数；
  • ALUop 控制的 ALU 运算只有 加法、减法 两种（除法过程中做减法试商、加法调整余数）。

第（2）问：除法异常的情形与响应操作

idiv 检测并触发除法异常的两种情况：

情形d[i]（被除数）x（除数）原因
除 0 异常表示范围内的任意值0000 0000H除数为 0，商无定义
商溢出异常8000 0000HFFFF FFFFH−2^31 ÷ (−1) = 2^31，超出 int 表示范围

发生除法异常后，异常响应过程中 CPU 需要：

  1. 保存断点和程序状态（保存被中断指令的下一条地址与程序状态字等现场）；
  2. 关中断（防止异常响应过程被新的中断请求打断）；
  3. 跳转到异常处理程序执行（转入除法异常处理服务程序）。

易错点

  • R 答成 00000000H：符号扩展看被除数最高位，87654321H 是负数，高 32 位全 1。
  • 溢出情形写错组合：只有最小负数 −2^31（8000 0000H）除以 −1（FFFF FFFFH）时商 2^31 才装不下；除数是其他非零值时商都在范围内。
  • 响应操作漏「关中断」：标准三步是保存断点和程序状态、关中断、转异常处理程序。
一句话结论：R = FFFFFFFFH、Q = 87654321H、Y = 000000FFH，计数器在控制逻辑中，ALU 只做加法和减法；x = 00000000H 或（d[i] = 80000000H 且 x = FFFFFFFFH）时触发除法异常，响应时保存断点和程序状态、关中断、转异常处理程序。
