本题讲解：双向链表 p2 指针整体改链的代码判定

答案：D

第一步：把题意翻译成指针等式

结点中 p2 指向直接前驱、p1 指向直接后继。目标：对 L 的每个结点，把它的 p2 改为指向「p1 所指结点的直接后继」，即当 cu->p1 存在时执行 cu->p2 = cu->p1->p1；当 cu->p1 为 NULL（尾结点）时，p1 所指结点不存在，其直接后继也不存在，按题意 p2 应置 NULL。头结点也是 L 的结点（cu 从 head 出发），同样要处理。

第二步：找每个选项的致命点

选项致命点
A尾结点的 cu->p1 为 NULL，仍执行 cu->p1->p1，解引用空指针出错
B循环条件要求 cu->p2 != NULL，而头结点的 p2 初值是 NULL，循环一次都不执行
C尾结点处 cu->p1 为 NULL 时 if 不成立、cu 也不更新，死循环
Dcu->p1 为 NULL 时置 cu->p2 = NULL 并让 cu 前进，处理完整条链后正常结束

第三步：用一条 3 结点链验证 D

设 head 指向头结点，链为 head→a1→a2→a3→NULL，cu 从 head 出发：

cu判断本步修改
headp1 = a1 非空head 的 p2 改为 a2
a1p1 = a2 非空a1 的 p2 改为 a3
a2p1 = a3 非空a2 的 p2 改为 NULL（a3 的 p1 是 NULL）
a3p1 = NULLa3 的 p2 置 NULL，cu = a3 的 p1 = NULL，循环结束

每个结点都被正确改写，遍历沿 p1 进行、修改 p2 不影响前进路线，D 正确。

易错点

  • 忽略头结点：头结点没有前驱，p2 初值是 NULL，这正是 B 选项循环条件直接失效的原因。
  • 忽略尾结点：尾结点的 p1 为 NULL，是 A 崩溃、C 死循环的共同根源。
  • 误以为必须单独处理倒数第二个结点：cu->p1->p1 在 cu 为倒数第二个结点时值为 NULL，直接赋值即可，D 的 if 分支天然涵盖。
一句话结论：能同时正确处理「头结点 p2 初值 NULL」与「尾结点 p1 为 NULL」的只有 D。
