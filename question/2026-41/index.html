树形查找
综合应用题 13 分

已知二叉搜索树采用二叉链表存储，类型定义如下：

typedef struct BSTNode                 //二叉搜索树结点
{   int data;                          //保存结点的关键字值
    struct BSTNode * left, * right;    //指向左孩子、右孩子的指针
} BinTNode;
typedef BinTNode * BTree;              //二叉搜索树

对于给定的非空二叉搜索树 T（root 为指向 T 的根结点的指针）和整数 k，请设计尽可能高效的查找算法：

void searchX( BTree root, int k )

查找 T 中其关键字值与 k 之差的绝对值最小的所有结点，输出差值的绝对值和结点中的关键字值。要求：

（1）给出算法的基本设计思想。（4 分）

（2）根据设计思想，采用 C 或 C++ 语言描述算法，关键之处给出注释。（9 分）

答案

（1）算法的基本设计思想

按照在二叉搜索树中查找目标 k 的方法，从根开始沿着某条向下的路径进行查找。若当前结点中的关键字值与 k 相等，则结果只包含一个结点，差值的绝对值为 0，不相等时，结果最多包含两个结点，差值的绝对值大于 0。

对于不相等的情况，若当前结点中的关键字值大于 k，则结果只可能是当前结点或/及左子树中的结点，此时沿 left 指针继续查找。若当前结点中的关键字值小于 k，则结果只可能是当前结点或/及右子树中的结点，此时沿 right 指针继续查找。直到遇到空指针时为止。

（2）算法实现

void searchX( BTree root, int k )
{   BTree p = root, pmin1, pmin2;
    int min = MAX;                          //MAX 为能表示的整型最大值
    if ( p == NULL ) return;                //若为空树，则返回
    while( p != NULL )
    {   if ( p->data == k )                 //结果只包含一个结点
        {   min = 0;
            printf ( "差值绝对值 = %d 结点 = %d\n", min, p->data );
            return;
        }
        else if ( abs( p->data-k ) < min )  //出现差值绝对值更小的结点
        {   min = abs( p->data-k );
            pmin1 = pmin2 = p;
        }
        else if ( abs( p->data-k ) == min ) //出现另一个差值绝对值为 min 的结点
            pmin2 = p;
        if ( p->data > k )
            p = p->left;    //若当前结点的 data>k，则结果还可能在左子树中
        else
            p = p->right;   //若当前结点的 data<k，则结果还可能在右子树中
    }
    if ( pmin1->data != pmin2->data )
        printf ( "差值绝对值 = %d 结点 1 = %d 结点 2 = %d\n",
        min, pmin1->data, pmin2->data );
    else
        printf ( "差值绝对值 = %d 结点 = %d\n", min, pmin1->data );
    return;
}

本题讲解：二叉搜索树中找与 k 差值最小的结点

第一步：问 1 —— 答题框架（4 分）

设计思想按「怎么走、记什么、何时停」三句话给足：

  1. 怎么走：利用二叉搜索树的有序性，按「查找 k」的方式从根出发沿一条向下的单一路径查找：当前结点值大于 k 就进入左子树，小于 k 就进入右子树，直到遇到空指针。
  2. 记什么：行进途中沿途记录差值绝对值最小的结点。若某结点值恰好等于 k，差值绝对值为 0，结果只含这一个结点；若不相等，结果最多包含两个结点（k 上下两侧各一个候选），差值绝对值大于 0。
  3. 何时停：走到空指针或已命中 k 时结束，输出差值绝对值与对应结点的关键字。

第二步：为什么只需考察路径上的结点（问 1 的得分点）

设当前结点值为 v：

  • v > k 时，右子树中所有值都不小于 v，它们与 k 的差都大于 v−k，不可能是更优答案，候选只可能是当前结点或/及左子树中的结点，沿 left 指针继续；
  • v < k 时对称，候选只可能是当前结点或/及右子树中的结点，沿 right 指针继续。

每一步要么结束、要么范围缩到一棵子树，因此路径上的结点已覆盖全部候选，时间复杂度为 O(h)（h 为树高），空间 O(1)。

第三步：问 2 —— 算法实现（9 分）

用 p 沿路径下行，min 记当前最小差值，pmin1、pmin2 记录取得最小差值的结点（最多两个）：

取 BST：50 的左孩子 30（30 的孩子为 20、40，40 的左孩子 35），右孩子 70（孩子 60、80）。令 k = 45：

p 指向差值绝对值动作min / pmin1 / pmin2

NULL—循环结束，输出差值 5，结点 50 与 40

易错点

  • 全树遍历：中序遍历全树虽然正确，但为 O(n)，没有利用 BST 的有序性，不满足「尽可能高效」。
  • 只记一个候选：k 恰好落在两个结点值正中间时，差值最小者有两个，漏掉 pmin2 会丢解。
  • 忘记 k 等于某结点值的情形：此时差值 0 且唯一，应立即输出返回，否则会继续误判。
  • 空树未处理：入口处判 root 是否为 NULL，避免解引用空指针。
一句话结论：沿 BST 查找路径边走边记最小差值，命中即返回，走到空指针时路径上的候选至多两个，时间 O(h)、空间 O(1)。
