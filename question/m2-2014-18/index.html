微分方程
解答题 10 分

设函数 $f(u)$ 二阶连续可导, $z=f\left(\mathrm{e}x \cos y\right)$ 满足 $\displaystyle \frac{\partial2 z}{\partial x2}+\frac{\partial2 z}{\partial y2}=\left(4 z+\mathrm{e}x \cos y\right) \mathrm{e}2 x$, 若 $f(0)=0, f\prime(0)=0$, 求 $f(u)$ 的表达式

答案

【分析】这是复合函数求二阶偏导反推 $f$ 的题。令 $u=\mathrm ex\cos y$，把 $z_{xx}+z_{yy}$ 算出来，利用 $\cos2y+\sin2y=1$ 会奇迹般地凑成只含 $f''$ 的式子，从而把偏微分方程化成关于 $f(u)$ 的常系数二阶线性 ODE，再用两个初值定常数。 【解答】设 $u=\mathrm ex\cos y$。 $$z_x=f'(u)\,\mathrm ex\cos y,\qquad z_{xx}=f''(u)\,\mathrm e2x\cos2y+f'(u)\,\mathrm ex\cos y,$$ $$z_y=-f'(u)\,\mathrm ex\sin y,\qquad z_{yy}=f''(u)\,\mathrm e2x\sin2y-f'(u)\,\mathrm ex\cos y.$$ 相加，$f'(u)\,\mathrm ex\cos y$ 两项抵消，且 $\cos2y+\sin2y=1$： $$z_{xx}+z_{yy}=f''(u)\,\mathrm e2x.$$ 代入题设 $z_{xx}+z_{yy}=(4z+\mathrm ex\cos y)\mathrm e2x=(4f(u)+u)\mathrm e2x$，约去 $\mathrm e2x>0$： $$f''(u)-4f(u)=u.$$ 齐次方程特征根 $r=\pm2$，齐次解 $C_1\mathrm e2u+C_2\mathrm e-2u$；特解设 $f^*=au+b$，代入得 $-4(au+b)=u$，故 $a=-\dfrac14,\ b=0$。于是 $$f(u)=C_1\mathrm e2u+C_2\mathrm e-2u-\frac14 u.$$ 由 $f(0)=0$：$C_1+C_2=0$。$f'(u)=2C_1\mathrm e2u-2C_2\mathrm e-2u-\dfrac14$，由 $f'(0)=0$：$2C_1-2C_2-\dfrac14=0$，即 $C_1-C_2=\dfrac18$。解得 $C_1=\dfrac{1}{16},\ C_2=-\dfrac{1}{16}$。 $$f(u)=\frac{1}{16}\left(\mathrm e2u-\mathrm e-2u\right)-\frac14 u.$$ 验算：$f''(u)=\dfrac{4}{16}(\mathrm e2u-\mathrm e-2u)=\dfrac14(\mathrm e2u-\mathrm e-2u)$，$4f(u)=\dfrac14(\mathrm e2u-\mathrm e-2u)-u$，故 $f''-4f=u$，且 $f(0)=0,\ f'(0)=0$，全部吻合。

自评得分：
18

本题讲解：调和变量让 $f'$ 项成对消去——偏微分方程化归为常微分方程

答案：$f(u)=\dfrac{1}{16}\left(e2u-e-2u\right)-\dfrac{u}{4}$。

第 0 步：先立机制——"奇迹消项"不是奇迹

一切"复合函数的偏微分方程反推 $f$"的题，流程固定三段：①设中间变量，算出 $z_{xx}+z_{yy}$；②代入方程，化成 $f(u)$ 的常微分方程；③用初值定常数。本题真正的机关在：$u=ex\cos y$ 是调和函数——它自己就满足

$$\frac{\partial2u}{\partial x2}+\frac{\partial2u}{\partial y2}=ex\cos y-ex\cos y=0.$$

链式法则对复合函数二阶求导时，除了 $f''(u)$ 项必然还会拖出一串 $f'(u)$ 项，其系数恰是 $\dfrac{\partial2u}{\partial x2}+\dfrac{\partial2u}{\partial y2}$——调和性让这一串 $f'$ 项整体归零。所以"两相抵消"是结构性必然，出题人选 $ex\cos y$ 就是为了这个。

第一步：链式法则求一阶偏导

$z=f(u)$，$u=ex\cos y$：

$$z_x=f'(u)\,ex\cos y,\qquad z_y=-f'(u)\,ex\sin y.$$

第二步：再求一次——为什么会出现 $f'$ 项

对 $z_x=f'(u)\,ex\cos y$ 再求 $x$ 导时，$u_x=ex\cos y$ 也要跟着求导（"先乘后导"），于是劈成两项：

$$z_{xx}=f''(u)\,e2x\cos2y+f'(u)\,ex\cos y,$$

$$z_{yy}=f''(u)\,e2x\sin2y-f'(u)\,ex\cos y.$$

看第二式的结构：$f''$ 项的系数是 $u_y2$，$f'$ 项的系数是 $u_{yy}=-ex\cos y$。这就是第 0 步说的机制：$f'$ 项的系数最终全靠 $u_{xx}$ 与 $u_{yy}$ 对账，而 $u_{xx}+u_{yy}=0$，注定相消。$z_{yy}$ 最易漏项：对 $-f'(u)ex\sin y$ 求 $y$ 导，$-f''(u)ex\sin y$ 与 $-f'(u)ex\cos y$ 都要写，漏掉后者，抵消就不成立。

第三步：相加——调和性兑现

$$z_{xx}+z_{yy}=f''(u)\,e2x\left(\cos2y+\sin2y\right)+f'(u)\left(ex\cos y-ex\cos y\right)=f''(u)\,e2x.$$

两处化简各司其职：$f'$ 项因 $\Delta u=0$ 成对消去；$f''$ 项因 $\cos2y+\sin2y=1$ 收拢成一个系数。偏微分方程被压成一条只含 $f$ 的等式。

第四步：代入并约去 $e2x$——为什么可以约

题设右边 $=\left(4z+ex\cos y\right)e2x$，其中 $z=f(u)$、$ex\cos y=u$，故右边 $=\left(4f(u)+u\right)e2x$。于是

$$f''(u)\,e2x=\left(4f(u)+u\right)e2x.$$

$e2x>0$ 恒成立，两边同除不改变方程——这一约，把 $x,y$ 彻底送走，剩下纯 $u$ 的常微分方程：

$$f''(u)-4f(u)=u.$$

第五步：解常微分方程——为什么特解设 $au+b$

特征方程 $r2-4=0$，$r=\pm2$，齐次解 $C_1e2u+C_2e-2u$。右端 $u$ 是一次多项式，按"同次多项式试探"设特解 $au+b$：代入得 $-4(au+b)=u$，比较系数 $a=-\dfrac14,\ b=0$。为什么敢设一次式：$4\neq0$ 不是特征根，多项式空间被 $-4$ 倍地映回自身，一次试探必成功；若右端次数对应的 $\lambda=0$ 恰是特征根，才需要升次重设。

第六步：两个初值定两个常数

$f(0)=0$：$C_1+C_2=0$。$f'(u)=2C_1e2u-2C_2e-2u-\dfrac14$，$f'(0)=0$：$2C_1-2C_2=\dfrac14$，即 $C_1-C_2=\dfrac18$。为什么两个条件刚好够：二阶方程通解含两个自由常数，一个初值定一个。解得 $C_1=\dfrac1{16},\ C_2=-\dfrac1{16}$：

$$f(u)=\frac{1}{16}\left(e2u-e-2u\right)-\frac u4.$$

验算：$f''=\dfrac14(e2u-e-2u)$，$4f=\dfrac14(e2u-e-2u)-u$，相减得 $u$ ✓；$f(0)=0$、$f'(0)=\dfrac{2}{16}+\dfrac{2}{16}-\dfrac14=0$ ✓。

易错点

  • $z_{yy}$ 漏一阶项：$-f'(u)ex\cos y$ 不写，$f'$ 项不抵消，整题崩盘——它的存在正是"调和消项"机制的另一半。
  • 忘约 $e2x$：不约就看不出 $f''-4f=u$，方程永远带着 $x,y$ 解不动。
  • 初值方程算错：$f'(0)=0$ 给出 $2C_1-2C_2=\dfrac14$，除以 2 才是 $\dfrac18$，直接令 $C_1-C_2=\dfrac14$ 会差一半。
  • 特解形式乱设：右端是一次多项式，设 $au+b$ 即可；设 $au$ 也可，设指数式反而解不出。
结论：$u=ex\cos y$ 调和（$\Delta u=0$）⇒ $z_{xx}+z_{yy}=f''(u)e2x$ ⇒ $f''-4f=u$ 配初值 ⇒ $f(u)=\dfrac1{16}(e2u-e-2u)-\dfrac u4$。
