栈和队列的应用
选择题 2 分

已知程序如下：

int S(int n)
{
    return (n <= 0) ? 0 : S(n - 1) + n;
}

void main()
{
    cout << S(1);
}

程序运行时使用栈来保存调用过程的信息，自栈底到栈顶保存的信息依次对应的是__。

答案

答案：A

▶本题解析视频（B 站）
1

本题讲解：递归调用时栈内保存信息的排列次序

答案：A

第一步：理清调用链

程序从 main() 开始执行，main() 调用 S(1)；S(1) 中 n=1 大于 0，于是要计算 S(0)+1，又调用 S(0)；S(0) 满足 n≤0 直接返回 0。所以调用链为 main() → S(1) → S(0)。

第二步：按"先调用先入栈"排栈

程序运行时用栈保存函数调用的信息（返回地址、参数、局部变量等），规则是：先调用的函数先入栈，后调用的压在栈顶。

时刻动作栈内（自底向上）
1main() 开始执行main()
2main 调用 S(1)main() → S(1)
3S(1) 调用 S(0)（最深时刻）main() → S(1) → S(0)
4S(0) 返回 0 出栈，S(1) 算出 1 出栈main()
5main 输出 1，结束出栈（空）

在递归到达最深、S(0) 尚未返回的那一刻，栈内自栈底到栈顶依次是 main() → S(1) → S(0)。

易错点

  • 把栈顶当成栈底：若按 B/D 那样把后调用的写在前面，就颠倒了"栈顶是最后入栈元素"这一基本性质。
  • 漏掉某一层调用：C 选项写成 main()→S(0)→S(1)，忽略了 S(1) 先于 S(0) 被调用。
记忆点：调用栈的入栈次序 = 调用发生的先后次序；栈顶永远是"当前正在执行"的函数。

本题讲解：先序序列固定时不同二叉树的个数

答案：B（14 个）

第一步：转化问题

先序序列固定为 a,b,c,d，意味着：给定一个树形（4 个结点的二叉树形态），按先序次序依次填入 a、b、c、d，标号方式唯一。反过来，不同的树形就得到不同的二叉树。所以本题等于问：4 个结点的二叉树有多少种形态。

第二步：用递推计数

设 f(n) 为 n 个结点的二叉树形态数。取 1 个结点做根，左子树 i 个结点、右子树 n−1−i 个结点，则：

f(n) = f(0)·f(n−1) + f(1)·f(n−2) + … + f(n−1)·f(0)，其中 f(0) = 1（空树）。

n计算f(n)
0边界1
1f0·f0 = 11
2f0·f1 + f1·f0 = 22
3f0·f2 + f1·f1 + f2·f0 = 55
4f0·f3 + f1·f2 + f2·f1 + f3·f0 = 5+2+2+514

第三步：卡特兰数验证

n 个结点的二叉树形态数就是卡特兰数：f(n) = C(2n, n) / (n+1)。代入 n=4：C(8,4)/5 = 70/5 = 14，与递推一致。

易错点

  • 误选 C（15）或 D（16）：把"4 个结点的有序树/无标号树"等别的计数对象混进来，或忘记 f(0)=1 这一边界。
  • 误以为标号还有自由度：先序序列已把每个树形的标号唯一确定，不存在"同一树形多种标号"的放大效应。
记忆点：先序固定 → 数形态；形态数 = 卡特兰数 C(2n,n)/(n+1)，n=4 时为 14。

本题讲解：两条根到叶路径能否同属一棵哈夫曼树

答案：D

第一步：把"权值序列"翻译成树上的约束

路径序列如 24,10,5 表示从根出发依次经过权为 24、10、5 的结点到达叶。由此得到三条硬性规则：

  1. 两条路径公共前缀对应同一个结点，从分叉点起才是不同结点；
  2. 父结点权值 = 两个孩子权值之和（哈夫曼树的合并性质）；
  3. 哈夫曼树不含权为 0 的结点，且可由叶子集合自底向上合并还原验证。

第二步：逐项排查

选项推理结论
A两路径共享结点 10，则 5 和 7 是同一父结点的孩子，但 5+7=12≠10矛盾
B根 24 的两个孩子是 10 与 12，但 10+12=22≠24矛盾
C路径 24,10,10：权 10 的结点有孩子 10，另一个孩子权为 0矛盾
D24=10+14 ✓；10=5+5；14=6+8，叶子集合 {5,5,6,8}自洽

第三步：用哈夫曼构造法验证 D

把 {5,5,6,8} 当叶子反推哈夫曼树：合并最小两个 5+5=10；再合并 6+8=14；最后 10+14=24。得到的树根为 24、两个内结点恰为 10 和 14，两条路径 24,10,5 与 24,14,6 都在这棵树上，完全吻合。

易错点

  • 只看首元素相同就选：A/B 选项首元素都是 24，但必须继续核对"孩子权之和=父权"。
  • 忽略公共前缀的含义：两序列前缀相同说明是同一结点，两个孩子权必须加起来等于父权。
  • 忘记反演验证：D 不仅无矛盾，还能被 {5,5,6,8} 的哈夫曼构造完整还原，这才是"能属于同一棵哈夫曼树"的充分证据。
记忆点：先查"同父孩子相加"，再用叶子集合反演哈夫曼构造，两关都过才算正确。

答案：D

4

本题讲解：中序为降序序列的 AVL 树的性质判断

答案：D

第一步：确定树的基本形态

中序遍历（左→根→右）得到降序序列，说明这是"镜像"的二叉排序树：对任一结点，左子树所有结点 > 根 > 右子树所有结点。同时它是 AVL 树，任一结点左右子树高度差不超过 1。

第二步：逐项判断

  • A（根的度一定为 2）错：度指孩子数。树只有 1 个结点时根的度为 0，2 个结点时度为 1，均合法。
  • B（最小元素一定是叶结点）错：最小元沿"最右链"走，它必无右孩子（否则右子树里还有更小的），但可以有左孩子（左孩子比它大，不违反性质）。反例：根 10、右孩子 5、5 的左孩子 7，中序为 10,7,5，最小元 5 不是叶。
  • C（最后插入的元素一定是叶结点）错：插入可能引发失衡旋转，新结点会被"顶"上去。反例：空树依次插入 3、1、2，在 3 处发生 LR 失衡，双旋后 2 成为根，最后插入的 2 带着两个孩子 1 和 3，不是叶。
  • D（最大元素一定无左子树）对：最大元沿"最左链"走。若它还有左孩子，左子树全是比它大的元素，与"它最大"矛盾，所以左子树必不存在；右孩子可有可无（右子树全是更小元素）。

易错点

  • 只按普通 BST（中序升序）想：本题是降序，左右大小关系要反过来，最大元在"最左链"上。
  • 忽略旋转对 C 的影响：新结点插入时确实是叶，但 AVL 会旋转调整，旋转可能把它变成内结点。
  • 混淆"无左子树"与"是叶结点"：D 只要求没有左孩子，右孩子可以有，所以 D 的表述更弱、恰好恒成立。
记忆点：降序 BST 中，最右链的末端（最小元）必无右孩子；最左链的末端（最大元）必无左孩子。

本题讲解：有向图从 v0 出发 DFS 的不同序列个数

答案：D（5 个）

第一步：整理邻接关系

有向图 G：V={v0,v1,v2,v3}，E={⟨v0,v1⟩,⟨v0,v2⟩,⟨v0,v3⟩,⟨v1,v3⟩}。

顶点能直接到达
v0v1, v2, v3（次序可任选）
v1v3
v2无
v3无

DFS 深度优先：访问某顶点后先递归访问它的全部可达未访问邻接点，回溯后再访问下一邻接点；起点固定为 v0。

第二步：按"第一个访问谁"分类枚举

  • 先访问 v1：v1 只能去 v3，v3 无出边，回溯到 v0 后只剩 v2 → v0,v1,v3,v2（1 种）
  • 先访问 v2：v2 无出边，回溯到 v0；第二个可任选 v1 或 v3 → v0,v2,v1,v3、v0,v2,v3,v1（2 种）
  • 先访问 v3：v3 无出边，回溯到 v0；第二个可任选 v1 或 v2 → v0,v3,v1,v2、v0,v3,v2,v1（2 种）

合计 1+2+2 = 5 种。

易错点

  • 漏数"先访问 v2/v3"的情形：以为 DFS 必须按编号顺序访问邻居（那样只剩 1 种）。DFS 的邻接点访问次序取决于存储结构，题目问的是"可能得到"的不同序列个数。
  • 忘记回溯后继续访问剩余邻居：如 v0,v1,v3 之后必须回到 v0 再访问 v2，否则序列不完整。
  • 忽略 v1→v3 的约束：v1 在前时 v3 一定紧跟其后（v1 的唯一出边），所以 v0,v1,v2,v3 是不存在的。
记忆点：分类标准取"v0 之后第一个访问的顶点"，每类再枚举回溯后的选择，1+2+2=5。

本题讲解：判断哪个序列不能是折半查找的比较序列

答案：A

第一步：判定规则

折半查找每次比较后，查找范围缩小为左半或右半，下一次被比较的关键字必须落在当前"可能区间"内。给定一个比较序列，只需检查是否存在一组"左/右走"的走向，使每个关键字都落在前一步缩出来的区间里。

第二步：验证 A（500, 200, 450, 180）

步骤比较可能区间判定
1500x<500 → (−∞, 500)✓
2200200∈(−∞,500)；若 x<200 → (−∞,200)，若 x>200 → (200,500)✓
3450450 只可能在 (200,500) 中出现，故取 x>200；x<450 → (200,450)✓
4180180 ∉ (200,450)✗ 越界

第 4 次要与 180 比较，但 180 已经不在可能区间内——区间里轮不到它，所以 A 不可能。

第三步：验证其余三项（存在合法走向即可）

  • B：500→450→200→180：全程向左，x 依次落入 (−∞,500)、(−∞,450)、(−∞,200)，180 ∈ (−∞,200) ✓
  • C：180→500→200→450：右、左、右，区间 (180,∞)→(180,500)→(200,500)，450 ∈ (200,500) ✓
  • D：180→200→500→450：右、右、左，区间 (180,∞)→(200,∞)→(200,500)，450 ∈ (200,500) ✓

  • 只检查"下一关键字比上一关键字小/大"：单调性不是判据，区间的"范围收缩"才是。
  • 漏掉分支：比较后既可能向左也可能向右，必须枚举两个分支，只要有一个分支能让后续所有关键字落在区间内，序列就合法（B 正是靠"一路向左"存活）。
  • 对 A 误以为合法：看到 500→200→450 递增、最后 180 变小就觉得"可能是先左后右"，但 450 比较完区间已不含 180。
记忆点：折半比较序列合法 ⇔ 每个被比较的关键字都落在前面所有比较共同缩出的可能区间内。

选择题 2 分

已知字符串S为“abaabaabacacaabaabcc”，模式串t为“abaabc”。采用KMP算法进行匹配，第一次出现“失配”（s[i]≠t[j]）时，i=j=5，下次开始匹配时，i和j的值分别是__。

答案

答案：C

▶本题解析视频（B 站）
8

本题讲解：KMP 首次失配后 i、j 的取值

答案：C（i=5, j=2）

第一步：确认下标与失配位置

主串 S = abaabaabacacaabaabcc，模式串 t = abaabc，下标从 0 开始。S[0..4] = abaab 与 t[0..4] = abaab 逐位相等；第 6 次比较 S[5] = a 与 t[5] = c 不相等，即首次失配发生在 i = j = 5（与题干一致）。

第二步：失配处理——求 t[0..4] 的最长相等前后缀

KMP 的规则：i 不回退，j 回退为"已匹配部分 t[0..j−1] 的最长相等前后缀长度"。已匹配部分是 t[0..4] = abaab：它的最长相等前后缀是 ab（前缀 ab 与后缀 ab 相等，长度 2；不存在更长的）。

第三步：得出 i、j

  • i 保持 5 不变（主串指针永不回退）；
  • j 回退为 2，即下次从 S[5] 与 t[2] 开始比较；
  • 几何意义：模式串右移 3 格，t[0..1] = ab 自动对齐 S[3..4]（这两位不必重比），正是"最长相等前后缀"提供的跳跃。

所以下次开始匹配时 i = 5，j = 2，选 C。

易错点

  • 选 A（i=1, j=0）：这是朴素 BF 算法的做法（i 回退到 i−j+1、j 归 0），KMP 的全部价值就在于 i 不回退。

本题讲解：二级页表的地址划分与转换开销

答题框架

先按"10 + 10 + 12"读位段 → 定页大小与页数 → 算页目录/页表占页数 → 用高 10 位判断涉及几个二级页表。

第一问：页和页框的大小、虚拟地址空间页数

虚拟地址 32 位，页内偏移占 12 位 → 页大小 = 2^12 = 4096 字节（4KB）；页框大小恒等于页大小，也是 4096 字节。

虚拟地址空间 = 2^32 字节 ÷ 2^12 字节/页 = 2^20 = 1048576 页（20 位页号）。

第二问：页目录和页表共占多少页

页目录项与页表项均为 4 字节，每页 4096 字节可容纳 1024 个表项：

  • 页目录：页目录号 10 位 → 2^10 = 1024 项 × 4B = 4KB = 1 页；
  • 页表：进程共 2^20 页，每页需要 1 个页表项 → 2^20 × 4B = 4MB → 4MB ÷ 4KB = 1024 页；
  • 合计：1 + 1024 = 1025 页。

第三问：两个地址共访问多少个二级页表

把两个地址按 10 + 10 + 12 展开：

虚拟地址页目录号（高 10 位）页表索引（中 10 位）
0100 0000H0000000100B = 40000000000B = 0
0111 2048H0000000100B = 40100010010B = 274

两个地址的页目录号相同（都是 4） → 查到的是同一个页目录项 → 它指向同一个二级页表。虽然页表索引不同（0 与 274，是同一页表内不同的表项），但涉及的二级页表只有这一个 → 共访问 1 个二级页表。

易错点

  • 第一问漏答页框：页框大小 = 页大小 = 4KB，两问各答一次。
  • 第二问以为"页表占 1 页"：2^20 个页表项共 4MB，单页放不下——这正是二级页表把大页表拆成 1024 个 4KB"页表页"的原因。
  • 第三问答成 2：访问几个二级页表取决于页目录号是否相同，与地址个数无关；两地址页目录号同为 4，只涉及 1 个二级页表。
记忆锚点：偏移 12 位定页大小；页目录号相同 → 同一个页目录项 → 同一个二级页表。

本题讲解：DHCP 地址池、ARP 广播帧与网关配置错误（9 分大题）

三问结论先行：① 地址池 111.123.15.5 ～ 111.123.15.254，Discover 报文源 IP 0.0.0.0、目的 IP 255.255.255.255；② 第一个以太网帧（ARP 请求）目的 MAC FF-FF-FF-FF-FF-FF，承载 IP 分组的帧目的 MAC 00-a1-a1-a1-a1-a1；③ 主机 1 能访问 WWW 服务器，不能访问 Internet（默认网关配错）。

拓扑要点：交换机一侧接 WWW 服务器（111.123.15.3/24）、DHCP 服务器（111.123.15.2/24，MAC 00-b1-b1-b1-b1-b1）、主机 1（111.123.15.4/24）与主机 2～N（DHCP 动态获取），另一侧接路由器内网接口（111.123.15.1/24，MAC 00-a1-a1-a1-a1-a1），路由器外侧是 Internet。

第 1）问：DHCP 地址池与 Discover 的 IP 封装

答题框架：先圈出静态占用的地址，剩下才是动态池；Discover 在主机还没有 IP 时只能「全 0 源、全 1 目的」广播。

  • 静态占用：路由器 .1、DHCP 服务器 .2、WWW 服务器 .3、主机 1 .4；.0 是网络地址、.255 是广播地址，都不能分配。
  • 可动态分配的最大范围：111.123.15.5 ～ 111.123.15.254。
  • 主机 2 此刻没有 IP → 源 IP 填 0.0.0.0；也不知道 DHCP 服务器在哪 → 对本网广播，目的 IP 255.255.255.255。

第 2）问：两个「目的 MAC 地址」

答题框架：ARP 表为空 ⇒ 第一个帧是广播的 ARP 请求；真正传数据的帧按「下一跳」封装 MAC。

  • 要把分组发往 Internet，下一跳是默认网关（路由器内网口 111.123.15.1），而 ARP 表为空 → 第一个帧就是 ARP 请求广播帧，目的 MAC = FF-FF-FF-FF-FF-FF。
  • 学到网关 MAC 后，封装发往 Internet 的 IP 分组的以太网帧，目的 MAC = 下一跳的 MAC = 00-a1-a1-a1-a1-a1（路由器内网接口）。注意：帧里的目的 MAC 写网关，IP 分组头里的目的 IP 仍是 Internet 上那台服务器。

第 3）问：主机 1 能否访问 WWW 服务器 / Internet

答题框架：先判断同网段直连，再看网关对不对。

  • 掩码 255.255.255.0 与网络 /24 一致；WWW 服务器 111.123.15.3 与主机 1 同子网 → 直接交付、不经网关，能访问。
  • 默认网关被配成 111.123.15.2——那是 DHCP 服务器，不是路由器内网口（应为 111.123.15.1）。访问 Internet 的分组会被交给错误网关，而 DHCP 服务器不作路由转发 → 不能访问 Internet。

易错点

  • 把 .255 或静态占用的 .1～.4 算进 DHCP 地址池。
  • 第 2）问把「载 IP 分组的帧」也写成全 F：广播只用于 ARP 请求；传数据帧的目的 MAC 是网关接口的 MAC。
  • 第 3）问漏答 WWW 可达：同子网通信不依赖默认网关，网关配错只影响跨网段访问。
记忆锚点：DHCP Discover = 0.0.0.0 → 255.255.255.255；ARP 请求 = 全 F 广播；跨网段的帧永远封装「下一跳」的 MAC。
